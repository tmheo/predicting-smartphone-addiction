버리는 논리 시제품

재학습 예산을 숫자가 아니라 근거에서 실행하기

원시 선택값을 모델 계열 연결부에서 관측 학습 길이로 바꾸고, 공통 계산부가 재학습 예산을 도출하며, 장부 검증기가 계산을 다시 수행해야만 전체 자료 재학습을 허용하는 계약을 눌러서 시험합니다.

이 시제품이 답하려는 질문 모델별 의미 변환, 공통 예산 계산, 근거 보존, 실행 차단을 각각 어느 경계가 소유해야 미확정 값과 손으로 고친 예산이 전체 자료 재학습으로 넘어가지 않는가?
모델 계열 연결부

normalize_training_length

원시 필드의 의미를 알고 원시 선택값과 관측 학습 길이를 함께 내보냅니다. 공통부는 필드 이름을 추측하지 않습니다.

공통 계산부

derive_refit_budgets

확정된 관측 학습 길이만 받아 시드별 중앙값, 1.25배, 사사오입을 한 번만 수행합니다.

재학습 계획 장부

validate_for_refit

원시 근거와 실행 계보에서 예산을 다시 계산합니다. 저장 예산이 다르거나 근거가 미확정이면 실행을 막습니다.

각 행은 원래 모형 상태까지 돌아갈 수 있는 한 건의 근거입니다.

시드별 재학습 예산

저장값과 재계산값이 같아야 실행할 수 있습니다.

자유 조작

순서와 상관없이 눌러 보면서 어떤 상태가 거부되는지 확인합니다.

`예산만 1 줄이기`는 장부 숫자만 손으로 바꾼 상황을, `근거 실행 ID 훼손`은 실행 계보가 끊긴 상황을 흉내 냅니다.

용어 경계

          
분할별 변환 결과는 `관측 학습 길이`, 전체 자료 실행에 넘길 최종 횟수는 `재학습 예산`으로 부를지 확인합니다.

        

        

          
소유권 경계

          
모델 계열 연결부는 원시 의미 변환만, 공통 계산부는 중앙값과 배수와 반올림만, 계획 장부는 계보 보존과 실행 관문만 소유할지 확인합니다.

        

        

          
실행 관문

          
전체 자료 재학습 진입점이 저장된 예산을 그대로 믿지 않고, 확정 원시 근거에서 매번 다시 계산해 정확히 일치할 때만 실행할지 확인합니다.
