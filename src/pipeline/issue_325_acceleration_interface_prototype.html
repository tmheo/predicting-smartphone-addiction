              현재 권고
              기본 호출자 우선안을 중심으로 합친다
              
      
              
        기존 cv.run_cv interface는 유지하고 내부 execute_seed가 복구 선검증부터 폴드 결과 확정까지 소유하는 안이 가장 강하다.
