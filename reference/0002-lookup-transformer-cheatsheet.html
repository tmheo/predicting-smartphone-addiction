컬럼별 인코딩 규칙

컬럼 종류lookup 채널PLR 채널
lookup_cols (원시 12컬럼) 학습 fold의 정확값마다 id. id 0 = NA, 마지막 id = UNK 수치 컬럼이면 rank-gauss 값으로 켬. 결측·범주는 mask로 끔
그 외 (연속 파생 6컬럼) 컬럼 상수 embedding 하나 (어휘 크기 1) 항상 사용. 이 채널이 정보의 전부

어휘와 분위 함수는 학습 fold에서만 적합한다. 검증·테스트의 새 값은 UNK로, 결측은 NA로 간다. 이 둘은 다른 embedding이다.

용어

용어뜻
lookup embedding정확값 id로 조회하는 학습 벡터. 합성 데이터의 반복 키를 암기
PLRPeriodic-Linear embedding. sin·cos로 펼친 수치를 선형 변환해 연속 추세를 표현
rank-gauss분위(순위) 기반으로 수치를 정규분포 모양으로 바꾸는 변환
CLS 토큰분류 요약 전용 토큰. encoder 통과 후 이 토큰의 출력만 head로 감
NA / UNKNA는 결측, UNK는 학습 fold에 없던 새 값. 컬럼별로 분리된 id
EMA가중치의 지수이동평균. 학습 노이즈를 걸러 평가를 안정화
