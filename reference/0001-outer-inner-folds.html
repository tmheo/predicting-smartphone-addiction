빠른 참고표

outer fold는 평가,
inner fold는 누수 방지

outer 5-fold

전체 학습 데이터를 5등분한다.

매번 4개로 모델을 학습하고 남은 1개로 성능을 잰다.

각 행이 정확히 한 번 모델의 검증 대상이 된다.

inner 10-fold

outer fold의 학습 데이터만 다시 10등분한다.

각 행의 target encoding을 만들 때 그 행의 정답을 제외한다.

모델 성능을 다시 평가하는 절차가 아니다.

기억할 한 문장: outer 5-fold는 모델을 평가하고, inner 10-fold는 누수 없이 target encoding feature를 만든다.
