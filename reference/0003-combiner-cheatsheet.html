결합 전략 (COMBINER_REGISTRY)

이름학습동작
rank_mean없음블록 내 백분위 순위의 균등 평균. 가중치 전원 1/N.
performance_weighted_rank_mean약함단독 OOF AUC의 0.5 초과분을 비음수 가중치로 정규화.
greedy_rank_mean / bagged_greedy_rank_mean선택AUC가 오르는 동안 구성원을 하나씩 추가. bagged는 층화 부분 표본 50개의 선택 빈도 평균.

ridge_logit_alpha_*계수logit 변환 예측에 Ridge 회귀 (alpha 0.01-100).
logit_logistic / rank_logistic / rank_gauss_logistic계수단일 표현(logit, 경험적 CDF 순위, rank-gauss) + 표준화 + 로지스틱 회귀.
rank_logit_logistic ★#64계수구성원당 [순위, logit] 이중 표현 → 표준화 → 로지스틱 (C=1, lbfgs). 순위는 학습 블록의 경험적 CDF를 고정해 적용.
missing_segmented_rank_logit ★#65계수×3원시 특성 결측 0-1 / 2-3 / 4+ 구간마다 rank_logit_logistic을 독립 학습. 구간은 train+test에서 목표값 없이 사전 고정.
missing_4plus_rank_logit계수×2전역 모델 유지, 결측 4+ 구간만 전용 모델로 교체.
missing_interaction_rank_logit계수전역 이중 표현에 구간 지시자 상호작용 항을 추가한 단일 로지스틱.
xgb_rank_logit트리이중 표현 위 depth 2, 200그루 고정 XGBoost 2단 결합.
