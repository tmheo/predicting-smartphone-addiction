# AMFormer 진입 진단

이 문서는 [P3: AMFormer의 champion 교체·후보 풀 다양성 기여 결정](https://github.com/tmheo/predicting-smartphone-addiction/issues/144)의 구현과 Vast.ai fold 0 진입 진단 결과를 기록한다.

## 결론

AMFormer는 fold 0 seed 42에서 AUC `0.7250206215`를 기록했다.
같은 fold의 champion AUC `0.9685285491`보다 `0.2435079275` 낮아 허용 폭 `0.01`을 크게 넘었다.
전진·역전파의 수치 안정성, 메모리, 시간과 예측 무결성은 모두 통과했지만 성능 문턱에서 탈락했다.
[P3: AMFormer의 champion 교체·후보 풀 다양성 기여 결정](https://github.com/tmheo/predicting-smartphone-addiction/issues/144)의 규칙에 따라 seed 42 5-fold, 중복·표준 순위 평균 기여 측정과 3시드 확정 재검증은 실행하지 않는다.
폭 64 축소 조건도 발생하지 않았고 설정을 추가 탐색하지 않는다.
champion과 후보 풀은 바꾸지 않는다.

## 독립 구현

`src/pipeline/amformer.py`는 [AAAI 2024 논문](https://ojs.aaai.org/index.php/AAAI/article/view/29033)에 적힌 수치·범주 열 표현, 병렬 덧셈·곱셈 주의, 학습 질의 벡터, 곱셈 경로 상위 k개 선택과 잔차 연결 구조를 근거로 새로 작성했다.
GPL-3.0인 [공식 구현](https://github.com/aigc-apps/AMFormer)과 이를 바탕으로 한 TALENT 소스는 복사하거나 번역하지 않았고 설정과 동작을 대조하는 자료로만 사용했다.
논문에 정의되지 않은 `target_mode=mix`는 학습 질의 벡터와 같은 위치의 행별 입력 표현을 더해 자료 공통 상호작용과 행별 상호작용을 함께 질의하는 것으로 이 저장소 안에서 명시했다.

`AMFormerAdapter`와 `MODEL_REGISTRY`의 `amformer` 항목을 통해 기존 실행 계약에 연결했다.
`configs/exp085_amformer.yaml`은 champion의 33개 특성과 원시 수치 열 9개의 결측 표시를 합친 42개 입력 표현을 사용한다.
모형은 3층, 폭 128, 머리 8개, 층별 학습 질의 수 `[42, 42, 42]`, 곱셈 경로 선택 수 `[4, 4, 4]`로 고정했다.
학습률은 `1e-4`, 가중치 감쇠는 `1e-5`, 주의 탈락률은 `0.2`, 나머지 탈락률은 `0.1`, 최대 epoch는 50, 조기 종료 대기는 5 epoch다.
permutation importance는 seed 42로 고정한 검증 행 8,192개와 반복 1회를 사용했다.
