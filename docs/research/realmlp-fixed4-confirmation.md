# RealMLP 고정 4 epoch 다양성 진입 재검증

이 문서는 GitHub 이슈 [공개 스택 재현: RealMLP-TD 2시드의 다양성 진입](https://github.com/tmheo/predicting-smartphone-addiction/issues/180)의 구현, 실행과 판정을 기록한다.
대상은 `configs/exp121_realmlp_fixed4_two_init.yaml`이며 커밋된 5개 바깥쪽 분할과 파이프라인 시드 42, 43, 44를 사용했다.

## 결론

시드 42 선확인의 OOF AUC는 `0.9636468810`으로 진입 하한을 넘었고 최근접 구성원과의 중복 관문도 통과했다.
3시드 평균 OOF AUC는 `0.9637131967`이며 진입 하한 `0.9591957618`보다 `0.0045174349` 높다.
최근접 구성원 `exp110_lgb_kitopl_no_te`와의 스피어만 상관은 `0.9842843993`으로 중복 기준 `0.998`보다 낮다.
따라서 확인 실행 `56701722ba224b98b5ddf799ec5e55db`을 후보 풀의 24번째 구성원으로 등록했다.

24개 풀의 최선 중첩 OOF 전략은 `missing_interaction_rank_logit`이며 AUC는 `0.9696190314`다.
같은 전략의 23개 풀 기준 `0.9696138214`보다 `+0.0000052100` 높다.
RealMLP는 5개 바깥쪽 분할에서 모두 선택됐고 평균 계수는 `-0.2033151057`이다.
이 증분은 마일스톤 제출 기준 `+0.0002`에 미달하므로 이 이슈에서 새 제출은 만들지 않는다.

공개 계약의 두 초기화 평균 AUC `0.9682583979`는 자체 재현의 3시드 평균보다 `0.0045452012` 높다.
따라서 공개 수치의 동일 재현으로 주장하지 않고, 공개 구조를 누출 없이 자체 자료 흐름에 옮겨 다양성 관문을 통과한 결과로 한정한다.

## 공개 구조의 이식

모형은 512차원 은닉층 세 개, piecewise-linear 수치 임베딩의 은닉 차원 20과 출력 차원 5, 배치 크기 256, 고정 4 epoch와 스케줄 지평 8을 사용한다.
각 내부 초기화는 병렬 모형 8개의 평균이고, 바깥쪽 분할 안에서 초기화 두 개의 예측을 다시 산술 평균한다.
이 두 초기화 평균은 파이프라인 시드 42, 43, 44의 평균과 별개다.

공개 계약은 `pytabkit RealMLP_TD_Classifier`라는 이름을 쓰지만, 고정한 공개 노트북의 실제 구현은 직접 작성한 PyTorch RealMLP다.
감사 가능한 공개 소스를 구현 기준으로 삼았고 학습 관측에 `source_backend=custom_pytorch_realmlp`과 `pytabkit_estimator_used=false`를 남겼다.
이 차이를 숨긴 채 라이브러리 분류기를 재현했다고 기록하지 않는다.

결측 대체, 범주 어휘, 수치 구간과 내부 목표 인코딩은 바깥쪽 학습 부분에서만 맞춘다.
목표 인코딩은 바깥쪽 학습 부분 내부의 5-fold OOF 표현을 학습 행에 돌려준다.
검증 목표값은 전처리, epoch 선택이나 초기화 선택에 사용하지 않으며 고정 4 epoch의 마지막 상태만 쓴다.
공개 구현의 내부 특성 53개에 저장소 필수 `placebo_noise` 한 열을 더해 모든 조합에서 54개 내부 특성을 사용했다.

## 성능과 무결성

| 측정값 | 결과 |
| --- | ---: |
| 시드 42 OOF AUC | `0.9636468810` |
| 시드 43 OOF AUC | `0.9636610665` |
| 시드 44 OOF AUC | `0.9636572062` |
| 3시드 평균 OOF AUC | `0.9637131967` |
| 최근접 후보 스피어만 상관 | `0.9842843993` |
| 표준 평가 앙상블 참고 변화 | `-0.0000283233` |
| 24개 풀 중첩 OOF AUC | `0.9696190314` |
| 23개 풀 같은 전략 대비 변화 | `+0.0000052100` |

15개 시드와 분할 조합의 예측과 순열 중요도는 모두 유한값이다.
각 조합에서 학습 행 수, 전처리 적합 행 수와 목표 인코딩 적합 행 수가 일치한다.
`placebo_noise` 순열 중요도의 절댓값 최댓값은 `0.0000398237`이다.
확인 실행의 모형 학습 시간 합은 `2559.09초`이고 조합별 범위는 `169.65초`부터 `172.20초`다.
최대 CUDA 할당 메모리는 916,721,664바이트이고 최대 예약 메모리는 1,331,691,520바이트다.

전체 자료 재학습 계획에는 바깥쪽 분할의 고정 학습 길이 4에 규약 배수 1.25를 적용해 시드별 5 epoch를 기록했다.
이 이슈에서는 전체 자료 재학습을 실행하지 않았다.

## 출처와 사용 조건

고정한 공개 소스는 Kaggle 노트북 [S6E8 Fold-Safe RealMLP](https://www.kaggle.com/code/beicicc/s6e8-fold-safe-realmlp)이며 kernel id는 `129554888`이다.
받은 소스의 SHA-256은 `60a0bd05332e8932468d9cc796855013be3c3798344fd75c15c016764eba58ef`다.
공개 노트북 소스의 Apache License 2.0 조건을 따랐고 원문 사용 조건 사본과 수정 내역을 구현 파일에 연결했다.
원본에 별도 `NOTICE`는 없었다.

공개 예측 계약 자료는 Kaggle 자료 [S6E8 Fixed4 RealMLP Two-Seed Artifacts](https://www.kaggle.com/datasets/beicicc/s6e8-fixed4-realmlp-two-seed-artifacts)이며 사용 조건은 CC BY 4.0이다.
계약의 초기화별 AUC는 `0.9681563866`과 `0.9681715455`이고 산술 평균 AUC는 `0.9682583979`다.
이 자료의 예측은 진입 진단과 공개 수치 대조에만 사용했으며 후보 풀에는 자체 학습한 예측만 넣었다.

## 원격 실행과 결과 해시

화면 평가는 Vast.ai RTX A4000 한 장과 `nvcr.io/nvidia/pytorch:26.01-py3` 이미지를 사용했다.
인스턴스 `48070695`의 실행 상태 이후 시간은 945초이고 계산 비용 추정치는 `$0.020980556`이다.
기준 커밋은 `30767b899aba03b2bf86ff0822bfc3e427681231`이고 입력 묶음 SHA-256은 `a47c03de91037f79b5a4438798813a3feb31e0d3276068e76ff016e9645bb880`이다.
회수 결과 SHA-256은 `8f58fadfe096ea23a0a34a0ff7e1682ee0ca94ac7c8037cb1741942978e2edaf`다.

3시드 확인도 같은 공급자, GPU 등급과 이미지를 사용했다.
인스턴스 `48071959`의 실행 상태 이후 시간은 2708초이고 계산 비용 추정치는 `$0.060122058`이다.
기준 커밋은 `8958baffc1179f99ba9585ff5d87a261dc4c179e`이고 입력 묶음 SHA-256은 `1cb67361af93bd8e3d753142dfec9b4f2ed5ea3cba6b1d52d32f2c89ca990b8c`이다.
회수 결과 SHA-256은 `97a60f3de118500c04a07eb33068a9ba86507823f277ed616de984e8198d2246`다.

결과를 회수하고 해시를 확인한 뒤 두 계산 자원과 이 작업의 종료 예약을 삭제했다.

확인 원본 실행 `cf0318dfa8ed4ee9bb9ee4180280200c`는 주 MLflow에 `56701722ba224b98b5ddf799ec5e55db`으로 반입했다.
