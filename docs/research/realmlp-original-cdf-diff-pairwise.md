# RealMLP 원본 프록시 CDF 차이 5열 짝비교

## 결론

원본 프록시 CDF 차이 5열을 더한 `exp140_realmlp_orig_cdf_diff`는 직접 기준인 `exp124_realmlp_dtype_fix`보다 3시드 평균 OOF AUC가 `+0.00008960` 높았다.
세 시드와 다섯 분할이 모두 개선되어 이 묶음을 `실신호`로 판정했다.
후보는 기존 `exp124`와 스피어만 상관 `0.99907209`로 중복 문턱 `0.998`을 넘었고 후보의 단독 OOF AUC가 더 높아 직접 교체했다.
고정 결합법의 직접 교체 변화는 `+0.000000003`, 외부 분할 3/5로 사실상 동률이었다.
후보 자체의 포함·제외 한계 차이는 `-0.000001304`, 외부 분할 3/5여서 별도의 양의 후보 풀 기여는 확인되지 않았다.
포함·제외 참고값은 후보 풀 진입이나 제거 관문이 아니므로 중복 구성원 가운데 성능이 높은 `exp140`을 남기는 장부 변경과 충돌하지 않는다.

## 구현과 비교 규율

후보 설정은 `exp124_realmlp_dtype_fix`의 RealMLP 모델 설정을 그대로 사용하고 `original_cdf_diff` 제공자만 추가했다.
추가한 열은 `daily_screen_time_hours_orig_cdf_diff`, `weekend_screen_time_orig_cdf_diff`, `social_media_hours_orig_cdf_diff`, `notifications_per_day_orig_cdf_diff`, `app_opens_per_day_orig_cdf_diff`다.
KDE 로그 밀도비 3열은 열지 않았다.
결측값 보정과 수치 변환은 기존 RealMLP와 같은 분할 학습 자료 내부 상태만 사용했다.
구성 차이 시험은 두 설정의 차이가 `features.providers.original_cdf_diff` 하나뿐임을 고정한다.

## 짝지은 OOF 결과

| 단계 | 시드 | 후보 OOF | 기준 OOF | 변화 | 분할 승수 |
| --- | --- | ---: | ---: | ---: | ---: |
| 선별 | 42 | 0.9683352436 | 0.9682564071 | +0.0000788365 | 5/5 |
| 확인 | 42, 43, 44 평균 | 0.9684119417 | 0.9683223458 | +0.0000895959 | 5/5 |

확인 실행의 시드별 변화는 시드 42 `+0.00007884`, 시드 43 `+0.00008913`, 시드 44 `+0.00009895`로 3/3이 양수였다.
평균 개선폭이 `+0.0002`보다 작은 경계 구간이므로 시드 평균 예측의 분할 승수 3/5 이상이 필요했고 실제로 5/5를 충족했다.
확인 실행의 시드 42 예측은 별도 선별 실행과 모든 행에서 정확히 일치했다.
확인 대조군의 3시드 평균 예측은 후보 풀에 있던 `exp124` 실행과 모든 행에서 정확히 일치했다.

## 보조 중요도

확인 실행의 플라시보 평균 중요도는 `0.00000228235`였다.
`daily_screen_time_hours_orig_cdf_diff`는 평균 `0.00620539`로 15/15칸이 플라시보 평균보다 높았다.
`social_media_hours_orig_cdf_diff`는 평균 `0.00270766`으로 15/15칸이 플라시보 평균보다 높았다.
`weekend_screen_time_orig_cdf_diff`는 평균 `0.00041568`로 15/15칸이 플라시보 평균보다 높았다.
`notifications_per_day_orig_cdf_diff`는 평균 `0.00001712`로 10/15칸이 플라시보 평균보다 높았다.
`app_opens_per_day_orig_cdf_diff`는 평균 `-0.00000413`으로 6/15칸만 플라시보 평균보다 높아 짝지은 OOF와 충돌하는 보조 근거로 기록했다.
중요도는 실신호와 후보 풀 판정의 관문으로 사용하지 않았다.

## 후보 풀 판정

판정 원본은 SHA-256 `e6f093c08af4d09a70e2ee9a7cc99f9d099b06b7505116005464b5ae1240712a`인 35개 후보 풀이었다.
후보 OOF AUC `0.96841194`는 champion 기준 진입 하한 `0.95933973`을 통과했다.
고정 결합법 `missing_interaction_rank_logit`에서 기존 35개 풀은 `0.9697297236`, `exp124` 제외 34개 풀은 `0.9697310310`, 후보 포함 35개 풀은 `0.9697297266`이었다.
후보의 포함·제외 한계 차이가 음수라 상태는 `양의 기여 미확인`으로 기록했다.
기존 `exp124`를 후보로 바꾼 직접 변화는 `+0.000000003`이고 외부 분할 3/5가 양수였다.
후보 계수는 5/5 외부 분할에서 선택됐고 평균 가중치는 `-0.20900046`이었지만 계수 부호를 개별 후보의 인과적 기여로 해석하지 않았다.
공식 진입 명령은 중복 구성원 중 OOF AUC가 낮은 `exp124`를 제거하고 `exp140`을 등록했으며 풀 크기는 35개로 유지됐다.

## 결합 전략 재평가와 재학습 계획

교체된 35개 풀에서 기본 결합 전략 19개를 다시 평가했고 실패 전략은 없었다.
최고값은 기존과 같은 `shrunk_rank_logit_logistic`의 nested OOF `0.9697407043`이었다.
전체 자료 재학습에 고정된 `missing_interaction_rank_logit`의 nested OOF는 `0.9697297266`이었다.
이 티켓은 구성원 직접 교체 범위이므로 champion과 전체 자료 결합 규약은 바꾸지 않았다.
전체 자료 재학습 계획에서는 `exp124`를 제거하고 `exp140`을 같은 시드 42, 43, 44와 시드별 5회 학습 예산으로 등록했다.

## 재현성과 원격 정리

선별과 확인 실행은 고정 커밋 `b802367a28de90ad6828f1b691522d578364ef66`, 같은 입력 해시, 같은 5분할과 같은 컨테이너 이미지에서 실행했다.
확인 결과 묶음은 원격과 로컬 SHA-256 `abb52540a164b450008c92be53ba953ed13ef6592c365188a9b249d0bc9d959b`가 일치했고 내부 산출물 목록 검증도 통과했다.
결과를 기본 MLflow 저장소에 반입하고 필수 산출물을 다시 조회한 뒤 Vast.ai 인스턴스를 삭제했다.
삭제 뒤 대상 인스턴스, 작업용 저장 공간과 이 작업의 종료 예약이 모두 없음을 확인했다.
같은 계정에서 다른 작업과 잔액 변동이 겹쳐 이 작업의 단독 비용은 계정 잔액 차이로 산정하지 않았다.
준비 실패를 복구할 때도 같은 Vast.ai 인스턴스를 사용했고 Runpod 자원은 만들지 않았다.
