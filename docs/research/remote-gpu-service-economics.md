# 원격 GPU 서비스 비용과 실행 지속성 조사

조사 기준일은 2026-08-14이다.
공식 가격표, 공식 설명서, 서비스가 직접 제공하는 API 응답만 근거로 사용했다.

## 결론

이 프로젝트의 주 실행 환경은 **Runpod의 일반 임대 Pod**가 가장 적합하다.
RTX A5000의 공개 시작가는 시간당 $0.27이고, 6시간 실행의 계산 자원 비용은 $1.62다.
일반 임대 Pod는 실행 중 GPU를 독점하므로 다른 사용자에게 밀려 중단되지 않고, 컨테이너와 SSH를 지원하며, 초 단위로 과금된다.

**Vast.ai의 검증된 호스트에서 빌리는 일반 임대 인스턴스**는 가장 저렴한 예비 환경으로 적합하다.
공식 API의 현재 매물 스냅샷에서 신뢰도 99% 이상이고 6시간 이상 빌릴 수 있는 RTX A4000의 중간 가격은 시간당 $0.109였으며, 6시간 비용은 약 $0.65였다.
다만 개별 호스트의 신뢰도, 남은 임대 가능 시간, 저장 장치와 통신망 성능을 사용자가 직접 선별해야 한다.

**Colab Pro는 2시간 선별 실험용 보조 환경**으로는 편리하지만, 6시간 확정 재검증의 주 환경으로 삼기에는 부적합하다.
유료 요금제도 GPU 종류, GPU 확보, 전체 사용 한도, 유휴 종료 시점이 보장되지 않고, Colab은 이 한도를 공개하지 않는다.
Colab Pro+는 최대 24시간 연속 실행과 백그라운드 실행을 제공하지만, GPU 가용성의 불확실성은 그대로이고 월 $49.99라서 예외 예산에서만 검토할 만하다.

**선점형 또는 중단 가능 인스턴스는 현재 사용하지 않는다.**
Runpod의 선점형 Pod는 언제든 중단될 수 있고, Vast.ai의 중단 가능 인스턴스는 더 높은 입찰이나 일반 임대 요청 때문에 멈출 수 있다.
현재 실험은 중간 저장 후 이어서 실행할 수 없으므로, 6시간 실행 한 번이 5시간째 중단되면 완료 비용은 최소 11시간분으로 늘어난다.

## 비교 전제

- 실험 시간은 현재 T4급 환경에서 선별 2시간, 확정 재검증 6시간으로 고정했다.
- GPU가 빨라져 실행 시간이 줄어드는 효과는 아직 실측하지 않았으므로 비용표에 반영하지 않았다.
- 원화 환산은 환율 예측이 아니라 예산 비교용 보수적 가정인 `1 USD = 1,500원`을 사용했다.
- 월 5만 원과 10만 원은 각각 약 $33.33과 $66.67로 계산했다.
- 원화 금액에는 카드사의 해외 결제 수수료, 환전 차이, 부가세나 판매세를 포함하지 않았다.
- 아래의 완료 비용은 실행이 한 번에 끝났을 때의 계산 자원 비용이다.
- 서비스들은 실험 단위의 완료율이나 중단 확률을 공개하지 않으므로 실패 확률을 반영한 기대 비용은 계산할 수 없다.

Paperspace는 기본 50 GB 저장 공간에 시간당 $0.0074가 별도로 붙고, 인스턴스를 한 달 내내 보존하면 저장 비용이 최대 $5다.
Lambda Cloud는 판매세가 별도일 수 있다.

선별 10회와 확정 재검증 3회를 한 달에 수행한다고 가정하면 GPU 사용 시간은 총 38시간이다.
같은 GPU에서 실행 시간이 변하지 않는다는 보수적 전제에서 Runpod RTX A5000 계산 비용은 $10.26, 약 15,390원이다.
Runpod L4는 $14.82, 약 22,230원이고, Vast.ai RTX A4000 중간값은 약 $4.14, 약 6,210원이다.
따라서 월 5만 원은 Runpod에서 이번 대회 실험을 운영하기에 충분한 상한이며, 월 10만 원 예외 상한은 고가 서비스가 꼭 필요할 때만 의미가 있다.

## 서비스별 판단

### Colab Pro와 Pro+

공식 가입 페이지의 미국 달러 표시 가격은 Pro 월 $9.99, Pro+ 월 $49.99이고, 각각 매월 100과 500 계산 단위를 제공한다.
100 계산 단위 종량제 묶음도 $9.99로 표시된다.
다만 Google은 GPU별 시간당 계산 단위 소모율을 고정 가격표로 공개하지 않으며, 사용 한도와 GPU 종류도 수시로 바꿀 수 있다고 명시한다.
따라서 공식 자료만으로는 100 계산 단위가 T4에서 몇 번의 2시간 또는 6시간 실험을 완료하는지 계산할 수 없다.

일반적으로 Colab 노트북은 가용성과 사용 패턴에 따라 최대 12시간 실행할 수 있으므로 6시간 작업은 명목상 한도 안에 있다.
그러나 계산 단위가 실행 중 소진되면 백엔드가 종료될 수 있고, 유료 사용자도 특정 GPU를 보장받지 못한다.
Pro+는 계산 단위가 충분하면 최대 24시간 연속 실행할 수 있으며, 공식 요금제 비교표에서 백그라운드 실행은 Pro+에만 제공된다.

이 때문에 Colab Pro 결제는 GPU 부족 문제를 확실히 해결하는 구매가 아니다.
브라우저 기반 노트북의 편의성을 위해 2시간 선별 실험을 분산하는 용도로는 합리적이지만, 완료가 중요한 6시간 실행은 Runpod이나 Vast.ai의 일반 임대 환경으로 보내는 편이 안전하다.

### Runpod

Runpod의 공개 가격표에서 RTX A5000은 시간당 $0.27, L4는 시간당 $0.39부터 시작한다.
Pod는 계산과 저장 공간을 초 단위로 과금하며, 일반 임대 방식은 약정 없이 사용한 만큼만 낸다.
일반 임대 인스턴스는 전용 자원이라 다른 사용자에게 밀려나지 않고, 실행 중에는 GPU가 독점 예약되어 가격이 안정적이며 작업이 선점 중단되지 않는다.
반대로 `interruptible=true`인 선점형 Pod는 다른 Pod에 자원을 내주기 위해 언제든 정지될 수 있다.

일반 임대 Pod를 만들려면 선택한 구성의 최소 1시간분 잔액이 있어야 한다.
Runpod는 처음 평가할 때 $10부터 충전할 수 있고, 충전한 잔액은 환불되지 않는다.
남은 잔액이 실행 시간 10초분보다 적으면 모든 Pod를 자동 정지하므로 6시간 실행 전에는 자동 충전이나 충분한 잔액이 필요하다.

실행 중인 컨테이너 디스크와 볼륨 디스크는 월 GB당 $0.10이다.
정지된 볼륨 디스크는 월 GB당 $0.20이고, 1 TB 미만 네트워크 볼륨은 월 GB당 $0.07이다.
Pod를 정지하면 GPU는 반납되므로 다시 시작할 때 같은 GPU가 없을 수 있다.
네트워크 볼륨을 사용하면 새 Pod에 데이터를 다시 붙일 수 있지만, 네트워크 볼륨이 연결된 Pod는 정지할 수 없고 종료만 할 수 있다.

공식 관리 설명서는 `sleep 2h; runpodctl pod stop ...`처럼 종료 시점을 예약하는 방법을 제공한다.
실험 명령의 종료 코드에 따라 결과를 외부 저장소로 복사한 뒤 Pod를 종료하는 정리 명령을 붙이면 유휴 비용을 제한할 수 있다.

출처: [Runpod GPU 가격](https://www.runpod.io/pricing), [Pod 가격과 저장 비용](https://docs.runpod.io/pods/pricing), [Pod 생성과 선점 조건](https://docs.runpod.io/api-reference/pods/POST/pods), [Pod 관리와 예약 정지](https://docs.runpod.io/pods/manage-pods), [정지 후 GPU 가용성](https://docs.runpod.io/pods/troubleshooting/zero-gpus), [결제와 최소 충전액](https://docs.runpod.io/accounts-billing/billing).

### Vast.ai

Vast.ai는 호스트가 가격을 정하는 시장이므로 고정 시간당 가격이 없다.
일반 임대 인스턴스는 고정 가격과 높은 우선순위를 가지며 실행 중 선점되지 않는다.
중단 가능 인스턴스는 보통 일반 임대보다 50% 이상 싸지만, 더 높은 입찰이나 일반 임대 수요가 생기면 실행 중인 과정이 종료되고 인스턴스가 멈춘다.

2026-08-14에 공식 검색 API를 통해 검증된 호스트, 신뢰도 99% 이상, GPU 1개, 남은 임대 가능 시간 6시간 이상인 일반 임대 매물을 조회했다.
그 결과 RTX A4000은 15개였고 총 시간당 가격은 최저 $0.095, 중간 $0.109, 최고 $0.176이었다.
같은 조건에서 RTX A5000은 10개였고 최저 $0.176, 중간 $0.233, 최고 $0.360이었다.
RTX 3090은 33개였고 최저 $0.116, 중간 $0.195, 최고 $0.601이었다.
L4는 5개였고 최저 $0.332, 중간 $0.336, 최고 $0.339였다.
시세는 조회 즉시 달라질 수 있으므로 이 값은 예산 추정용 스냅샷일 뿐이다.

Vast.ai는 GPU, 저장 공간, 송수신을 각각 초 단위 사용량에 따라 과금하고, 구체적인 가격은 매물마다 다르다.
최소 충전액은 $5다.
잔액이 0이 되면 실행이 자동 정지되고, 결제 수단이 없으면 인스턴스와 데이터가 삭제 대상으로 전환된다.
자동 결제를 켜면 잔액 부족으로 인한 중단을 줄일 수 있다.

정지하면 GPU 과금은 멈추지만 저장 공간 과금은 계속되고, 재시작할 때 GPU가 다시 확보된다는 보장은 없다.
모든 과금을 멈추려면 결과를 회수한 뒤 인스턴스를 삭제해야 한다.
Vast.ai는 일반 인스턴스에 대한 유휴 자동 종료 기능을 공식 문서에서 제공하지 않으므로, 작업 완료 후 API 또는 명령줄 도구로 삭제하는 정리 절차가 필요하다.

가격보다 실행 완료가 중요한 6시간 재검증에서는 `verified`, 신뢰도 99.5% 이상, 남은 임대 가능 시간 12시간 이상, 충분한 저장 장치 속도와 송수신 속도를 만족하는 일반 임대 매물만 선택하는 것이 안전하다.
중단 가능 매물은 시드나 폴드 단위 재개 기능을 구현한 뒤에만 선별 실험 후보로 다시 검토할 수 있다.

### Lambda Cloud

Lambda Cloud의 단일 GPU 가격은 RTX 6000 시간당 $0.69, A10 시간당 $1.29, A6000 시간당 $1.09다.
A10을 기준으로 2시간은 $2.58, 6시간은 $7.74다.
분 단위로 과금하며, 인스턴스가 상태 점검을 통과한 시점부터 종료할 때까지 유휴 여부와 관계없이 계속 과금된다.

Lambda Cloud에는 인스턴스를 일시 정지하는 기능이 없다.
실행을 멈추려면 인스턴스를 종료해야 하며, 이때 로컬 데이터가 사라지므로 외부 저장소나 별도 파일 시스템에 결과를 보존해야 한다.
연결된 파일 시스템은 인스턴스를 종료해도 시간 단위 저장 비용이 계속 발생한다.
문서상 특정 GPU가 모든 지역에 있는 것은 아니며, 실제 가용 종류는 실행 마법사나 API에서 확인해야 한다.

선결제 잔액은 필요 없고 주간 사용분을 청구하지만, 카드를 등록할 때 환불되는 $10 사전 승인이 발생한다.
한국과 일본은 공식 지원 결제 지역에 포함된다.
안정적인 일반 가상 장비라는 장점은 있지만 이번 예산과 짧은 실험에는 Runpod이나 Vast.ai보다 비싸므로, 두 핵심 후보의 재고가 없을 때만 보조 후보로 유지한다.

출처: [Lambda Cloud 가격](https://lambda.ai/instances), [분 단위 과금](https://docs.lambda.ai/public-cloud/billing/), [인스턴스 일시 정지 불가](https://docs.lambda.ai/public-cloud/on-demand/creating-managing-instances/), [지역별 가용성](https://docs.lambda.ai/public-cloud/on-demand/), [결제 설정과 지원 지역](https://docs.lambda.ai/public-cloud/manage-billing/).

### Paperspace

Paperspace의 유료 A4000 Machine은 시간당 $0.76이고 기본 저장 공간은 50 GB다.
계산 자원은 장비가 켜져 있을 때만 시간 단위로 과금되고, 장비를 끄면 계산 과금은 멈춘다.
그러나 50 GB 저장 공간은 장비가 꺼져 있어도 시간당 $0.0074, 월 최대 $5가 계속 과금된다.

Paperspace Machine은 1시간에서 1주일 사이의 유휴 자동 종료 시간을 설정할 수 있다.
Linux 장비는 사용자가 연결되어 있어도 정해진 유휴 시간이 지나면 종료되므로, 장시간 계산에서는 이 기능을 끄거나 실험 시간보다 넉넉하게 설정해야 한다.
유료 장비의 재고가 없으면 사용할 수 없고, 고급 GPU는 계정 승인이 필요할 수 있다.

Gradient Pro는 월 $8이며 무료 A4000 Notebook을 포함한다.
그러나 무료 장비의 자동 종료 상한은 6시간이고, 타이머는 노트북을 시작한 순간부터 흐른다.
6시간 재검증은 환경 준비 시간과 결과 저장 시간을 포함하면 이 상한을 넘으므로 완료를 기대할 수 없다.
무료 GPU는 수요가 많고 재고가 없으면 기다려야 하므로, Gradient Pro는 2시간 선별 실험의 보조 수단으로만 적합하다.

Paperspace는 저장 공간과 자동 종료 기능이 잘 정리되어 있지만, 유료 A4000의 6시간 계산 비용 $4.56은 Runpod A5000의 $1.62보다 약 2.8배 높다.
따라서 기존 Paperspace 작업 환경을 재사용할 이유가 없다면 새로 선택할 우선순위는 낮다.

## 권장 운영안

1. Runpod에 최소 충전액인 $10를 넣고 RTX A5000 일반 임대 Pod에서 실제 2시간 실험 하나를 실행해 처리 시간과 GPU 메모리 사용량을 측정한다.
2. RTX A5000의 실제 시간이 T4와 비슷하거나 더 짧으면 Runpod을 6시간 재검증의 주 환경으로 확정한다.
3. RTX A5000 재고가 없으면 Runpod L4나 A4000 계열 일반 임대 Pod를 선택한다.
4. Runpod 전체 재고가 부족하면 Vast.ai에서 검증된 고신뢰 호스트의 RTX A4000, RTX A5000, RTX 3090 일반 임대 매물을 고른다.
5. Colab 무료 또는 Pro는 GPU가 잡힐 때 2시간 선별 실험을 병렬로 보내는 보조 환경으로만 사용한다.
6. 모든 SSH 기반 원격 실행은 `tmux` 또는 `screen` 안에서 시작하고, 결과와 로그를 외부 저장소에 복사한 뒤 인스턴스를 종료하는 정리 명령을 실행한다.
7. 계정 잔액 부족 중단을 막기 위해 Runpod과 Vast.ai에 저액 자동 결제와 사용 알림을 설정하되, 월 사용 한도는 별도 감시 명령으로 지킨다.
8. 시드 또는 폴드 단위 재개 기능이 생기기 전에는 어떤 서비스에서도 선점형 상품을 사용하지 않는다.

이 운영안은 장기 약정 없이 월 5만 원 안에서 충분히 수행할 수 있다.
Colab Pro는 주 실행 환경이 아니라 노트북 편의성을 위한 선택이므로, Runpod 시험 실행 뒤에도 브라우저 노트북이 실제로 필요할 때만 결제하는 편이 합리적이다.
