# 결측 증강 후보의 후보 풀 기여 판정

이 문서는 [통과한 결측 증강 후보의 후보 풀 기여를 판정한다](https://github.com/tmheo/predicting-smartphone-addiction/issues/503)의 동결 입력, 중첩 OOF 비교, 중복 처리와 등록 결과를 기록한다.

## 결론

결측 증강 평균본은 일반 추가에서 중첩 OOF AUC `+0.000021787808`, 기존 `exp117_ag25_gbm_r21`과의 원자 교체에서 `+0.000019363665`의 양의 기여를 냈다.
두 비교 모두 바깥 분할 `5/5`, `5/5`가 양수였다.
두 차이는 성능 동등 대역 상한 `+0.000027669802` 이내이므로 경계 기여다.
후보는 기존 구성원 한 건과만 중복됐고 원자 교체 뒤 남은 구성원과의 최대 상관이 문턱 아래이므로 후보 풀에 지속 등록했다.
현재 313개 제출 결합과 제출물은 변경하지 않았다.

## 결과 확인 전 동결

동결 기록은 커밋 `185d985cdaf680ecd5fe9d8939fec8e8d0902c84`에서 먼저 확정했고 파일 SHA-256은 `28aeb93fabd1971eaa5bf00f203ac354a3298a248885df43051d4d0112516a0b`다.

학습은 `2026-08-28T20:26:36.318000+00:00`부터 `2026-08-28T21:56:16.891000+00:00`까지 수행됐다.
실행 산출물 `19`개의 전체 목록 해시는 `9db0615952f4303c344aea616c4f78267a12282cb237630b0253c898299517fe`다.

## 자격 검사

후보는 완료 상태, 난수 42·43·44 평균본, 깨끗한 실행 커밋, 입력 및 분할 해시 일치, 학습 행 무결성과 목표값 부호화 카나리아 검사를 모두 통과했다.
