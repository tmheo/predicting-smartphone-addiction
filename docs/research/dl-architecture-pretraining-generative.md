# 사전학습·자기지도·생성형 표 자료 계열의 실행 후보 조사

## 조사 범위와 결론

이 문서는 2026년 8월 15일을 기준으로, 현재 챔피언인 Lookup Transformer를 넘어설 가능성이 있거나 서로 다른 오차를 제공할 수 있는 사전학습·자기지도·생성형 표 자료 모형을 조사한다.
이번 조사는 논문, 공식 저장소, 공식 모형 배포 페이지, 공식 라이선스만 기술 근거로 사용했으며 실제 모형 실행이나 유료 GPU 사용은 하지 않았다.
현재 챔피언은 `exp067_lookup_xgb_impute_comps5`이고, 3개 시드의 고정 5분할 OOF AUC 평균은 `0.9690978395195489`이다.
이 계열에서 바로 실행할 후보는 1순위 TabICLv2와 2순위 TabDPT-Turbo이다.
TabSTAR와 T-JEPA는 각각 자료 열 이름의 의미 활용과 같은 자료 안에서의 자기지도 학습이라는 차별성은 있지만, 현재 자료와 실행 제약에 대한 직접 근거가 부족하므로 관찰 후보로 둔다.
TabDiff, TabSyn, TabRep 같은 생성형 표 자료 모형은 합성 자료 품질과 결측값 복원이 주된 검증 대상이어서, 69만 행의 완전 지도학습 문제에서 챔피언 교체 실험으로 올릴 근거가 부족하다.
따라서 이 조사 계열의 실행 결정은 `TabICLv2 실행`, `TabDPT-Turbo 실행`, `TabSTAR 관찰`, `T-JEPA 관찰`, `생성형 증강과 구형 자기지도 계열 제외`로 요약한다.

## 판단 기준

자료는 약 69만 행과 12개 공통 입력 열로 구성되며, 수치형과 범주형이 섞여 있고 결측값이 존재한다.
모든 판단은 저장소의 고정 5분할 OOF를 유지하고, 선별 단계에서는 시드 42를 사용하며, 확인 단계에서는 시드 42, 43, 44를 사용하는 규약을 따른다.
챔피언 교체 후보는 선별 단계에서 같은 시드 챔피언보다 낮지 않아야 하고, 확인 단계에서 평균 AUC가 최소 `0.0001` 높아야 하며, 3개 시드 중 2개 이상에서 이겨야 한다.
개선 폭이 `0.0001` 이상 `0.0002` 미만이면 5개 분할 중 3개 이상에서도 이겨야 한다.
다양성 후보는 3개 시드 평균이 챔피언보다 `0.01` 이내이고, 표준 순위 평균 앙상블에 실제 양의 기여를 해야 한다.
예측 순위의 Spearman 상관계수가 `0.998` 이상이면서 AUC도 낮은 후보는 중복 후보로 제거한다.
초기 실행 후보는 단일 16GB에서 24GB GPU와 약 24 GPU시간 안에서 판정 가능해야 한다.
사전학습 가중치를 쓰는 후보와 현재 대회 자료로 새로 자기지도 학습하는 후보를 구분했으며, 후자는 매 외부 분할의 학습 부분에서만 표현을 학습해야 한다.
공개 점수는 후보 채택 기준으로 사용하지 않는다.

## 실행 후보 1: TabICLv2

### 기술 근거

[TabICLv2 논문](https://arxiv.org/abs/2602.11139)은 합성한 수백만 개의 표 자료 과제로 사전학습한 문맥 내 학습 모형을 제안한다.
사전학습 자료가 공식 합성 생성기의 출력이므로, 제3자 실제 표 자료 묶음의 개별 라이선스를 제출 과정에서 다시 추적해야 하는 부담이 없다.
이 모형은 각 열의 분포를 읽어 열 표현을 만드는 단계와, 학습 행을 문맥으로 삼아 질의 행의 값을 예측하는 행 단위 Transformer 단계를 결합한다.
두 단계 구조는 열 안의 값 분포와 행 사이의 관계를 서로 다른 축에서 처리한다는 점에서, 각 값을 토큰화해 감독학습하는 Lookup Transformer와 다르다.
[공식 저장소](https://github.com/soda-inria/tabicl)는 TabICLv2가 사전학습 때 300행에서 4만 8천 행, 2열에서 100열 범위의 과제를 보았고, 일부 60만 행 자료에서도 잘 작동했다고 설명한다.
공식 저장소는 CPU나 디스크로 중간 결과를 옮기는 기능을 이용하면 50만 행을 처리할 수 있고, 최신 GPU에서는 100만 행 추론도 가능하다고 설명하지만, 행 수가 사전학습 범위를 크게 넘으면 정확도가 낮아질 수 있다고 함께 경고한다.
논문이 제시한 계산량은 행 수에 대한 제곱 항과 열 수에 대한 항을 포함하므로, 12열이라는 좁은 폭은 유리하지만 69만 행의 문맥 처리는 반드시 실제 측정으로 확인해야 한다.
공식 구현은 수치형 결측값을 평균으로 채우고 범주형 결측값은 별도 범주로 보존한다.
공식 구현은 `predict_proba`를 제공하므로 기존 OOF 확률 예측과 순위 평균 앙상블에 바로 연결할 수 있다.
[코드와 공식 가중치](https://huggingface.co/jingang/TabICL)는 BSD 3-Clause 라이선스로 공개되어 있고 별도 접근 승인이 필요하지 않다.

### 이 자료에서의 실행 경로

첫 진단은 시드 42의 첫 번째 외부 분할 하나에서 원래 12개 열만 사용해 실행한다.
외부 학습 부분 약 55만 2천 행 전체를 문맥으로 제공하고, 공식 구현의 자동 CPU·디스크 이동 기능을 켠 상태에서 검증 부분 약 13만 8천 행을 예측한다.
가장 작은 속도·메모리 확인은 추정기 하나로 시작하고, 통과하면 공식 기본값인 8개 추정기로 같은 분할을 다시 확인한다.
이 비교에서는 공식 전처리 그대로의 입력을 먼저 사용해, 기존 복원·재구성 파생 열의 효과와 모형 계열의 효과가 섞이지 않게 한다.
공식 결측값 처리가 단순 평균 대체이므로 전체 AUC와 함께 결측 행과 완전 행의 AUC를 따로 기록한다.
결측 행에서만 명확하게 약하면 두 번째 진단에서 챔피언의 복원·재구성 파생 열 묶음을 추가하되, 새 열의 검증 이득이 임의 위약 열보다 커야 한다.
테스트 자료는 외부 분할의 학습, 전처리 적합, 문맥 구성에 사용하지 않는다.

### 판정과 중단 기준

한 분할 진단에서 GPU 메모리 부족을 CPU·디스크 이동으로도 해소하지 못하면 즉시 중단한다.
한 분할의 측정값으로 전체 시드 42 고정 5분할 실행이 24 GPU시간을 넘을 것으로 예상되면 즉시 중단한다.
추정기 8개의 같은 분할 AUC가 같은 분할의 시드 42 챔피언보다 낮고, 결측 행과 완전 행 어느 쪽에서도 보완 신호가 없으면 전체 선별로 확장하지 않는다.
속도 제약을 통과하고 같은 분할 차이가 0 이상이면 시드 42의 고정 5분할 OOF로 확장한다.
전체 선별에서 챔피언보다 낮더라도 차이가 `-0.01` 이내이면 예측 상관과 표준 순위 평균 앙상블 기여를 계산해 다양성 후보 여부를 판정한다.
TabICLv2는 합성 과제 사전학습과 두 축 처리가 Lookup Transformer, TabM, TabPFN-3 모두와 달라 챔피언 교체 가능성은 중상, 다양성 가치는 중간으로 판단한다.
TabPFN-3와 같은 문맥 내 학습 계열이라는 공통점 때문에, 다양성 가치는 반드시 OOF 예측 상관과 앙상블 기여로 확인해야 한다.

## 실행 후보 2: TabDPT-Turbo

### 기술 근거

[TabDPT-Turbo 논문](https://arxiv.org/abs/2608.01400)은 1,445개의 정제·중복 제거된 OpenML 자료에서 약 3억 990만 행과 56억 개의 셀을 사용해 자기지도 방식으로 사전학습한 행 중심 문맥 내 학습 모형을 제안한다.
논문과 [공식 학습 저장소](https://github.com/layer6ai-labs/TabDPT-training)는 자료 수집·제외 절차를 공개하지만 1,445개 자료의 개별 이용 조건을 하나의 검증된 라이선스 목록으로 제공하지는 않는다.
사전학습 과제는 실제 표에서 목표 열을 고르고 일부 행을 문맥으로 제공한 뒤 나머지 행의 목표값을 예측하는 방식이다.
TabDPT-Turbo는 검색 단계를 제거하고, 문맥 행과 사고용 학습 토큰을 이용해 질의 행을 예측한다.
논문은 최대 3만 2천 문맥 행으로 사전학습했고 검색 없이 10만 문맥 행까지 평가했으며, H100에서 기본 8회 예측 기준으로 1천 행당 적합 약 0.44초와 예측 약 0.19초를 보고한다.
이 속도 수치는 H100 기준이므로 16GB에서 24GB 임대 GPU의 실행 시간으로 그대로 옮겨서는 안 된다.
[공식 저장소](https://github.com/layer6ai-labs/TabDPT-inference)는 문맥 크기, 반복 예측 횟수, 배치 크기를 조절할 수 있고, 더 작은 문맥을 요청하면 균형 표본 추출이나 단순 표본 추출을 사용할 수 있다.
공식 구현은 수치형 결측값을 평균으로 채우며 선택적으로 결측 여부 열을 추가할 수 있다.
공식 구현은 `predict_proba`를 제공하므로 현재 평가 절차와 호환된다.
[코드와 공식 가중치](https://huggingface.co/Layer6/TabDPT)는 Apache 2.0 라이선스로 공개되어 있고 별도 접근 승인이 필요하지 않다.

### 이 자료에서의 실행 경로

외부 학습 부분 약 55만 2천 행은 논문이 평가한 10만 문맥 행보다 크므로, 전체를 한 번에 넣는 실행을 기본 경로로 삼지 않는다.
권장 경로는 각 외부 학습 부분을 계층 비율을 보존한 약 3만 1천 행 크기의 18개 고정 조각으로 나누고, 각 조각을 한 번씩 문맥으로 사용해 같은 검증 행을 예측한 뒤 확률을 평균하는 방식이다.
이 조각 평균 경로는 논문이 직접 평가한 설정이 아니라, 이 문서가 전체 자료 사용과 메모리 제약을 함께 만족시키기 위해 제안하는 실행 설계이다.
이 크기는 사전학습에서 본 최대 문맥 길이에 가깝고, 모든 외부 학습 행을 정확히 한 번 사용하며, 검색 자료 구조를 별도로 만들지 않는다.
조각은 외부 분할과 시드에서 결정적으로 생성하고, 검증 행이나 테스트 행의 목표값과 입력 분포를 이용해 선택하지 않는다.
첫 진단은 시드 42의 첫 번째 외부 분할에서 조각 2개 또는 3개만 사용하고 반복 예측 횟수를 1로 둔다.
이 작은 진단은 채택 판정이 아니라 메모리·시간과 조각 추가에 따른 AUC 방향을 확인하는 용도이다.
첫 진단이 통과하면 같은 분할의 18개 조각 전체로 확장해 확률 평균이 안정되는지와 조각 수에 따른 AUC 곡선을 기록한다.
논문의 H100 처리율을 단순 대입하면 18개 조각이 같은 검증 부분을 한 번씩 예측하는 시간은 한 분할에서 약 8분이지만, 이 값은 16GB에서 24GB GPU의 배치·메모리 이동 비용을 반영하지 않은 낙관적 하한이다.
원래 12개 열과 공식 평균 대체를 기본으로 사용하고, 결측 여부 열은 한 분할에서만 분리된 소규모 비교로 확인한다.
기존 조사에서 원래 결측 여부 자체의 목표 신호가 약했으므로, 결측 여부 열을 기본 구성에 자동으로 넣지 않는다.

### 판정과 중단 기준

조각 하나가 16GB에서 24GB GPU에 들어가지 않거나, 조각 크기를 줄였을 때 한 분할 전체 실행이 24 GPU시간 제약을 넘길 것으로 예상되면 중단한다.
조각 2개 또는 3개까지 늘려도 AUC가 개선되지 않거나 예측 분산이 줄지 않으면 18개 전체로 확장하지 않는다.
18개 조각의 같은 분할 결과는 같은 분할의 시드 42 챔피언과 기존 TabPFN-3 OOF를 기준으로 비교한다.
18개 조각의 같은 분할 결과가 챔피언보다 낮고 표준 순위 평균 앙상블에도 기여하지 않으면 전체 선별로 확장하지 않는다.
같은 분할 차이가 0 이상이거나 챔피언 대비 `-0.01` 이내에서 분명한 앙상블 기여가 있으면 시드 42의 고정 5분할 OOF로 확장한다.
TabDPT-Turbo는 실제 표 자료 자기지도 사전학습, 행 중심 긴 문맥, 조각별 독립 문맥 평균이라는 점에서 합성 과제 중심 TabPFN-3와 TabICLv2, 값 토큰 중심 Lookup Transformer, 감독학습 매개변수 앙상블인 TabM과 모두 다르다.
따라서 챔피언 교체 가능성은 중간, 다양성 가치는 중상으로 판단한다.

## 관찰 후보 1: TabSTAR

[TabSTAR 논문](https://arxiv.org/abs/2505.18125)은 390개의 실제 표 자료로 사전학습하고, 열 이름과 목표 이름을 값 표현에 함께 넣어 의미를 활용하는 모형을 제안한다.
사전학습 묶음은 OpenML과 Kaggle을 포함한 여러 공개 출처에서 모았지만, 논문은 모든 원자료의 개별 라이선스를 하나의 검증 목록으로 제공하지 않는다.
수치형 값은 분위수 구간을 문장으로 표현한 정보와 표준화한 숫자 표현을 함께 사용하고, 범주형 값은 열 이름과 값의 텍스트 표현을 사용한다.
사전학습 뒤에는 LoRA로 일부 매개변수만 조정하며, 논문 설정은 약 4,726만 개 매개변수 중 약 160만 개를 학습한다.
공식 구현은 결측값을 `Unknown Value`로 표현하고 수치 경로에는 평균 대체를 적용한다.
[공식 저장소](https://github.com/alanarazi7/TabSTAR)는 MIT 라이선스이고, [공식 가중치](https://huggingface.co/alana89/TabSTAR)는 CC BY 4.0 라이선스로 공개되어 있으며, 기반 텍스트 부호화기인 [e5-small-v2](https://huggingface.co/intfloat/e5-small-v2)는 MIT 라이선스이다.
이 대회의 열 이름과 목표 이름은 의미가 있지만 자유 서술형 열은 없으므로, 논문의 가장 강한 장점이 그대로 재현된다고 보기 어렵다.
논문도 매우 큰 자료에서는 여전히 경사 상승 나무 계열과 차이가 남을 수 있음을 보여 주므로, 현재는 실행 후보보다 관찰 후보가 적절하다.
승격을 검토할 때의 최소 진단은 시드 42의 한 분할, 공식 LoRA 설정, 1회에서 3회 학습 주기, 60분에서 120분의 시간 제한으로 원래 12개 열만 학습하는 것이다.
한 분할의 전처리·학습 시간으로 5분할이 24 GPU시간을 넘거나, 챔피언보다 낮고 예측 상관이 `0.998` 이상이면 중단한다.
이 후보의 챔피언 교체 가능성은 중하, 자유 서술형 자료가 없는 상태에서의 다양성 가치는 중간으로 판단한다.

## 관찰 후보 2: T-JEPA

[T-JEPA 논문](https://arxiv.org/abs/2410.05016)은 같은 자료의 입력 열을 서로 겹치지 않는 문맥 열과 목표 열로 나누고, 문맥 열에서 목표 열의 잠재 표현을 예측하도록 사전학습한다.
목표 표현을 만드는 모형은 지수 이동 평균으로 갱신하고, 표현 붕괴를 막기 위한 학습 토큰을 사용한다.
논문은 사전학습한 표현이 여러 MLP, ResNet, FT-Transformer, AutoInt 후속 모형을 개선하고 일부 자료에서 경사 상승 나무에 근접한다고 보고한다.
[공식 저장소](https://github.com/jose-melo/t-jepa)는 MIT 라이선스이지만 소수의 지정 자료만 직접 지원하고, 임의의 DataFrame과 결측값을 안정적으로 처리하는 범용 추정기 인터페이스를 제공하지 않는다.
공식 설정은 긴 사전학습과 별도 후속 지도학습을 요구하고, 논문 실험은 A100 40GB에서 수행되었다.
69만 행과 12열 자체는 배치 학습이 가능한 규모지만, 현재 구현을 대회 자료에 맞추는 작업과 표현 붕괴·결측 처리 검증까지 포함하면 16GB에서 24GB GPU와 24 GPU시간 안에 신뢰할 만한 판정을 내리기 어렵다.
임의 자료와 결측값을 지원하는 유지보수된 공식 추정기가 나오고, 24GB 이하 GPU에서 대규모 자료의 실행 근거가 추가될 때 실행 후보로 재검토한다.
이 후보의 장기적 다양성 가치는 높지만 현재 실행 준비도는 낮다.

## 현재 제외하는 후보

### SwitchTab, SAINT, SCARF

[SwitchTab 논문](https://arxiv.org/abs/2401.02013)은 비대칭 자동 부호화기에서 행 쌍의 공통 표현과 개별 표현을 교환하며 학습하고, 그 표현을 XGBoost 입력으로도 사용할 수 있다고 보고한다.
그러나 논문과 연결된 유지보수 중인 공식 구현을 확인하지 못했고, 69만 행의 결측 혼합 자료에서 24 GPU시간 안에 재현할 실행 경로도 제시되지 않았다.
[SAINT](https://arxiv.org/abs/2106.01342)는 행·열 주의집중과 대조·재구성 사전학습을 결합하고, [SCARF](https://arxiv.org/abs/2106.15147)는 무작위 열 오염을 이용한 대조학습을 사용한다.
두 모형은 현재 T-JEPA보다 오래된 자기지도 기준선이고, 이 저장소에서 일반 MLP와 FT-Transformer 계열의 약세를 뒤집을 새로운 대규모·결측 자료 근거가 없다.
따라서 SwitchTab, SAINT, SCARF는 이번 실행 목록에서 제외한다.

### TabDiff, TabSyn, TabRep, D2R2

[TabDiff](https://openreview.net/forum?id=swvURjrt8z)는 혼합 자료형을 위한 연속시간 확산 모형과 열별 학습 잡음 일정을 사용하며, [공식 구현](https://github.com/MinkaiXu/TabDiff)은 조건부 결측값 대체도 지원한다.
[TabSyn](https://arxiv.org/abs/2310.09656)은 변분 자동 부호화기의 잠재 공간에서 확산을 수행하고, [공식 구현](https://github.com/amazon-science/tabsyn)은 Apache 2.0 라이선스로 공개되어 있다.
[TabRep](https://openreview.net/forum?id=yRbtFEh2OP)은 확산 모형의 연속 표현을 표 자료 합성에 사용하고, [공식 구현](https://github.com/jacobyhsi/TabRep)을 제공한다.
[D2R2](https://openreview.net/forum?id=lS9e36lkxG)는 소량 표본에서 확산 모형으로 표현을 학습하는 데 초점을 둔다.
이 네 계열의 주된 검증 목표는 합성 품질, 결측값 대체, 소량 표본 표현이며, 69만 개의 목표값이 있는 이진 분류에서 직접 지도학습 모형의 OOF AUC를 높인다는 근거가 부족하다.
생성 모형을 외부 학습 부분마다 새로 적합하고 합성 행을 만들면 계산량이 크게 늘고, 생성 품질과 분류 성능 사이에 별도 검증 단계도 필요하다.
전체 학습·테스트 입력으로 생성 모형을 적합하면 현재 저장소의 엄격한 분할 단위 의사결정과도 맞지 않는다.
향후 재검토하더라도 각 외부 분할의 학습 입력에서만 비지도 표현을 만들고 검증 부분에 변환을 적용해야 하며, 합성 자료 추가보다 표현 추가를 먼저 검증해야 한다.
현재는 직접 실행하지 않는다.

### TabFM

[TabFM 공식 저장소](https://github.com/google-research/tabfm)는 코드에 Apache 2.0을 적용하지만, 공개 가중치는 비상업·비운영 용도로 제한한다.
공식 기본 설정은 문맥 행 100개이고 큰 자료에서는 전체 학습 행을 직접 쓰기보다 문맥을 표본 추출한다.
2026년 8월 15일 현재 공식 저장소에서 동료 평가 논문이나 이에 준하는 기술 보고서를 확인하지 못했다.
따라서 근거 부족, 전체 자료 활용 방식의 불일치, 가중치 사용 조건 때문에 제외한다.

## 라이선스와 대회 규칙 확인

TabICLv2는 코드와 가중치가 BSD 3-Clause이고, TabDPT는 코드와 가중치가 Apache 2.0이며, 두 공식 배포 페이지 모두 공개 상태이다.
TabSTAR는 코드가 MIT이고 공식 가중치가 CC BY 4.0이므로, 결과물과 실험 기록에서 가중치 출처와 저작자 표시 요건을 지켜야 한다.
코드 라이선스와 가중치 라이선스는 별도로 확인했으며, 코드 라이선스만으로 가중치 이용 조건을 추정하지 않았다.
TabICLv2는 합성 자료로 사전학습했지만, TabDPT와 TabSTAR는 여러 공개 실제 자료로 사전학습했으므로 가중치 이용 허가와 별개로 대회가 요구하는 외부 자료 공개성과 접근성 조건을 확인해야 한다.
TabDPT와 TabSTAR의 논문·공식 저장소만으로는 모든 원자료의 개별 라이선스 감사를 끝낼 수 없었으므로, 이 항목은 실행 전 확인 조건으로 남긴다.
실행 직전에는 [이 대회의 공식 규칙 페이지](https://www.kaggle.com/competitions/playground-series-s6e8/rules)에서 외부 자료와 사전학습 모형 조항을 다시 확인해야 한다.
공개·무상 가중치라는 사실만으로 특정 대회 규칙의 허용을 단정하지 않는다.
후보 모형의 확률 출력 자체에는 확인된 별도 제한이 없지만, 제출물 공유나 모형 재배포는 각 가중치 라이선스 범위 안에서 처리해야 한다.

## 권장 실행 순서

1. 대회 규칙의 외부 자료·사전학습 모형 조항과 사용할 가중치의 공개 접근 상태를 실행 당일 다시 확인한다.
2. TabICLv2의 한 분할 메모리·시간 진단과 같은 분할 AUC 비교를 먼저 수행한다.
3. TabICLv2가 통과하면 시드 42의 고정 5분할 선별과 OOF 상관·앙상블 기여 평가를 수행한다.
4. TabDPT-Turbo의 2개 또는 3개 문맥 조각 진단으로 시간과 조각 수 증가에 따른 AUC 방향을 확인한다.
5. TabDPT-Turbo가 통과하면 18개 문맥 조각의 한 분할 확인 뒤 시드 42 고정 5분할로 확장한다.
6. 두 후보 중 하나라도 선별 기준을 통과하면 시드 42, 43, 44 확인 단계와 챔피언 교체·다양성 계약을 적용한다.
7. 두 후보가 모두 실패한 경우에도 TabSTAR나 T-JEPA를 자동 승격하지 않고, 유지보수 상태와 새 대규모 근거가 생겼는지 다시 조사한다.

## 최종 결정

TabICLv2는 전체 학습 행을 문맥으로 쓰는 공식 경로와 결측 처리, 공개 확률 출력, 허용적인 가중치 라이선스가 모두 확인되어 이 조사 계열의 최우선 실행 후보이다.
TabDPT-Turbo는 3만 2천 행 안팎의 결정적 문맥 조각을 평균하는 방식으로 전체 외부 학습 행을 누락 없이 사용할 수 있어, 외부 학습 자료 조건을 재확인한 뒤 실행할 두 번째 후보이다.
두 경로 모두 69만 행에서의 정확한 메모리와 시간은 공식 근거만으로 확정할 수 없으므로, 한 분할의 작은 진단을 통과한 뒤에만 전체 OOF로 확장해야 한다.
TabSTAR와 T-JEPA는 구조적 다양성은 있으나 현재 자료와 실행 제약에서의 직접 근거가 부족하므로 관찰에 남긴다.
생성형 증강과 구형 자기지도 계열은 현재 챔피언 교체 실험으로 실행하지 않는다.
