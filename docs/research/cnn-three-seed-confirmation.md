# CNN 개선안 3시드 짝재검증

이 문서는 [exp131 및 exp132 CNN 개선안의 3시드 짝재검증](https://github.com/tmheo/predicting-smartphone-addiction/issues/303) 결과를 기록한다.
실행 기준일은 2026-08-21이다.

## 재검증 계약

대조군 `exp113_tab_cnn_m0`, 내부 OOF 정확값 목표 평균 팔 `exp131_tab_cnn_oof_target_mean`, 최대 학습 길이 100회 팔 `exp132_tab_cnn_epochs100`을 시드 42, 43, 44와 같은 고정 5개 폴드에서 실행했다.
세 설정의 모형과 특성 명세는 [단일 시드 통제 비교](cnn-oof-target-mean-training-length-controls.md)에서 확정한 값에서 바꾸지 않았다.
목표 평균 팔은 내부 10개 폴드와 평활 계수 `10.0`을 유지했다.
세 설정은 같은 Vast.ai 인스턴스에서 차례로 실행하고 각 설정의 세 시드는 GPU 0, 1, 2에 하나씩 배정했다.

승격 대상은 대조군과의 평균 시드별 짝차이가 양수이고 세 시드 중 적어도 두 시드의 짝차이가 양수인 팔로 한정한다.
표준편차는 세 시드를 모집단으로 본 표준편차로 계산한다.
이 이슈에서는 후보군이나 챔피언 구성을 바꾸지 않는다.

## 처리량 진단

처음 선택한 RTX 4060 Ti 장비 `31607`과 RTX 5080 장비 `137655`는 실제 표 합성곱망의 한 학습 회차가 약 57초와 61초여서 8시간 상한 안에 세 설정을 끝낼 수 없었다.
세 시드 경쟁을 제거한 단일 GPU 검사에서도 RTX 5080 장비는 60.58초가 걸려 시드 병렬화가 주원인이라는 가설을 기각했다.
이전에 빠른 결과를 냈던 GPU 종류를 확인하려고 검사한 RTX A4000 장비 `14335`도 같은 크기 학습 회차가 54.11초였다.
최종 장비의 단일 GPU 기본 설정은 20.55초였고 세 GPU 동시 검사는 21.32초부터 30.19초였다.
세 예측의 SHA-256은 모두 `30e921068e1fad3ef4c327fd28ff72625c217f472f5acd4c91730e55dfba7224`로 같았다.
따라서 처리량 차이는 코드나 시드별 GPU 배정 결함이 아니라 원격 호스트의 CPU와 GPU 조합에 따른 작은 CUDA 연산 발행 처리량 차이로 판정했다.
중단한 두 본 실행에는 완성된 폴드가 없었고 그 결과를 재검증 점수에 사용하지 않았다.

## 학습 길이 팔 복구

학습 길이 팔의 첫 실행은 설정별 10,800초 제한에 도달해 종료 코드 124로 끝났다.
이때 15개 폴드 중 13개가 검증된 복구 산출물과 함께 완료됐고 시드 43과 44의 마지막 폴드만 남았다.
첫 실행 결과 압축 파일은 로그와 13개 복구 산출물을 보존하며 SHA-256은 `92e388de1f4b2736e680019d07dbc13bd0c18306ac88fc89506eec8792214145`, 크기는 107,479,767바이트다.

같은 인스턴스, 실행 커밋, 설정, GPU 배정과 복구 저장소에서 학습 길이 팔만 재개했다.
재개 실행의 원격 MLflow 식별자는 `7aca60a1e54f4980b11a8d4ef39b28d3`이고 완료된 13개 폴드를 재사용해 나머지 2개 폴드만 학습했다.
재개 과정에서 각 폴드의 복구 결과를 읽기 전에 fold-fit 특성을 다시 준비하는 실행 순서를 확인했다.
완료된 폴드도 모형 학습만 건너뛰고 특성 준비는 다시 계산하므로 재개 뒤 첫 새 학습 회차까지 1시간 9분가량 GPU가 유휴 상태였다.
이 분석과 세부 계측 제안은 [fold-fit 피처 준비와 폴드 결과 확정 가속 지도](https://github.com/tmheo/predicting-smartphone-addiction/issues/318#issuecomment-5364168802)에 남겼다.

마지막 두 폴드를 다시 실행하지 않도록 수동 종료 상한을 `2026-08-21T01:50:00Z`에서 `2026-08-21T02:50:00Z`로 연장했다.
실제 Python 실행은 정상 완료했고 시간 제한 감시 프로세스만 수동으로 정리했다.
재개 결과 압축 파일의 SHA-256은 `7dce93c473931c270a84ab5eb1436eb6b961335f1f2a354993cac3fc92e4ef4f`이고 크기는 42,697,370바이트다.
압축 파일 내부의 15개 폴드 복구 산출물과 결과 묶음을 로컬에서 다시 해시 검증했다.
