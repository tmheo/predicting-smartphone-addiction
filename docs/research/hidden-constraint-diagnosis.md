# 숨은 제약과 결측 주입 구조의 진입 진단

이슈 [#88](https://github.com/tmheo/predicting-smartphone-addiction/issues/88)의 측정 기록이다.
[#85의 판별 규약](constraint-and-generation-order-diagnostics.md)을 따라, 채택된 화면 시간 제약 이외에 재현 가능한 숨은 제약이 있는지와 열별 독립 마지막 결측 주입을 반증하는 구조가 있는지를 잰다.
champion과 경쟁하는 실험이 아니라 측정만 하는 진입 진단이며, 재현 스크립트는 `scripts/diagnose_hidden_constraints.py`다.

원본 프록시(jayjoshi37 판본 1, [출처와 사용 조건](original-proxy-data.md))와 대회 train을 각각 발견 50% / 확인 50%로 목표값 층화 분할(시드 88)하고, 대회 test는 목표값 없는 독립 복제 자료로만 쓴다.
식, 허용오차(기계 정밀도 1e-9, 표시 반올림 오차 전파), 계수 집합, 최소 지지 기준은 전부 발견 자료를 보기 전에 스크립트 상수로 고정했고 확인 단계에서 바꾸지 않았다.

## 1. 스키마와 값 눈금의 계보

- **대회가 보존한 눈금**: age(18~35 정수), gaming(0~4.00), sleep(4.50~9.00), notifications(20~250 정수), app_opens(15~180 정수)는 범위, 고유값 수, 0.01 격자가 프록시와 정확히 같다.
- **대회가 넓힌 범위**: daily(프록시 3.00~12.00 → 대회 0.50~15.00), social(0.50~6.00 → 0~8.00), work(0.50~6.00 → 0~6.00), weekend(3.58~14.88 → 0.51~17.56).
  프록시 경계 밖 질량은 daily 아래쪽 4.2%, 위쪽 3.1% 등으로 크고 train 확인과 test에서 같은 크기로 재현된다.
  경계에 값이 쌓이지 않으므로(경계 질량 전부 0.1% 미만) 잘라낸 범위가 아니라 실제로 새 값을 만든 범위다.
- **격자 밖 소수**: train에 daily 3자리 소수 2행(4.518, 4.543)과 weekend 4자리 소수 3행(전부 8.7765), test에 weekend 4자리 1행(8.7769)이 있다.
  전체의 1e-5 이하라 제약 후보가 아니라 생성 잔재 수준의 특이값으로만 기록한다.

## 2. 함수 종속성과 조건부 함수 종속성

12개 설명변수와 목표값의 전 순서쌍(156개)에 대해 발견 자료에서 지지 키(프록시 3행, train 5행 이상) 20개 이상이면서 위반 0인 종속성을 찾았다.

- 프록시와 train 모두 **후보 0개**다.
- 범주 조건(성별, 스트레스, 학업 영향의 각 수준) 안에서만 성립하는 조건부 함수 종속성도 **후보 0개**다.
- 참고로 프록시 전용 열 `addiction_level -> addicted_label`은 결정적이지만(수준별 목표값 고유값 1) 대회 자료에 없는 열이라 계보 단서로만 남긴다.

결정론적 재계산 후보(잔차 0 질량이 기계 정밀도 수준)는 어느 열에서도 성립하지 않는다.

## 3. 작은 산술 문법

수치 9열의 전 수치 관측 행에서 단항(계수배)과 이항(합, 차, 비율, 최소, 최대)을 계수 {-3, -2, -1, -1/2, 1/2, 1, 2, 3}으로 완전 열거했다.

### 사전 등록 시간 예산식: 유일한 실질 제약이며 계보는 대회 신규

`daily - (social + gaming + work)` 잔차의 자료 집합별 요약:

| 집합 | 위반 비율(잔차 < -0.02) | 정확 0 질량 | 최소 | 1% | 중앙값 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 프록시 발견 | 61.0% | 0.05% | -12.36 | -9.13 | -1.08 |
| 프록시 확인 | 60.0% | 0.13% | -11.70 | -9.03 | -0.98 |
| train 발견 | 0% | 0.10% | 0.00 | 0.08 | 0.75 |
| train 확인 | 0% | 0.09% | 0.00 | 0.09 | 0.75 |
| test | 0% | 0.08% | 0.00 | 0.09 | 0.75 |

- **원본 프록시는 이 제약을 전혀 만족하지 않는다**(위반 60%, 잔차가 -12까지 퍼짐).
  대회 train과 test에서만 위반이 정확히 0이다.
  따라서 이 제약의 계보는 `원본 보존`이 아니라 **`대회 신규`**다.
  생성기가 프록시의 공동관계를 학습해서 생긴 규칙일 수 없고, 대회 자료를 만들 때 새로 부여된 구조다.
- 잔차 0.01 격자의 경계 근방 질량은 0.00에서 0.10까지 0.0009 → 0.0017로 완만하게 증가하며 0.00에 쌓임이 없다.
  [#85 결정표](constraint-and-generation-order-diagnostics.md) 기준으로 **값 자르기, 투영, 결정론적 재계산은 반증**되고, 성분 합에 양의 여유분을 더해 daily를 구성했거나 거부 표본 추출을 쓴 후보가 남는다.

### 그 밖의 등식과 부등식: 새 제약 없음

- 표시 허용오차 내 일치 비율 99.9% 이상인 **등식 후보는 0개**다.
- 부등식 후보(한쪽 위반 0.1% 이하이며 경계 근방 질량 0.5% 이상)는 프록시 발견 106개, train 발견 100개가 나왔지만, 대부분 발견 자료의 단변량 [min, max] 상자만으로 함의되는 자명한 관계다.
  예: `age >= 2*sleep_hours`는 age 최소 18과 sleep 최대 9.00이 만드는 범위 함의다.
- 상자 비함의이면서 확인 자료에서 위반 0으로 생존한 train 발견 후보 15개는 쌍별 관측 행 재확인(전 수치 관측 제한을 풀고, min/max가 실제 고른 열의 표시 단위만 오차 전파)에서 두 갈래로 정리된다.
  `min()`에 싸인 `daily >= social`과 `daily >= work` 계열은 재확인에서도 위반 0이지만 예산 부등식의 함의라 새 제약이 아니다.
  `daily <= 3*sleep` 계열은 전 수치 관측 행 제한과 age 표시 단위(1.0)의 굵은 허용오차가 만든 인공물로, 재확인에서 train 확인 17~19행, test 16~19행이 위반하며 위반 수가 독립 가정 기대치(각각 약 7행) 이상이라 꼬리 회피조차 없다.
  따라서 **예산 부등식과 독립인 새 부등식 제약은 0개**다.

작은 문법이 놓친 잔차 구조가 없어(등식 생존 0, 함수 종속성 0) 기호 회귀 제안 단계는 열 필요가 없었다.

## 4. 조건부 범위

범주 3열의 전 수준과 age 사분위 구간을 조건으로, 발견 자료에서 전역 범위보다 유의미하게 좁은 조건부 [min, max]를 찾아 확인 자료의 범위 밖 비율로 검증했다.

- 프록시 발견에서 좁아 보인 조건 범위 12개는 전부 weekend 한 열에 몰려 있고, train 확인과 test에서 2.4~3.1%가 범위를 벗어난다.
  프록시 3,750행의 표본 극값이었을 뿐 제약이 아니다.
- train 발견에서 좁아 보인 조건 범위 17개도 확인 자료 위반이 0이 아니고(1e-5 수준), 좁아진 폭이 표시 단위 몇 배 이내라 무거운 꼬리의 표본 극값과 구분되지 않는다.
  완전히 정확한 조건부 범위는 없다.

## 5. 결측 마스크: 열별 독립 주입 반증

프록시 설명변수에는 결측이 없으므로 결측은 전부 대회 생성 단계의 산물이다.

- **열별 비율은 train과 test가 다르다**: gaming 18.3% 대 20.1%, social 19.4% 대 16.0%, app_opens 11.7% 대 8.7% 등 최대 3%p 차이가 난다.
- **마스크 쌍 상관은 전부 양수다**: 66쌍 모두 phi > 0, 평균 phi 0.062, 최대 0.276(social~gaming, z=+229). test에서도 같은 구조(최대 0.278)가 재현된다.
- **행별 결측 수는 Poisson-binomial을 크게 벗어난다**: 총변동거리 0.184, 분산비 1.78.
  결측 0개 행이 기대 25.9% 대비 38.9%로 많고(0 팽창), 5개 이상 행이 기대 0.45% 대비 3.0%로 두껍다(무거운 꼬리).
  test도 같다(TV 0.177, 분산비 1.77).
- **교차적합 예측 가능성**: 발견에서 학습해 확인에서 채점한 M_j 예측 AUC는 0.55~0.75로 순열 대조(≈0.50)를 크게 넘고 test에서도 재현된다.
  단, **다른 열의 마스크만으로 예측해도 AUC가 같다**(예: daily 0.754 대 0.754). 관측값과 목표값을 넣어도 오르지 않는다.
- **목표값과는 사실상 독립이다**: 12열의 결측-관측 목표값 비율 차이는 전부 |0.004| 이하(z 최대 2.2, 12개 동시 검정에서 유의하지 않음). Y를 특성에 넣어도 AUC가 변하지 않는다.
- **관측값과의 연결은 age 한 방향만 약하게 있다**: 모든 마스크에서 결측 행의 age가 낮은 쪽으로 표준화 차이 -0.05~-0.08, corr(age, 행별 결측 수) = -0.054로 train과 test에서 같은 방향이다.
  다른 열의 관측값 이동은 이보다 작다.
- id 10분위별 행별 결측 수 평균은 1.25~1.29로 평탄해 생성 순서에 따른 이동은 없다.

판정: **열별 독립 마지막 주입(단순 MCAR)은 반증된다.**
마스크 구조는 행 단위 잠재 결측률(어떤 행은 전반적으로 많이 비는) 공동 과정과 맞고, 그 잠재율이 age와 약하게 연결된다.
값·목표값 조건부 방향(MAR 대 MNAR)은 관측 자료만으로 식별되지 않아 미식별로 남긴다.

## 판정

1. **새 숨은 제약은 없다.**
   함수 종속성 0, 등식 생존 0, 정확 조건부 범위 0이며, 실질 제약은 이미 채택한 화면 시간 예산 부등식 하나뿐이다.
   따라서 **새 제약 표현 실험 트랙은 열지 않는다.** recon 4열(#74)이 이 유일한 제약을 이미 산술 경계로 쓰고 있다.
2. **화면 시간 예산 제약의 계보를 `대회 신규`로 재분류한다.**
   원본 프록시는 이 제약을 60% 위반하므로, 후보 생성 과정(#89)은 프록시 학습만으로 이 제약을 재현할 수 없고 생성 중 구성(성분 합 + 양의 여유분) 또는 거부 표본 추출류의 별도 단계를 가져야 한다.
   자르기, 투영, 재계산 후보는 경계 질량 부재와 함수 종속성 부재로 반증되었다.
3. **열별 독립 결측 주입은 반증되지만, 공동 결측 복원 실험 트랙은 열지 않는다.**
   마스크 간 의존은 강해도 목표값과 관측값(약한 age 연결 제외)에 사실상 독립이라, 마스크 구조를 예측 표현으로 옮겨 얻을 신호가 없다.
   마스크만으로 낸 AUC와 값·목표값을 더한 AUC가 같다는 측정이 그 근거다.
   현행 결측 가정(원시 NaN 유지 + 예산 제약 기반 recon)은 유지한다.
4. **#89로 넘기는 제약 조건**: 후보 생성 과정의 결측 재현은 열별 독립 Bernoulli가 아니라 행별 잠재 결측률(0 팽창과 무거운 꼬리, train/test 별도 비율, age 약한 연결)을 재현해야 하고, 목표값·제약 재현은 예산 부등식을 프록시에 없던 신규 구조로 만들어야 한다.
