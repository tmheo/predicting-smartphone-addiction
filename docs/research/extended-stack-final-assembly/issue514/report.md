# 이슈 514 전체 자료 재학습, 최종 조립과 제출 기록

## 결론

공식 풀 36개의 전체 자료 재학습 시험 예측과, 같은 자체 예측에 동결 외부 OOF 278개를 붙인 314개 확장 결합 예측을 각각 Kaggle에 제출했다.
사용자가 말한 전체 재학습은 학습 자료 전체를 사용한 적합을 뜻하며, 교차 검증 분할별 시험 예측의 평균을 뜻하지 않는다.
두 제출의 OOF AUC와 Public AUC는 각각 같은 MLflow 실행에 기록했다.

| 구성 | MLflow 실행 | 중첩 OOF AUC | Kaggle 제출 | Public AUC |
| --- | --- | ---: | ---: | ---: |
| 공식 풀 36개 전체 자료 재학습 | `223055f44dc9427da588a141bc3b1ca3` | `0.9698828758140019` | `55907601` | `0.97101` |
| 자체 36개 전체 자료 재학습 + 외부 278개 | `3279e114ef444cfeaff4232bc401d7b4` | `0.9703843058098193` | `55907610` | `0.97135` |

## 직전 확장 결합 제출과 비교

이슈 489의 313개 확장 결합 제출 `55844886`은 OOF AUC `0.9703608940404231`, Public AUC `0.97135`였다.
이번 314개 확장 결합은 OOF AUC가 `0.0000234117693961` 높지만 Public AUC는 같은 `0.97135`다.
따라서 이번 변경이 공개 자료 성능을 높였다는 근거는 없다.

두 시험 예측의 Spearman 순위 상관계수는 `0.9993173362920516`이다.
296,302개 행에서 순위 이동의 중앙값은 `1,433`, 95백분위는 `6,938.95`, 최댓값은 `27,618`이었다.
제출 파일은 서로 다르지만 예측 순위의 대부분이 매우 비슷하고, 작은 OOF 상승폭이 공개 점수 상승으로 이어지지 않은 결과다.
전체 자료 재학습 예측과 교차 검증 분할별 시험 예측 평균은 학습 절차가 다르므로, OOF에서 관측한 차이가 시험 자료에 그대로 이전된다고 볼 수도 없다.
Public AUC는 소수점 다섯 자리로 표시되므로 이 결과만으로 표시 단위보다 작은 차이의 방향을 판정할 수 없다.

## 전체 자료 재학습

공식 풀과 재학습 계획의 SHA-256은 각각 `40947563a00cab8212498c7e339517e387979b14c6477c6ce8e196036e02044c`와 `89edf321b1821f1de645799f2353705c461065a275263375d5479e3edd6b006c`다.
구성원 항목이 바뀌지 않은 29개는 이미 검증된 전체 자료 재학습 예측을 구성원 항목 해시로 다시 확인해 재사용했다.
새로 들어오거나 교체된 다음 7개는 학습 자료 전체로 다시 적합했다.

- `mpv1_exp035_lattice_te_missingness_augmented`
- `mpv1_exp058_logreg_onehot_missingness_augmented`
- `mpv1_exp070_cat_exact_cats_missingness_augmented`
- `mpv1_exp110_lgb_kitopl_no_te_missingness_augmented`
- `mpv1_exp131_lookup_bivariate_plr5_missingness_augmented`
- `exp208_issue500_ag25_missingness_augmented`
- `exp209_issue505_lgb_lr_onehot_init`

신경망인 `mpv1_exp131_lookup_bivariate_plr5_missingness_augmented`는 사용자 지시대로 Vast.ai에서 시드 42, 43, 44를 GPU 세 장에 나눠 전체 자료로 학습했다.
나머지 새 구성원은 로컬에서 전체 자료로 학습했다.
표준 `pipeline.refit --assemble`은 36개 구성원 산출물의 설정, 입력, 계보, 예산, 시드와 예측 해시를 모두 확인한 뒤 전체 자료 전용 제출을 만들었다.

## 결정적 조립

첫 제출은 공식 풀 36개의 전체 자료 재학습 시험 예측에 등록 결합 방식 `shrunk_rank_logit_logistic`을 적용한 표준 `submission_full.csv`다.
선택된 수축 계수는 `1.0`이다.
두 번째 제출은 같은 자체 36개 전체 자료 예측과 동결 외부 278개의 교차 검증 분할 평균 시험 예측을 붙이고, 이슈 513에서 통과한 314열 OOF에 C 선택 결합기를 한 번 적합해 만들었다.
선택값은 `C=0.03`, `lambda=1.0`이다.

조립은 서로 다른 새 과정과 새 출력 폴더 `assembly-a`, `assembly-b`에서 두 번 실행했다.
두 CSV, 전체 조립 manifest와 체크섬 파일은 모두 바이트 단위로 같았다.
조립 manifest SHA-256은 `7f3179e577748dda1ea5b36a498d07a7a01a9b120f8e00e64a10099502e51495`다.
36개 풀 CSV는 표준 전체 자료 재학습 제출 파일과도 바이트 단위로 같다.

초기 조립 검사에서 표준 CSV를 다시 읽을 때 생기는 최대 `1.1102230246251565e-16`의 마지막 자리 차이를 발견했다.
순위는 전 행에서 같았고, 최종 36개 풀 제출은 표준 CSV 바이트를 그대로 보존하도록 고쳤다.
외부 장부의 `test_sha256`은 파일 바이트가 아니라 예측 배열의 의미 해시라는 기존 계약도 확인해, 의미 해시는 동결값과 비교하고 실제 원본 파일 해시는 별도 정보로 기록했다.
배열 선택자가 붙은 외부 경로는 기본 파일과 선택자를 분리해 원본 파일 해시를 계산했다.
수정 뒤 외부 구성원 278개의 OOF와 시험 예측 의미 해시를 전부 다시 확인했다.
