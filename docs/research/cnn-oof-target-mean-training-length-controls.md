# CNN OOF 목표 평균과 학습 길이 단일 변화 통제

이 문서는 [exp113 CNN의 입력 축과 학습 길이 축 통제 비교](https://github.com/tmheo/predicting-smartphone-addiction/issues/285)의 실행 결과다.
실행 기준일은 2026-08-20이다.

## 결론

`exp113_tab_cnn_m0` seed 42의 OOF AUC `0.9598023679`를 기준으로 두 단일 변화 팔을 같은 Vast.ai RTX A4000에서 비교했다.
내부 OOF 정확값 목표 평균을 추가한 `exp131_tab_cnn_oof_target_mean`은 OOF AUC `0.9674152911`로 `+0.0076129232` 개선됐다.
이 값은 공개 CNN seed 42와 exp113 seed 42의 OOF 격차 `0.0079032656` 가운데 `96.326298%`를 회복하고 `0.0002903424`만 남긴다.

다른 설정을 유지하고 최대 학습 길이만 30회에서 100회로 늘린 `exp132_tab_cnn_epochs100`은 OOF AUC `0.9602845458`로 `+0.0004821779` 개선됐다.
학습 길이 증가는 같은 격차의 `6.100996%`를 회복했다.
따라서 이번 통제 범위에서는 내부 OOF 정확값 목표 평균이 주된 회복 축이고 학습 길이는 양수지만 작은 보조 축이다.

목표 평균 팔의 무작위 위약 목표 평균 특성 `placebo_noise_te`의 평균 순열 중요도는 `0.000004`였다.
이는 원본 무작위 위약 특성 `placebo_noise`의 `0.000050`보다 낮아 목표값 누출 경보를 통과했다.

두 팔 모두 단일 시드에서 기준을 넘었으므로 exp113 대조군과 seeds `[42, 43, 44]`로 짝지어 재검증하는 [후속 이슈](https://github.com/tmheo/predicting-smartphone-addiction/issues/303)를 열었다.
이번 결과만으로 후보군이나 챔피언 구성은 바꾸지 않는다.

## 비교 계약

기준과 두 팔은 학습 자료 691,369행, 고정 5개 폴드, seed 42, 표 합성곱망 구조와 평가 절차를 공유한다.
학습 자료 SHA-256은 `f4669147311c76eb03496061a852af283efcf0f12cf5c19274e775def81edd9c`다.
고정 폴드 SHA-256은 `5f5d09e9356f227ecb4a063270b175bb5cae20afb25636c563db185e18a155c4`다.

목표 평균 팔은 exp113의 33개 입력 뒤에 원시 12열의 정확값 목표 평균과 무작위 위약 목표 평균을 붙여 총 46개 입력을 사용한다.
각 바깥쪽 학습 폴드 안에서 10개 내부 폴드로 학습 행의 목표 평균을 만들기 때문에 한 행의 목표값이 그 행의 입력값 계산에 직접 들어가지 않는다.
평활 계수는 `10.0`이며 바깥쪽 검증 행과 시험 행에는 바깥쪽 학습 폴드 통계만 적용한다.
모형의 최대 학습 길이는 기준과 같은 30회다.

학습 길이 팔은 exp113의 33개 입력을 그대로 사용한다.
유일한 변화는 최대 학습 길이를 30회에서 100회로 늘린 것이다.
검증 AUC 기준 인내 15회의 조기 종료와 나머지 최적화 설정은 바꾸지 않았다.

## 구현

[`ExactValueTargetEncoder`](../../src/pipeline/features.py)는 기본값 `0.0`을 유지하면서 음수가 아닌 유한 실수 평활 계수를 받을 수 있게 확장했다.
양수 평활은 각 정확값 집단의 합과 개수에 학습 부분의 전체 목표 평균을 결합한다.
내부 OOF 학습 행은 각 내부 학습 부분의 전체 평균을 사용하고 바깥쪽 검증과 시험 행은 바깥쪽 학습 폴드의 전체 평균을 사용한다.
기존 평활 없는 호출의 동작은 바뀌지 않는다.

[`exp131_tab_cnn_oof_target_mean.yaml`](../../configs/exp131_tab_cnn_oof_target_mean.yaml)은 목표 평균 팔을 정의한다.
[`exp132_tab_cnn_epochs100.yaml`](../../configs/exp132_tab_cnn_epochs100.yaml)은 학습 길이 팔을 정의한다.
설정 회귀 시험은 두 팔이 선언된 한 축 외에는 exp113과 같고 목표 평균 팔의 무작위 위약 특성이 포함되는지 확인한다.

## 판정 제한

목표 평균 팔은 공개 CNN의 처리 경로 전체를 재현하지 않는다.
공개판의 빈도 특성, 행별 파생 특성, 학습 행 자기 포함 목표 평균, 열 순서와 난수 흐름은 이번 팔에 들어가지 않았다.
따라서 `96.326298%`는 같은 OOF 점수 격차에서 관측한 회복률이지 공개판과 exp113의 모든 차이를 목표 평균 하나에 인과적으로 귀속한 비율이 아니다.

다만 누출을 막은 내부 OOF 목표 평균 한 축만으로 남은 격차가 `0.0002903424`까지 줄었고 다섯 폴드가 모두 같은 높은 범위에 놓였다.
이번 통제 범위에서는 정확값 목표 평균이 가장 강한 구조 차이라는 판정은 충분히 지지된다.
3시드 짝재검증 전에는 이 팔을 후보군이나 챔피언 구성에 넣지 않는다.
