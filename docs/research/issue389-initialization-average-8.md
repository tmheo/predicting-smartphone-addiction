# 초기화 평균 8개 확정 재검증

## 결론

fold 안에서 평균하는 초기화를 3개에서 8개로 늘리면 세 대상의 단독 OOF AUC는 모두 높아졌다.
새 champion `exp156_lookup_bivariate_plr5_initavg8`은 기존 champion보다 `+0.000027877599` 높았고 시드 3/3과 분할 4/5가 개선되어 ADR 0001 계열 1로 교체했다.
후보 풀의 `exp157_lookup_muon_initavg8`은 같은 계보의 `exp127_lookup_muon`을 바꾸는 nested OOF가 `+0.000001362325`여서 원자 교체했다.
`exp158_lookup_fold_initialization_avg8`은 단독 OOF가 `+0.000037316169` 높았지만 최신 후보 풀의 원자 교체 nested OOF가 `-0.000000384843`여서 `exp081_lookup_fold_initialization_avg3`을 유지했다.

| --- | ---: | ---: | ---: | ---: | ---: | --- |
| `exp156_lookup_bivariate_plr5_initavg8` | `0.969339732964` | `0.969367610562` | `+0.000027877599` | 3/3 | 4/5 | champion 교체 |

## 고정 조건과 실행

세 후보는 각 기준 설정에서 이름과 `fold_seed_offsets`만 바꿨다.
초기화 간격은 `[0, 1000, 2000, 3000, 4000, 5000, 6000, 7000]`이고 외부 확인 시드는 `[42, 43, 44]`다.
최종 실행은 커밋 `170b4f4faf50e499e30f78d518276203bc16f12e`와 컨테이너 이미지 `nvcr.io/nvidia/pytorch@sha256:a411b86de9ac003ce5db43894ea7920718512bc02c51a521157c0899aac75631`에서 수행했다.

세 후보는 서로 다른 Vast.ai 인스턴스에서 병렬로 실행했다.
각 인스턴스는 RTX 3090 8장을 사용했고, 같은 인스턴스 안에서도 외부 시드 작업자 3개가 장치 8장을 공유했다.
fold 초기화 구성원 8개는 장치별로 하나씩 학습했고 예측과 중요도 계산도 장치별로 병렬 처리했다.
실제 모델을 사용한 3개 작업자 곱하기 8개 GPU 사전 검사를 세 인스턴스 모두 통과했다.

## 후보 풀 원자 교체

첫 대조는 SHA-256 `e430d32dc6d80b7feb34151ed93d431adc42dc9b61ca344368218768c30fc349`인 33개 후보 풀에서 `exp127`을 `exp157`로 바꿨다.
기준과 교체 뒤의 최선 방식은 모두 `shrunk_rank_logit_logistic`이었고 nested OOF AUC는 `0.969769351339`에서 `0.969770713664`로 높아졌다.
바깥 분할별 차이는 `+0.000002331176`, `-0.000005512058`, `+0.000002407799`, `-0.000005242608`, `+0.000012827432`였으며 3/5가 양수였다.
전체 차이가 엄격히 양수이므로 경계 기여 경고와 함께 교체했다.

두 번째 대조는 첫 교체 뒤 SHA-256 `20e4a3e332e16e886a8b744ad8a7bc5389caa4dcf218845d9281c81dea90faf9`인 최신 33개 후보 풀에서 수행했다.
`exp081`을 `exp158`로 바꾸면 nested OOF AUC가 `0.969770713664`에서 `0.969770328821`로 낮아졌다.
바깥 분할별 차이는 `-0.000004595877`, `-0.000000708893`, `-0.000000338716`, `+0.000000908062`, `+0.000002811242`였으며 2/5만 양수였다.
전체 차이가 0 이하이므로 두 번째 교체를 거절했다.

## 전체 자료 재학습 예산

초기화 8개 평균은 한 외부 시드의 내부 전체 자료 적합 수를 3회에서 8회로 늘린다.
이는 시드당 5회와 `166.7%` 증가이며 확인 시드 3개 전체에서는 채택된 설정 하나당 9회에서 24회로 15회 늘어난다.
새 champion을 단독 경로로 전체 자료 재학습하면 내부 적합이 15회 늘어난다.
후보 풀에서는 `exp157` 한 개만 채택되어 내부 적합이 15회 늘어나며, 후보 풀 구성원 수 33개와 바깥 시드 실행 수 97회는 변하지 않는다.
두 채택 경로를 모두 실제로 실행할 때의 추가 내부 적합은 합계 30회다.

`exp157`의 구조화 진단에는 3시드 곱하기 5분할 곱하기 초기화 8개인 원시 관측 120개가 있다.
시드별 관측 학습 길이 중앙값에 1.25를 곱해 반올림한 전체 자료 재학습 예산은 시드 42, 43, 44에 각각 14, 15, 15다.
후보 풀 해시, 실행 계보, 진단 산출물 해시와 이 예산은 `artifacts/full-refit-plan.yaml`에 반영했다.

## 비용과 정리

Vast.ai 계정 잔액 차감으로 측정한 전체 비용은 `15.267214721`달러다.
세 최종 인스턴스의 개별 기록값은 약 `4.4010`, `5.3538`, `5.3706`달러이며 전체 잔액 차감에는 최종 실행 전 가속 검증 과정도 포함된다.
인스턴스 `48573810`, `48573813`, `48573817`을 모두 삭제한 뒤 목록 부재를 재확인했다.
Vast.ai 작업용 저장 공간은 0개이고 저장소 및 환경의 종료 예약 변수도 모두 빈 목록으로 되돌렸다.
입력과 결과는 SSH 표준 스트림으로만 전송했고 반입 뒤 결과 묶음과 필수 산출물 해시를 다시 검증했다.
