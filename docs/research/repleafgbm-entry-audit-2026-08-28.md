# RepLeafGBM 공개 OOF 진입 진단과 자격 감사

이 문서는 [RepLeafGBM 공개 노트북](https://www.kaggle.com/code/masayakawamata/s6e8-repleafgbm-cv-0-968187)의 저장 실행 결과가 현재 313개 확장 결합에 새 신호를 더하는지 진단하고, 엄격 외부 후보가 될 자격이 있는지 분리해 판정한다.
진입 진단의 양수와 외부 구성원 자격을 같은 결론으로 읽지 않는다.

## 결론

RepLeafGBM 공개 OOF는 현재 313개 결합에 약한 보완 신호를 더했다.
폴드 0·1에서 고른 순위 5% 혼합은 미사용 폴드 2·3·4에서 모두 양수였고 평균 차이는 `+0.0000158`이었다.
따라서 단독 주력 모형으로 다시 학습할 근거는 약하지만, 결측 증강을 적용한 나무 모형의 잔차가 현재 결합과 완전히 같지는 않다는 진입 진단은 통과했다.

그러나 공개 배열은 엄격 외부 후보 자격이 없다.
고정 공개 판본은 같은 바깥쪽 검증 자료의 결과로 잎 모형과 결측 증강 설정을 골랐다고 명시한다.
이는 `CONTEXT.md`의 **검증 가능한 개별 외부 구성원**이 요구하는 설정 선택 격리를 위반한다.
따라서 이 예측 쌍을 다음 외부 후보 동결 명세에 넣거나 엄격 외부 사다리 판정으로 올리지 않는다.

현재 [마감 전 확장 스택 지도](https://github.com/tmheo/predicting-smartphone-addiction/issues/451)는 자체 신규 학습을 범위 밖으로 고정했다.
그 범위를 별도 결정으로 넓히지 않는 한 후속 계산은 없다.
범위를 넓힌다면 공개 OOF를 그대로 쓰는 것이 아니라, 각 바깥쪽 학습 부분 안에서 설정 선택까지 다시 수행하는 완전 중첩 자체 재현만 정식 개선 판정이 될 수 있다.

## 배열과 분할 무결성

- OOF는 691,369행, 시험 예측은 296,302행이며 두 배열 모두 유한값이다.
- 두 CSV의 `id`는 공식 `train.csv`와 `test.csv`의 원래 순서와 정확히 일치한다.
- OOF 재채점은 `0.968187400472623`으로 노트북 선언값 `0.968187`과 `1e-6` 안에서 맞는다.
- 코드 셀 19는 `StratifiedKFold(n_splits=5, shuffle=True, random_state=42)`를 원래 훈련 행 순서에 적용하고, 검증 예측을 해당 행 위치에 저장한다.
- 시험 예측은 같은 고정 설정의 분할 모형 5개를 산술 평균한다.
- 목표값 통계는 각 바깥쪽 학습 부분 안의 10개 내부 분할로 만들고 검증 행에는 전체 바깥쪽 학습 부분의 통계만 적용한다.
- 목표값을 쓰지 않는 그룹 평균만 훈련·시험 설명변수의 합친 집합에서 계산한다.
- OOF와 시험 예측은 외부 예측을 입력으로 받지 않는 단일 RepLeafGBM 계보에서 직접 나온다.

## 진입 진단 규약

현재 313개 중첩 OOF `0.970350946943525`를 고정 기준으로 사용했다.
후보와 기준의 전체 스피어만 순위 상관은 `0.9892124`였다.

결과를 보기 전에 혼합 표현 `raw`, `logit`, `rank`와 후보 가중치 `0.005`, `0.01`, `0.02`, `0.05`, `0.1`, `0.2`를 고정했다.
폴드 0·1에서 두 폴드 차이의 최솟값이 가장 큰 팔 하나를 골랐고, 폴드 2·3·4는 그 팔의 표현과 가중치를 다시 고르지 않고 평가했다.
통과 조건은 선별 폴드 2/2 양수, 미사용 폴드 3/3 양수, 미사용 폴드 평균 `+0.00001` 이상이었다.

선택된 팔은 `rank`, 후보 가중치 `0.05`였다.

| 구획 | 폴드 | 313 대비 AUC 차이 |
| --- | ---: | ---: |
| 선별 | 0 | `+0.0000060` |
| 선별 | 1 | `+0.0000133` |
| 미사용 | 2 | `+0.0000221` |
| 미사용 | 3 | `+0.0000138` |
| 미사용 | 4 | `+0.0000115` |

미사용 폴드 평균은 `+0.0000158`이고 3/3 양수라 진입 진단 문턱을 넘었다.
현재 엄격 교체 문턱 `+0.00002`보다 작고, 이 진단은 고정 OOF 재채점이므로 정식 중첩 개선 판정을 대신하지 않는다.

진단 코드는 `kaggle/repleaf_entry_screen/run.py`, 비공개 캐글 CPU 실행은 [S6E8 RepLeafGBM 313-member entry screen](https://www.kaggle.com/code/tmheo74/s6e8-repleafgbm-313-member-entry-screen)이다.
실행 산출물은 커밋 제외 경로 `run-logs/kaggle-out/repleaf-entry-screen-v1/`에 있다.

## 자격 위반 근거

공개 원본의 설정 선택 서술은 다음 경계를 넘는다.

- 마크다운 셀 0은 현재 설정이 제거 대조 사다리의 결과로 골라졌다고 설명한다.
- 마크다운 셀 1은 선형 잎 대신 상수 잎을 고른 근거로 같은 고정 분할의 폴드 0 비교 `+0.000388`을 제시한다.
- 마크다운 셀 16은 결측 증강 채택 근거로 같은 고정 5개 폴드의 차이와 전체 OOF `+0.000106`을 제시한다.
- 마크다운 셀 24는 이 비교들을 현재 공개 설정이 된 사다리라고 다시 명시한다.

검증 행의 목표값이 최종 예측을 만드는 모형 적합에 직접 들어가지는 않았다.
하지만 그 검증 결과가 잎 종류와 결측 증강 설정 선택에 닿았으므로, 설정 선택까지 포함하는 엄격 격리는 성립하지 않는다.
이는 성능 미달이 아니라 전제 위반에 따른 `자격 없음`이다.

## 판정

- 외부 배열 진입 진단: 통과.
- 검증 가능한 개별 외부 구성원 자격: 없음.
- 다음 외부 후보 동결 명세 편입: 하지 않음.
- 엄격 외부 사다리 판정 실행: 열지 않음.
- 공개 배열로 제출 조립: 하지 않음.
- 자체 완전 중첩 재현: 현재 지도의 범위 밖이며 별도 범위 결정이 있을 때만 검토.
