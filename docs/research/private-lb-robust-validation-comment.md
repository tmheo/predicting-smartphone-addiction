# Private-LB-robust validation 댓글의 증분 가치 판정

## 결론

[토론 734628](https://www.kaggle.com/competitions/playground-series-s6e8/discussion/734628)의 댓글은 현재 실험 계획을 바꿀 새 후보를 제시하지 않는다.
적대적 검증, 결측, 7,500행 프록시, 순위표 분해능과 교사-학생 누출 규율은 기존 문서와 티켓에 이미 더 강한 근거로 반영돼 있다.
새로운 부분은 74개 OOF 구성원에서 후보 선별과 가중치 학습의 상호작용을 보여 주는 2×2 비교이며, 이는 전체 후보를 nested 선형 결합에 남기는 현행 규칙을 외부에서 재확인한다.
따라서 새 실험이나 코드 변경은 열지 않고, 디스커션 종합 문서에 이 정성적 재확인만 반영한다.

## 확인 범위

Kaggle 페이지와 공개 읽기 API를 브라우저 자동화로 직접 확인했다.
본문은 2026-08-12 07:10:56 UTC에 게시됐고, 유일한 댓글은 Georgy Mamarin이 2026-08-14 16:29:58 UTC에 게시한 id `3512895`다.
기존 [남은 실험 공간 전수 재점검](remaining-experiment-space-audit.md)은 2026-08-14 05:12 UTC에 작성됐으므로 본문만 읽었고 이 댓글은 포함할 수 없었다.

댓글이 인용한 [S6E8 honest OOF blend](https://www.kaggle.com/code/szymonkapiski/s6e8-honest-oof-blend)는 74개 공통 OOF를 같은 5-fold로 맞추고 outer 학습 부분에서 선형 결합을 다시 맞추는 공개 노트북이다.
노트북은 Apache License 2.0으로 공개돼 있으며, 이번 검토에서는 코드나 산출물을 복사하지 않았다.

## 새로 확인된 앙상블 비교

댓글은 같은 74개 구성원 묶음에서 다음 수치를 직접 보고한다.

| 후보 풀 | 균등 가중 | 힐 클라이밍 |
| --- | ---: | ---: |
| 단독 점수 상위 10개 | 0.96931 | 0.96942 |
| 전체 74개 | 0.96738 | 0.96948 |

균등 가중에서는 상위 10개 선별이 `+0.00193`이지만, 힐 클라이밍에서는 전체 74개가 상위 10개보다 `+0.00006` 높다.
가중치 학습의 이득도 상위 10개에서는 `+0.00011`인 반면 전체 74개에서는 `+0.00210`이다.
댓글은 전체 74개를 쓴 nested 로지스틱 결합이 `0.96963`으로 네 칸을 모두 넘으며, 음의 계수로 약한 구성원을 보정 방향에 쓸 수 있기 때문이라고 해석한다.

이 표는 후보 선별과 가중치 학습을 독립 이득으로 더하면 안 된다는 정성적 근거다.
단순 평균은 약한 구성원을 직접 벌하지만, 학습형 결합은 같은 구성원을 잔차 보정에 쓸 수 있다.

다만 2×2 표에는 계산 코드, 실행 산출물, 상위 10개 선정 계약과 힐 클라이밍의 outer 평가 절차가 연결돼 있지 않다.
댓글은 로지스틱 결합만 nested라고 명시하므로 네 칸의 힐 클라이밍 점수를 선택 편향 없는 채택 수치로 간주할 수 없다.
따라서 이 표는 방향을 확인하는 외부 보고이고, 자체 nested OOF보다 증거 등급이 낮다.

## 현재 파이프라인과의 대조

[순위 평균과 nested 선형 스태킹 비교](https://github.com/tmheo/predicting-smartphone-addiction/issues/64)는 outer fold 밖에서만 변환, 표준화와 계수를 학습했다.
16개 전체 후보의 순위와 logit 이중 표현 로지스틱 결합은 nested OOF `0.969483491650`을 기록했다.

[부분집합 선택과 가중치 탐색의 일반화 성능 결정](https://github.com/tmheo/predicting-smartphone-addiction/issues/62)은 탐욕, 배깅 탐욕과 Optuna가 모든 outer fold에서 같은 3개만 골랐지만, 그 균등 순위 평균은 `0.969450024608`로 전체 16개 학습형 결합보다 `0.000033467042` 낮고 5개 fold에서 모두 졌다.
이는 댓글의 정성적 결론을 우리 fold와 자체 OOF에서 더 엄격하게 재현한 결과다.

[보강 풀의 nested 재평가와 결합 전략 재선정](https://github.com/tmheo/predicting-smartphone-addiction/issues/187)에서도 단독 점수가 더 낮은 `exp107`은 최고 결합에서 평균 계수 `+0.147`, 더 높은 `exp108`은 `-0.435`를 받아 역할이 분화됐다.
현재 `missing_interaction_rank_logit`은 후보 풀 전체를 입력받아 각 outer 학습 부분에서 음수를 포함한 계수를 학습하므로 댓글이 권하는 구조를 이미 충족한다.

결론적으로 무결성과 중복 검사를 통과한 후보는 단독 점수나 균등 평균 제외 기여만으로 제거하지 않고, 전체 후보를 nested 결합기가 판정하게 하는 현행 규칙을 유지한다.
