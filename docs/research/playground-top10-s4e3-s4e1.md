# Playground Series S4E3부터 S4E1까지 상위 10위 해법과 댓글 조사

이 문서는 GitHub 이슈 [리서치: S4E3-S4E1 상위권 해법 글과 댓글 조사](https://github.com/tmheo/predicting-smartphone-addiction/issues/470)의 조사 결과다.
조사 기준일은 2026-08-28이다.

## 결론

세 대회의 공식 해법 범주에 보이는 글 13개를 모두 열었고, 제목이나 본문에 Private 최종 1위부터 10위가 명시된 글 6개를 포함했다.
전체 공식 목록의 댓글 표시값 합계는 203개였고, 포함 글의 목록 댓글 표시값 합계는 185개였다.
포함 글 상세 화면 머리말의 일반 댓글 표시값 합계는 172개, 감사 댓글 표시값 합계는 22개였다.
모든 포함 글에서 내부 댓글 영역을 끝까지 내려 지연 표시되는 댓글을 불러왔고 접힌 답글도 모두 펼쳐 확인했다.

현재 S6E8에 새 실험을 열 만큼 강한 새 정보 관점은 발견하지 못했다.
가장 강한 과거 성공은 S4E1 2위의 원본 부분집합 정확 일치 특성이지만, 이 방법은 이슈 307이 이미 원본 거리와 일치 관점으로 분류했고 현재 자체 풀도 원본 최근접 라벨, 원본 목표 통계, 분포 좌표와 정확값 표현을 포함한다.
S4E1 3위의 광범위한 목표값 부호화, S4E3과 S4E2의 공통 분할 OOF 결합, 여러 나무 및 신경망의 다양성도 자체 35개 또는 외부 278개 확장 결합이 이미 덮는다.
의사 라벨과 XGBoost 2단 결합은 이번 글에서도 실패 사례가 나왔고 S6E8 자체 음성 판정과 같은 방향이다.
Public 점수로 제출 파일이나 후처리를 고르는 절차, 다중 분류의 정확도 문턱 최적화, 도메인 전용 비율과 문자열 성씨 표현은 현재 과제에 옮길 수 없다.

현재 비교 기준은 SHA-256 `caa1b90769720a4accbe07074dbc7efe0335ab6657fea80c6839b60121dc39d3`인 자체 후보 풀 35개와 외부 구성원 278개를 합친 313개 확장 결합이다.
자체 35개 풀의 최고 결합은 `shrunk_rank_logit_logistic`, nested OOF `0.9698105828`이다.
최신 확장 결합 실행 `443b3a71a2b045ba9052fbb3d821255d`는 같은 전략으로 nested OOF `0.9703509469`, 가중 OOF `0.9712170271`을 기록했다.
Public `0.97135`는 사후 참고값이며 후보 판정에는 사용하지 않는다.

## 조사 범위와 방법

Kaggle API, 웹 검색 결과 요약, 직접 HTTP 요청과 리더보드 조회는 사용하지 않았다.
`agent-browser`의 별도 이름 세션과 콘텐츠 경계를 켜고 각 대회의 실제 Kaggle 공식 화면을 직접 확인했다.
각 조사는 사용자가 지정한 [`competitionWriteUps` 화면](https://www.kaggle.com/competitions/playground-series-s4e3/discussion?category=competitionWriteUps&sort=recent-comments)에서 대회 slug만 바꾸어 시작했다.
추천 수와 정렬 순서는 발견 순서로만 사용했고 표본 선정에는 쓰지 않았다.
순위는 글 제목 또는 상세 화면의 `Solution Writeup · Nth place` 표기만 사용했다.
상위 10위 글이 없는 순위는 다른 글로 채우지 않았다.

과제와 평가지표는 Kaggle의 [S4E3 평가](https://www.kaggle.com/competitions/playground-series-s4e3/overview/evaluation), [S4E2 평가](https://www.kaggle.com/competitions/playground-series-s4e2/overview/evaluation), [S4E1 평가](https://www.kaggle.com/competitions/playground-series-s4e1/overview/evaluation) 화면에서 확인했다.
포함 글마다 본문, 작성자 표시, 순위 표시, 검증 설명, 특성, 모형, 결합, 보고 점수, 계산 자원, 외부 자료, 일반 댓글, 접힌 답글과 감사 댓글을 확인했다.
화면에 없는 팀 구성, 점수 또는 설정은 추정하지 않고 미보고로 남겼다.

Kaggle 목록의 댓글 수와 상세 화면 머리말의 일반 댓글 및 감사 댓글 수는 여러 글에서 서로 일치하지 않았다.
목록 수에는 답글, 삭제 댓글과 감사 댓글이 다르게 반영되는 것으로 보이지만 Kaggle 화면은 집계 규칙을 설명하지 않는다.
따라서 아래 장부는 전체 공식 목록, 포함 글 목록과 상세 화면의 원시 표시값을 따로 기록한다.

## S4E3: Steel Plate Defect Prediction

### 2위: Moonlit

[2nd place solution: OOF Ensemble](https://www.kaggle.com/competitions/playground-series-s4e3/writeups/moonlit-2nd-place-solution-oof-ensemble)은 Moonlit의 2위 글이다.
목록에는 댓글 23개가 표시됐고 상세 화면에는 일반 댓글 21개와 감사 댓글 3개가 표시됐다.

작성자는 대회 자료와 원본 자료를 합치되 여러 목표가 동시에 표시된 원본 행은 적어서 제외했다.
추가한 특성은 컨베이어 길이와 강판 두께의 비율, 최소와 최대를 이용해 정규화한 강판 두께, 수평 길이와 화소 면적의 곱 세 개였다.
CV, 특성 중요도와 쌍별 상관을 보고 일곱 특성을 제거했다.
XGBoost, LightGBM, CatBoost와 HistGradientBoostingClassifier를 10-fold CV와 Optuna로 학습해 분할별 예측을 평균했다.

자체 모형과 두 공개 노트북을 같은 분할로 다시 실행해 세 OOF를 만들고 Nelder-Mead로 CV 최적 가중치를 구했다.
최종 단계에서는 이 결합과 여러 공개 제출을 직관적 가중치로 다시 평균했다.
작성자는 기회가 적어 같은 가중치가 효과적이었다고 사후 평가했다.
공개 노트북 출력만 같은 가중치로 합친 대안은 Public `0.89684`, Private `0.88923`이었지만 최종 제출로 선택하지 않았다.
최종 제출의 CV, Public과 Private 점수는 보고하지 않았다.

실패한 방법은 의사 라벨, XGBoost를 2단 모형으로 쓴 결합과 학습 평가지표를 `roc_auc`로 바꾸는 것이었다.
댓글은 대부분 축하와 공개 자료에 대한 감사였다.
작성자가 최종 제출 판본 선택은 운이 좋았다고 답한 댓글은 직관적 제출 선택의 불확실성을 본문보다 더 분명히 한다.

S6E8 판단은 기존 결정과 중복 또는 현재 과제에 부적합이다.
같은 분할 OOF와 여러 나무 결합은 자체 35개와 외부 278개가 더 엄격하게 구현한다.
의사 라벨과 비선형 2단 결합의 실패는 S6E8 자체 음성 판정과 같은 방향이다.
공개 제출을 보고 직관적으로 고르는 최종 단계는 ADR 0001의 선택 경계에 어긋난다.
강판 길이, 두께와 화소 면적의 관계는 현재 입력에 대응하지 않는다.

### 3위: Samvel Kocharyan

[3rd Place Solution - Mediocres et Impera](https://www.kaggle.com/competitions/playground-series-s4e3/writeups/samvel-kocharyan-3rd-place-solution-mediocres-et-i)는 Samvel Kocharyan의 3위 글이다.
목록에는 댓글 11개가 표시됐고 상세 화면에는 일반 댓글 9개가 표시됐다.

작성자는 일곱 목표를 하나의 다중 분류로 바꾸기보다 각각 예측하는 다중 라벨 접근이 CV와 Public에서 조금 높았다고 했다.
최종 제출은 PyBoost, AutoGluon과 여러 공개 제출을 합친 결과였다.
OpenFE 특성, 병합, 2단 결합과 평균도 사용했고 단일 모형과 원본 자료는 실패했다고 보고했다.
선택한 혼합 제출은 Private `0.88936`으로 3위, Public `0.89674`로 8위였다.
본문은 PyBoost와 OpenFE 제출의 두 점수 `0.88763`과 `0.89476`을 모두 Private으로 표기해 두 번째 점수의 판을 확정할 수 없다.
선택하지 않은 최고 제출은 Private `0.88944`로 2위 수준, Public `0.89670`으로 8위 수준이었다.

댓글에서 다른 상위 참가자는 선택하지 않은 제출 약 20개가 최종 제출보다 좋았고, 선택한 결과의 기하평균 중 최고는 Private `0.88951`이었다고 답했다.
작성자의 팀도 예전 제출 가운데 2위가 될 결과가 있었다고 보충했다.
이 댓글은 다양한 결합 자체보다 두 제출 선택 제한에서 생긴 우연이 최종 순위를 좌우했음을 보여 준다.

S6E8 판단은 기존 결정과 중복 또는 현재 과제에 부적합이다.
다중 라벨과 다중 분류의 선택은 이미 이진 목표인 S6E8에 적용되지 않는다.
PyBoost, AutoGluon, OpenFE와 다수 예측 결합은 외부 278개 폭 또는 기존 음성 판정이 덮는다.
선택하지 않은 제출의 Private 결과는 사후 정보라 어떤 후보의 채택 근거로도 쓸 수 없다.

## S4E2: Multi-Class Prediction of Obesity Risk

### 4위: Kirderf

[4th place solution: Stacking with XGB + Pseudo labeling + metric optimizing](https://www.kaggle.com/competitions/playground-series-s4e2/writeups/kirderf-4th-place-solution-stacking-with-xgb-pseud)는 Kirderf의 4위 글이다.
목록과 상세 화면 모두 댓글 28개를 표시했고 상세 화면에는 감사 댓글 9개가 따로 표시됐다.

작성자는 공개와 비공개 평가 비율이 20 대 80이라 순위 변동이 컸고 지역 CV를 우선해야 한다고 설명했다.
대회 자료와 원본 자료를 합친 뒤 나이 구간, 나이 로그와 최소-최대 변환, BMI, 나이와 성별의 곱, 범주 원-핫 표현과 나이 및 BMI 다항 특성을 만들었다.
AutoXGB, AutoGluon의 사전 탐색 설정, LightAutoML의 LightGBM 및 CatBoost, 자체 XGBoost와 LightGBM을 사용했다.
자체 나무는 의사 라벨 사용판과 미사용판을 모두 만들었다.

각 모형의 범주 확률을 원래 특성에 더하고 XGBoost를 2단 모형으로 학습했다.
대회 지표는 정확도였지만 학습에는 log loss를 사용했고 마지막에 공개된 정확도 최적화 후처리를 적용했다.
최종 예측은 자체 판본과 공개 노트북 두 개를 포함한 아홉 예측에서 행별 최빈 범주를 골랐다.
CV, Public, Private과 계산 시간은 보고하지 않았다.
댓글은 기술적 보충 없이 축하와 감사 중심이었다.

S6E8 판단은 기존 결정과 중복 또는 현재 과제에 부적합이다.
원본 행 추가, 도메인 비율과 다항식, 의사 라벨, XGBoost 2단 결합은 자체 판정에서 이미 기각되거나 기존 특성의 부분집합이다.
정확도의 범주 결정 문턱과 최빈 범주 결합은 순위만 보는 이진 ROC AUC에 대응하지 않는다.
AutoML과 여러 나무 및 신경망 출력은 313개 확장 결합이 더 넓고 엄격하다.

### 6위: Nirmal Falzoni

[6th place solution](https://www.kaggle.com/competitions/playground-series-s4e2/writeups/nirmal-falzoni-6th-place-solution)은 Nirmal Falzoni의 6위 글이다.
목록에는 댓글 28개가 표시됐고 상세 화면에는 일반 댓글 26개가 표시됐다.

작성자는 공개 노트북의 여러 전통 나무 결합에 Optuna로 설정을 고른 단순 신경망을 추가했다.
신경망이 나무와 다른 방식으로 학습하고 자료 생성에도 심층 모형이 쓰였다는 추측 때문에 CV 개선이 작아도 낮은 가중치로 유지했다.
결합 가중치는 단순 격자 탐색으로 CV에 맞췄다.
Public이 높은 모형보다 CV가 높고 Public과 크게 어긋나지 않는 모형을 제출했다고 설명했으며, 최종 CV, Public과 Private 점수는 본문에 없다.

댓글에서 작성자는 10-fold StratifiedKFold 전체 결합의 CV가 `0.9184`였다고 답했다.
신경망 CV는 약 `0.89`를 넘지 못했고 학습률 감소 일정이 조금 도왔다고 보충했다.
공개한 신경망은 64, 128, 256, 512, 256, 128, 64, 32, 16 폭의 밀집층, 여러 dropout과 softmax 출력으로 구성됐다.
작성자는 대회 자료와 원본 자료를 모두 사용했다고 확인했다.
하드웨어와 실행 시간은 보고하지 않았다.

S6E8 판단은 기존 결정과 중복 또는 현재 과제에 부적합이다.
나무와 약한 신경망의 오류 다양성은 자체 신경망 계열과 외부 278개가 이미 덮고, 이 글은 신경망을 뺀 한계 기여를 보고하지 않는다.
격자 가중치 탐색은 현재 nested 결합 전략 비교보다 약하다.
Public과 CV의 일치를 제출 선택에 쓰는 절차는 Public을 판정 근거에서 제외하는 현 계약에 어긋난다.
원본 행 추가는 S6E8의 직접 음성 판정을 다시 열지 못한다.

## S4E1: Binary Classification with a Bank Churn Dataset

### 2위: lukaszl

[2nd place solution](https://www.kaggle.com/competitions/playground-series-s4e1/writeups/lukaszl-2nd-place-solution)은 lukaszl의 2위 글이다.
목록에는 댓글 42개가 표시됐고 상세 화면에는 일반 댓글 40개와 감사 댓글 6개가 표시됐다.

작성자는 열 개 설명변수의 크기 1부터 10까지인 모든 부분집합을 만들고, 각 행의 해당 값 조합이 원본 자료에 정확히 존재하는지를 약 1,000개 이진 특성으로 나타냈다.
`CustomerId`와 `Surname`의 결합 일치 여부도 추가했다.
전체 목표 양성률은 약 `0.21`이지만 `CreditScore`, `Geography`, `Balance`의 원본 일치 여부에 따라 양성률이 `0.171026`과 `0.269552`로 갈렸다.
`CreditScore`, `Gender`, `NumOfProducts` 조합은 미일치 `0.203034`, 일치 `0.707857`로 더 크게 갈렸다.

LightGBM은 기본 특성을 포함해 50개를 사용했고 Private `0.90203`이었다.
댓글에서 작성자는 단순 유전 탐색을 몇 시간 돌려 50개를 골랐다고 설명했다.
AutoGluon은 약 1,000개를 모두 받고 `presets='best_quality'`, 시간 제한 14,400초로 학습해 Private `0.90378`이었다.
두 예측의 같은 가중치 평균은 최종 Private `0.90462`였다.
공개 특성을 조금 더했지만 차이는 작았고 CV와 Public은 보고하지 않았다.

작성자는 공개 목표를 이용한 이른바 `Feeling lucky` 후처리가 약 `0.01`을 더했다고 적었다.
댓글에서 3위 참가자는 부분집합 일치를 전체 열 누출의 일반화로 해석했고 작성자도 합성 생성기가 여러 결합 수준에서 목표 분포를 유지하지 못한 문제를 이용했다고 답했다.
작성자는 실제 고객 자료에는 생성 원본이 따로 없으므로 이 방법을 쓸 수 없다고 명시했다.
AutoGluon은 모형을 제외하지 않고 모두 사용했다고 보충했다.

S6E8 판단은 기존 결정과 중복이다.
이 방법은 과거 조사에서 이미 원본 부분집합 매칭으로 식별됐고 이슈 307은 원본 거리와 일치, 정확값 통계 및 최근접 라벨 관점에 포함해 판정을 끝냈다.
S6E8의 생성 지문 규약도 사전 고정한 2열, 3열과 6열 부분집합 충돌을 진단 대상으로 둔다.
현재 자체 35개에는 원본 최근접 라벨, 원본 목표 통계, CDF 차이와 정확값 표현이 있고 외부 278개도 여러 원본 활용판을 포함한다.
고차 결합은 원본 프록시 7,500행에서 거의 전부 미일치가 될 수 있고 쌍 66개 목표값 통계 선택도 음성이어서 새 개방 기준을 충족하지 않는다.
공개 목표 후처리는 성능과 무관하게 현재 검증 계약에 부적합하다.

### 3위: Iqbal Syah Akbar

[3rd Place Solution: CatBoost Encoding Galore](https://www.kaggle.com/competitions/playground-series-s4e1/writeups/iqbal-syah-akbar-3rd-place-solution-catboost-encod)는 Iqbal Syah Akbar의 3위 글이다.
목록에는 댓글 53개가 표시됐고 상세 화면에는 일반 댓글 48개와 감사 댓글 4개가 표시됐다.

작성자는 일부 열을 TF-IDF로 바꾸고 TruncatedSVD로 줄였으며, 성씨의 네 SVD 성분까지 정수로 바꿔 목표값 부호화했다.
잔액이 0인지, 나이와 급여의 정수화, 나이 구간, 거의 모든 범주를 이어 붙인 `AllCat`과 활동 여부 및 신용카드 결합을 추가했다.
원래 열 가운데 잔액과 신용카드 여부를 제외한 거의 모든 열에 CatBoost 계열 또는 M-estimate 목표값 부호화를 적용했다.

CatBoost 내장 부호화, `category-encoders`의 CatBoostEncoder와 MEstimateEncoder를 모형에 따라 달리 썼다.
CatBoostEncoder는 행 순서에 민감하므로 `has_time=True`를 쓰고 원본 자료를 대회 자료보다 앞에 놓는 순서가 가장 좋았다고 보고했다.
로지스틱 회귀, 작은 밀집 신경망, XGBoost, LightGBM과 표본 추출 방식이 서로 다른 CatBoost 세 개를 사용했다.
세 CatBoost의 CV는 모두 `0.902`보다 높았고 최종 가중치는 RidgeClassifier로 정했다.
정확한 최종 CV, Public과 Private 점수는 보고하지 않았다.

실험에는 5-fold를 쓰고 제출은 30-fold로 학습해 약 12시간이 걸렸다.
원본 자료를 두 번 이어 붙인 판이 가장 높은 Private을 얻었다고 사후 보고했고 공개 목표에 관한 후처리도 사용했다.
댓글에서 작성자는 낮은 값 종류 수의 열을 CatBoostEncoder로 너무 많이 부호화하면 일반적으로 과소적합하지만 이 대회는 예외였다고 설명했다.
가장 낮은 중요도 특성을 빼도 성능이 나빠져 최종에는 제거하지 않았다고 답했다.
30-fold가 좋은 이유를 큰 자료의 서로 다른 부분집합을 평균하는 효과라고 설명했지만 별도 제거 수치는 제시하지 않았다.

S6E8 판단은 대부분 기존 결정과 중복이고 문자열 경로는 현재 과제에 부적합하다.
정확값 및 목표값 부호화, 원본 목표 통계, CatBoost, 여러 표본 추출 설정, 로지스틱 및 Ridge 결합은 자체 35개 또는 외부 278개가 덮는다.
원본을 앞에 놓는 순서 효과는 원본 목표값 통계를 순차 사전정보로 주는 변형이며, 현 풀에는 행 순서에 기대지 않는 분할 안전 원본 통계가 이미 있다.
원본 행을 여러 번 넣는 재가중은 S6E8의 원본 행 추가 음성 판정과 충돌한다.
S6E8에는 성씨 같은 문자열 식별자가 없어 TF-IDF와 SVD 경로가 대응하지 않는다.
30-fold 자체는 현재 고정 5-fold 규약을 바꿀 독립 제거 근거가 없고 계산량만 크게 늘린다.

## 반복 근거와 댓글 반례

공통 분할 OOF와 여러 학습기 결합은 S4E3 2위, S4E2 4위와 6위, S4E1 3위에서 반복됐다.
이 반복은 예측 계보와 오류 다양성의 중요성을 보강하지만 313개 확장 결합에 새 방법을 더하지 않는다.

원본 자료는 세 대회 모두에서 시험됐지만 사용법의 부호가 달랐다.
S4E1 2위는 원본 부분집합 일치가 매우 강했고 S4E1 3위는 원본 선행 배치와 반복 주입이 좋았다고 보고했지만 S4E3 3위는 원본 자료가 실패했다고 적었다.
따라서 원본 사용 자체를 일반 법칙으로 만들 수 없고 S6E8의 직접 대조가 우선한다.

약한 구성원을 다양성만으로 유지한다는 주장은 제거 대조가 필요하다.
S4E2 6위의 신경망은 단독 CV가 약 `0.89`, 전체 결합은 `0.9184`였지만 신경망을 뺀 결과가 없다.
현재 313개 사다리에서는 약한 외부 고전 모형 120개를 제거했을 때 오히려 좋아졌으므로 모델 계열이 다르다는 이유만으로 유지할 수 없다.

최종 순위에는 제출 선택 운이 반복해서 개입했다.
S4E3 2위 작성자는 최종 판본 선택이 운이었다고 답했고 S4E3 3위 댓글은 선택하지 않은 약 20개 결과가 더 좋았다고 밝혔다.
이 반례는 Public과 직관으로 제출을 고르지 않고 OOF 선택 경계를 고정해야 한다는 현 규약을 지지한다.

## 적용 우선순위와 종료 조건

이번 구간만을 근거로 새 실험 티켓을 만들지 않는다.
자체 35개와 외부 278개의 현재 확장 결합을 동등 단계 기준으로 유지한다.
원본 부분집합 매칭, 원본 행 주입, 정확값 부호화, 의사 라벨, 비선형 2단 결합과 대규모 자동 특성 생성의 기존 판정을 다시 열지 않는다.

원본 부분집합 일치를 다시 검토하려면 기존 생성 지문 진단에서 사전 고정한 2열과 3열 조합의 일치율이 상수에 가깝지 않고 목표 및 기존 정확값 통계와 다른 신호를 보여야 한다.
그 뒤에만 결과를 보기 전에 조합 목록을 고정하고 각 바깥 분할 안에서 선택을 다시 수행한 OOF와 시험 예측을 만들 수 있다.
판정은 현재 35개 풀의 내용 해시를 고정한 단일 포함 및 제외 nested OOF, 바깥 분할 반복 승리와 기존 원본 관점 최근접 상관으로 해야 한다.
유전 탐색으로 전체 OOF를 본 뒤 50개를 고르거나 Public과 Private으로 조합을 고르면 결과를 폐기한다.

약한 신경망이나 많은 분할도 독립 제거 대조 한 건 또는 서로 독립된 성공 사례 두 건이 생기기 전에는 열지 않는다.
새 자료가 생겨도 ADR 0001의 계열 2 규약에 따라 기준 풀을 내용 해시로 고정하고 핵심 결합 전략을 양쪽에서 다시 선택해야 한다.
외부 예측이라면 OOF와 시험 예측의 행 정렬, 상류 분할 준수, 출처, 라이선스와 재배포 경계를 먼저 확인해야 한다.

## 사실과 추론의 경계

순위, 작성자, 댓글 표시값, 본문과 댓글의 수치, 특성, 모형, 분할과 계산 시간은 Kaggle 공식 화면에 적힌 사실이다.
본문이 보고하지 않은 팀 구성, CV, Public, Private, 하드웨어와 코드 세부는 미보고로 남겼다.
S4E3 3위 글에서 두 점수를 모두 Private으로 부른 표기는 원문 그대로 기록했고 두 번째를 Public으로 고치지 않았다.

네 범주 분류와 S6E8 적용 판단은 조사자의 추론이다.
특히 원본 부분집합 일치가 현재 원본 관점과 겹친다는 판단, 많은 분할이 새 정보 관점이 아니라는 판단, 약한 외부 모형 제거 결과가 S4E2 신경망 주장에 대한 반례라는 해석은 원문 진술이 아니다.
