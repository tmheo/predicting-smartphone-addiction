외부 구성원 감사 기록 계약

이 데모는 판본 3 후보의 감사 기록을 어떤 필드와 상태 전이로 남겨야 자격 판정을 기계적으로 다시 계산하고, 고정했던 후보 집합을 나중에도 그대로 재현할 수 있는지 검토하기 위한 것입니다.

이 파일은 결정 검토용이며 실제 판본 3 장부를 만들거나 외부 예측 배열을 반입하지 않습니다.
감사 진행 상태 발견됨 → 공개 판본 고정됨 → 감사 완료만 나타냅니다. 자격 결과와 섞지 않습니다.
자격 판정 자격 있음 / 자격 없음 / 근거 부족을 근거 코드에서 계산합니다. 라이선스 미표시는 자동 탈락이 아닙니다.
