# exp085 다층 출력 경로 짝비교

이 문서는 GitHub 이슈 [exp085에 다층 머리와 행별 혼합을 이식하는 개선 짝비교를 실행한다](https://github.com/tmheo/predicting-smartphone-addiction/issues/287)의 구현, Vast.ai 실행과 판정 근거를 기록한다.
기준은 `exp085_contextual_spline_m0`, 실험은 출력 경로만 공개판 1단계 다층 머리와 행별 혼합으로 바꾼 `exp136_contextual_spline_multilevel`이다.

## 결론

폴드 평균 AUC는 기준 `0.9674795117`, 실험 `0.9675127387`로 변화가 `+0.0000332270`이다.
이 값은 사전 고정한 유효 문턱 `+0.0006532`의 약 5.1%에 불과하므로 개선을 무효로 판정한다.
실험은 5개 폴드 중 3개에서 앞섰지만 변화 범위는 `-0.0000530690`에서 `+0.0001665999`로 모두 문턱 안이다.

원시 전체 OOF 변화는 `+0.0000415695`이고, 폴드 안 백분위 순위로 눈금을 맞춘 전체 OOF 변화는 폴드 평균과 같은 `+0.0000332270`이다.
따라서 전체 OOF의 눈금 효과를 제거해도 결론은 바뀌지 않는다.

중단 조건에 따라 3시드 확장과 2단계 보정망 후속 이슈를 열지 않는다.
후보 풀과 champion 판정은 이슈 범위 밖이므로 변경하지 않는다.

## 통제 구현

새 설정 `configs/exp136_contextual_spline_multilevel.yaml`은 `configs/exp085_contextual_spline_m0.yaml`과 비교해 실험 이름과 `model.params.output_path: multilevel_stage1`만 다르다.
두 조건은 같은 33개 특성, 시드 42, 커밋된 5개 폴드, 자료, 최적화 방식과 조기 종료 조건을 사용했다.

다층 출력 경로는 Kaggle 공개 노트북 [Multi-Level Deep Univariate Spline Transformer 판본 5](https://www.kaggle.com/code/ern711/multi-level-deep-univariate-spline-transformer?scriptVersionId=342998269)의 1단계 구조를 옮겼다.
공개 소스 SHA-256은 `3ae3e15d975892f90875d57e3877ba299ea073c5e019295b58870a09a35793fd`이고 Apache License 2.0 조건을 따랐다.

구현은 기존 ADD와 FINAL에 단변량 토큰의 평균과 최댓값을 쓰는 UNI, 주의 연산 뒤 토큰의 평균과 최댓값을 쓰는 ATTN을 더한다.
행별 혼합기는 네 logit과 여섯 쌍별 절대 차이를 받아 합이 1인 가중치 네 개를 만들며, 초깃값에서는 FINAL을 선호하도록 출력 편향을 둔다.
주 손실에 ADD `0.3`, UNI `0.1`, ATTN `0.1`의 보조 손실과 `1e-5` 계수의 혼합 엔트로피 벌점을 더했다.
공유 모형을 먼저 초기화해 두 조건의 공유 매개변수 초기값을 같게 유지했고, 2단계 보정망은 넣지 않았다.

기준 모형은 학습 가능한 매개변수 `5,944,123`개이고 실험 모형은 `5,978,181`개로 `34,058`개 늘었다.

## 실행 무결성과 자원 정리

구현과 두 원격 실행은 커밋 `be7786859d895246e087b34d3af0b144cca9cccd`에 고정했고 원격 Git 상태는 깨끗했다.
학습 자료 SHA-256은 `f4669147311c76eb03496061a852af283efcf0f12cf5c19274e775def81edd9c`, 시험 자료는 `8b462dd47fe8165cd0b082bf33b56523c5811453070af48b9f86b2eb928de49e`, 폴드는 `5f5d09e9356f227ecb4a063270b175bb5cae20afb25636c563db185e18a155c4`다.

Vast.ai의 RTX 3090 24GB 두 장에서 두 조건을 동시에 실행했다.
고정 이미지는 `nvcr.io/nvidia/pytorch@sha256:a411b86de9ac003ce5db43894ea7920718512bc02c51a521157c0899aac75631`이고, 학습 가상환경은 Python `3.12.3`, PyTorch `2.13.0+cu130`, CUDA `13.0`을 썼다.
학습은 `2026-08-20T13:12:31Z`부터 `2026-08-20T14:51:47Z`까지 실행됐고 두 조건과 원격 제어 파일의 종료 상태는 모두 0이다.

회수한 전체 결과 묶음 SHA-256은 `08a786c1ed641a124665d79bad787edbb104abeb44eef52150324636e83dccaa`다.
기준 실행 묶음 SHA-256은 `9541258c8d84c622cb377d3c0fc383b2698e69baf3e2fbd22ac8d1599f79e465`, 실험 실행 묶음은 `cf1a78955f23d5af2d55fac94cc996850c74e68feadff066027ea01846e7774b`다.
주 MLflow는 두 묶음을 로컬 자료와 폴드로 재채점한 뒤 기준 실행 `ca1fc18f00f54d1d9f3feaf38f9033d5`, 실험 실행 `bb5ad2d1bc2b47d0ad5b157be9fb71f4`로 반입했다.

첫 Vast.ai 시도는 입력 manifest의 상대 경로 기준 오류로 학습과 가상환경 설치 전에 중단됐고, 고정 실행 파일을 현장에서 바꾸지 않고 새 입력 묶음으로 다시 시작했다.
첫 시도의 확정 비용은 `$0.032`, 정상 실행 비용은 `$0.734`, 합계는 `$0.766`이다.
결과 회수와 반입 뒤 이 작업이 만든 인스턴스를 삭제했고 관련 별도 저장 공간이 없으며 목록 부재를 확인했다.
이 작업의 외부 종료 예약만 제거하고 동시에 실행 중인 다른 작업의 예약 세 개를 보존했다.

구현 커밋에서 `scripts/verify_environment_gates.sh --isolated`는 비커밋 입력 검사, 원격 Python 계약 4건과 전체 시험 397건을 통과했다.
