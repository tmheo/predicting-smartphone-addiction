# Playground Series S3E22부터 S3E20까지 상위 10위 해법과 댓글 조사

이 문서는 GitHub 이슈 [리서치: S3E22-S3E20 상위권 해법 글과 댓글 조사](https://github.com/tmheo/predicting-smartphone-addiction/issues/474)의 조사 결과다.
조사 기준일은 2026-08-28이다.

## 결론

세 대회의 공식 해법 범주에 보이는 글 9개를 모두 확인했고, 제목이나 본문에 Private 최종 1위부터 10위가 명시된 글 3개를 포함했다.
전체 공식 목록의 댓글 표시값 합계는 51개였고, 포함 글의 목록 및 상세 화면 댓글 표시값은 모두 23개였다.
포함 글에는 감사 댓글이 따로 표시되지 않았다.
모든 포함 글에서 댓글 영역을 끝까지 확인했고 접힌 답글도 모두 펼쳤다.

현재 S6E8에 새 실험을 열 만큼 강한 새 정보 관점은 발견하지 못했다.
S3E22에는 상위 10위 공식 해법 글이 한 개도 없어 적용 근거가 없다.
S3E21 4위의 이상치 제거는 고정 RandomForest 회귀 모형의 훈련 자료 자체를 제출하는 특수 대회에서 나온 결과이고, 글에 제거 규칙, 검증과 점수가 없어 일반적인 행 선별 후보로도 근거가 부족하다.
S3E20 3위와 4위의 연도별 검증, 코로나 기간 보정, 공간별 PCA와 전역 배율은 시공간 RMSE 예측 구조에 종속돼 정적 이진 ROC AUC 과제에 옮길 수 없다.
S3E20 4위 댓글은 Public 최고 제출이 Private 약 230위로 떨어졌고 무배율 판이 사후 1위 수준이었다고 밝혀 Public 기반 제출 선택을 피해야 한다는 기존 판정을 보강한다.

현재 비교 기준은 SHA-256 `caa1b90769720a4accbe07074dbc7efe0335ab6657fea80c6839b60121dc39d3`인 자체 후보 풀 35개와 외부 구성원 278개를 합친 313개 확장 결합이다.
자체 35개 풀의 최고 결합은 `shrunk_rank_logit_logistic`, nested OOF `0.9698105828`이다.
최신 확장 결합 실행 `443b3a71a2b045ba9052fbb3d821255d`는 같은 전략으로 nested OOF `0.9703509469`, 가중 OOF `0.9712170271`을 기록했다.
Public `0.97135`는 사후 참고값이며 후보 판정에는 사용하지 않는다.

## 조사 범위와 방법

Kaggle API, 웹 검색 결과 요약, 직접 HTTP 요청과 리더보드 조회는 사용하지 않았다.
`agent-browser`의 별도 이름 세션과 콘텐츠 경계를 켜고 각 대회의 실제 Kaggle 공식 화면을 직접 확인했다.
각 조사는 사용자가 지정한 [`competitionWriteUps` 화면](https://www.kaggle.com/competitions/playground-series-s3e22/discussion?category=competitionWriteUps&sort=recent-comments)에서 대회 slug만 바꾸어 시작했다.
추천 수와 정렬 순서는 발견 순서로만 사용했고 표본 선정에는 쓰지 않았다.
순위는 글 제목 또는 상세 화면의 `Solution Writeup · Nth place` 표기만 사용했다.
제목에 순위가 없는 두 글은 상세 화면까지 열어 각각 507위와 479위임을 확인했다.
상위 10위 글이 없는 순위는 다른 글로 채우지 않았다.

과제와 평가지표는 Kaggle의 [S3E22 평가](https://www.kaggle.com/competitions/playground-series-s3e22/overview/evaluation), [S3E21 평가](https://www.kaggle.com/competitions/playground-series-s3e21/overview/evaluation), [S3E20 평가](https://www.kaggle.com/competitions/playground-series-s3e20/overview/evaluation) 화면에서 확인했다.
포함 글마다 본문, 작성자 표시, 순위 표시, 검증 설명, 특성, 모형, 결합, 보고 점수, 계산 자원, 외부 자료, 일반 댓글과 접힌 답글을 확인했다.
화면에 없는 팀 구성, 점수 또는 설정은 추정하지 않고 미보고로 남겼다.

## S3E22: Predict Health Outcomes of Horses

Kaggle 공식 평가 화면은 여러 의료 지표로 말의 건강 결과를 예측하는 다중 분류 과제이며 평가지표가 micro F1이라고 명시한다.
공식 해법 범주에는 14위 글 한 개만 있었고 상위 10위 글은 없었다.
따라서 S3E22에서 S6E8에 적용할 해법, 댓글 반례 또는 신규 후보를 추출하지 않는다.

## S3E21: Improve a Fixed Model the Data-Centric Way!

### 과제 구조와 적용 경계

S3E21은 예측값을 제출하는 대회가 아니었다.
참가자는 `target`과 설명변수가 들어 있는 훈련 자료를 제출했고 Kaggle은 그 자료로 고정된 RandomForestRegressor를 학습해 숨은 시험 자료를 예측했다.
고정 모형은 나무 1,000개, 최대 깊이 7, `random_state=42`였고 평가지표는 RMSE였다.
제출 자료는 표본 제출과 같은 열을 가져야 하고 결측값이 없어야 하며 행 수는 표본 제출보다 적을 수 있지만 많을 수는 없었다.

따라서 참가자가 직접 고를 수 있는 것은 모형, 확률, 결합기가 아니라 훈련 행과 값뿐이었다.
이 대회의 순위는 특정 자료 정제가 하나의 숨은 회귀 시험 자료와 고정 RandomForest에 얼마나 잘 맞았는지를 측정한다.
S6E8은 참가자가 자체 모형과 OOF 예측을 학습해 ROC AUC로 판정하므로 자료 제출, 고정 학습기와 숨은 RMSE라는 세 핵심 경계가 모두 다르다.
S3E21의 행 제거를 S6E8에서 검토하려면 일반적인 훈련 자료 선별 후보로 새로 정의하고 각 바깥 분할 안에서 제거 규칙부터 다시 적합해야 한다.
과거 순위나 Private 점수만으로는 그 후보의 분할 안전성 또는 313개 결합에 대한 한계 기여를 알 수 없다.

### 4위: Maxime Perez

[4th place solution](https://www.kaggle.com/competitions/playground-series-s3e21/writeups/maxime-perez-4th-place-solution)은 Maxime Perez의 4위 글이다.
목록과 상세 화면 모두 댓글 5개를 표시했다.

작성자는 대회 막바지에 참가해 cleanlab을 쓰려 했지만 회귀 문제에는 적용하기 어렵다고 판단했다.
최종 접근은 이상치를 제거하는 것이었다.
본문은 이상치 정의, 제거 행 수, 검증 분할, 사용 특성, CV, Public, Private, 계산 시간과 외부 자료를 보고하지 않았다.
참가자 모형과 결합이 없는 것은 공식 평가가 제출 자료로 고정 RandomForest를 학습하는 구조이기 때문이다.
댓글 다섯 개는 모두 축하였고 기술적 보충이나 반례는 없었다.

S6E8 판단은 특수 대회 해법으로는 현재 과제에 부적합하고 일반 행 선별 방법으로는 근거 부족이다.
고정 회귀 모형에 넣을 제출 자료에서 이상치를 빼는 행위는 자체 이진 분류 모형의 훈련 행을 고르는 것과 같은 판정 대상이 아니다.
글에는 재현 가능한 제거 규칙이나 제거 대조가 없어 이슈 307의 독립 제거 대조 한 건 또는 독립 성공 두 건 조건도 충족하지 못한다.

## S3E20: Predict CO2 Emissions in Rwanda

### 3위: Xuebin Jiang

[3rd Place Solution (convert the COVID affected 2020 week8-week32's emission)](https://www.kaggle.com/competitions/playground-series-s3e20/writeups/xuebin-jiang-3rd-place-solution-convert-the-covid-)은 Xuebin Jiang의 3위 글이다.
목록과 상세 화면 모두 댓글 7개를 표시했다.

작성자는 전년 대비 월별 배출량을 보고 코로나 영향이 큰 2020년 8주부터 32주까지를 이상 구간으로 정했다.
코로나 비영향 자료와 영향 자료의 주별 평균 배출량 비율을 계산하고 2020년 영향 구간의 목표값에 곱해 2019년과 2021년 평균 수준으로 바꿨다.
시험 자료가 2022년 48주까지이므로 훈련도 `week_no <= 48`로 제한했다.
결측이 없는 위도, 경도와 주차 세 특성만 사용했다.

본문에는 `Ensemble Model` 제목이 있지만 모형 이름, 구성원과 가중치는 적혀 있지 않다.
최종 예측에는 전역 배율 `1.07`을 곱했고 경도 `29.321`의 알려진 문제도 보정했다.
검증 분할, CV, Public, Private, 계산 시간과 외부 자료는 보고하지 않았다.
댓글은 축하와 감사뿐이며 기술적 보충은 없다.

S6E8 판단은 현재 과제에 부적합하다.
코로나 기간의 목표값 비율 보정, 시험 연도와 주차를 맞춘 행 선택, 위도 및 경도 문제 수정은 시공간 배출량 자료에 종속된다.
S6E8에는 연도, 주차, 공간 격자와 외부 사건 구간이 없고 ID 구간 및 train-test 이동 진단도 음성이었다.
RMSE를 위한 전역 배율은 모든 확률에 같은 양수를 곱해도 순위가 바뀌지 않는 ROC AUC에서는 점수를 바꾸지 못한다.

### 4위: Konstantin Dmitriev

[4th place solution: using PCA (least shakeuped solution)](https://www.kaggle.com/competitions/playground-series-s3e20/writeups/konstantin-dmitriev-4th-place-solution-using-pca-l)은 Konstantin Dmitriev의 4위 글이다.
목록과 상세 화면 모두 댓글 11개를 표시했다.

검증은 2019년, 2020년과 2021년을 차례로 한 해씩 빼고 나머지 두 해로 학습하는 세 분할이었다.
최종에는 세 해 전체로 학습해 2022년 배출량을 예측했다.
배출량의 공간 구조를 여섯 PCA 성분으로 줄이고 각 성분을 독립적으로 예측한 뒤 역변환했다.
`PCA1`은 과거 배출량만, `PCA2`는 모든 입력 열을 열별 여섯 PCA 성분으로 바꾸어 사용했고 `PCA_SARIMA`는 여섯 SARIMA를 사용했다.
지역 CV와 Private에서 가장 좋았던 것은 `PCA2`였다.

Ridge, Lasso, RandomForest, XGBoost와 CatBoost를 비교했고 나무 계열이 선형 회귀보다 좋았다.
나무 사이 차이는 작아 최종에는 반복 300회, 최대 깊이 4, 학습률 `0.01`, 행 표본 비율 `0.5`인 XGBRegressor를 사용했다.
최종 후보에는 `1.00`, `0.95`, `1.05`, `1.07`, `1.08`의 전역 배율을 만들었지만 가장 나쁜 판을 골랐다고 적었다.
배율을 적용하지 않은 판은 사후 1위 수준이었다고 보고했다.
본문은 정확한 CV, 최종 Public, 최종 Private과 계산 시간을 보고하지 않았다.

댓글에서 Public 최고 제출은 Public `17.99`, Private `13.18`로 약 230위였다고 답했다.
작성자는 XGBoost 설정과 나무 종류를 바꿔도 결과 차이가 작았다고 보충했다.
PCA와 XGBoost를 조합한 구조이고 여러 접근을 빠르게 바꾸려고 계층화한 코드 구조를 썼다고 설명했다.

S6E8 판단은 현재 과제에 부적합 또는 기존 결정과 중복이다.
공간별 벡터 목표를 PCA 성분으로 줄여 각 성분을 예측하는 구조는 행마다 목표 하나를 예측하는 S6E8에 대응하지 않는다.
연도별 검증과 SARIMA도 시간 순서가 없는 현재 과제에 적용되지 않는다.
일반적인 PCA와 XGBoost 이름만 보면 현재 학습기 및 원본 표현 결정의 부분집합이지만 이 글의 성공 원리는 공간 출력 압축이다.
전역 양수 배율은 ROC AUC에 무효이고 Public 최고 판의 큰 Private 하락은 Public 선택 금지의 반례로만 남는다.

| 연도별 한 해 제외 검증, 코로나 구간 목표값 보정과 2022년 주차 맞춤 | 현재 과제에 부적합 | S6E8에는 시간 순서와 사건 구간이 없고 ID 및 이동 진단도 음성이다 | 외부 278개 폭과 별개인 시계열 전용 구조다 |
| 공간별 배출량을 PCA 여섯 성분으로 압축한 뒤 독립 예측하고 역변환 | 현재 과제에 부적합 | 행마다 이진 목표 하나만 있어 벡터 목표 압축이 성립하지 않는다 | PCA 이름의 중복이 아니라 출력 구조 자체가 다르다 |
| Ridge, Lasso, RandomForest, XGBoost, CatBoost와 여러 결합 | 기존 결정과 중복 | 주요 학습기와 결합 전략이 자체 35개에 있다 | 외부 278개와 313개 결합이 더 넓은 비교 기준이다 |
| 전역 배율과 Public 점수로 제출 판본 선택 | 현재 과제에 부적합 | 양의 전역 배율은 ROC AUC 순위를 바꾸지 않고 Public은 판정 근거에서 제외된다 | 외부 예측도 고정 OOF와 nested 선택만 허용한다 |
| S3E22 상위 10위 해법 | 근거 부족 | 공식 글 자체가 없어 방법을 확인할 수 없다 | 빈 표본을 다른 순위 글로 채우지 않는다 |

새 후보 범주에 남는 방법은 없다.
S3E21의 일반 이상치 제거만 방법 이름 수준에서 비어 있지만 재현 정보와 한계 기여가 없어 근거 부족이다.
나머지는 현재 결정과 중복이거나 과제 구조에 부적합하다.

## 반복 근거와 댓글 반례

S3E20 두 글은 모두 연도와 주차 구조를 직접 이용했고 전역 배율 후처리를 사용했다.
이는 시공간 RMSE 대회에서 시간 블록 검증과 눈금 보정이 중요했다는 반복 근거이지만 정적 ROC AUC 과제의 후보가 되지는 않는다.

Public과 Private의 불일치는 S3E20 4위에서 직접 확인됐다.
Public `17.99`로 가장 좋았던 제출은 Private `13.18`과 약 230위였고, 작성자가 최종 선택하지 않은 무배율 판은 사후 1위 수준이었다.
이는 Public 점수와 사후 Private을 후보 선택에 쓰지 않는 현재 계약을 지지한다.

S3E21은 같은 `이상치 제거`라는 말도 평가 구조에 따라 다른 행위가 된다는 경계 사례다.
고정 RandomForest의 훈련 자료를 제출하는 대회에서는 행을 지우는 것이 제출물 자체를 바꾸지만 S6E8에서는 여러 자체 학습기와 그 OOF를 모두 다시 만드는 실험 설계가 필요하다.
따라서 과거 4위라는 사실만 옮기면 작동 원리와 검증 단위가 함께 사라진다.

## 적용 우선순위와 종료 조건

이번 구간만을 근거로 새 실험 티켓을 만들지 않는다.
자체 35개와 외부 278개의 현재 313개 확장 결합을 동등 단계 기준으로 유지한다.
시계열 검증, 공간 출력 PCA, 코로나 목표값 보정, 전역 배율과 고정 RandomForest용 자료 제출을 현재 실험 공간에 넣지 않는다.

일반 행 이상치 제거를 다시 검토하려면 S6E8에서 오류나 분포 오염을 나타내는 목표 독립 진단이 먼저 필요하다.
그 진단이 생겨도 제거 규칙과 문턱은 결과를 보기 전에 고정하고 각 바깥 분할의 학습 부분 안에서만 적합해야 한다.
그 뒤 같은 35개 풀 내용 해시와 핵심 결합 전략을 양쪽에서 다시 선택한 포함 및 제외 nested OOF, 바깥 분할 반복 승리와 삭제 행의 특성 장부를 남겨야 한다.
S3E21의 순위와 이상치라는 이름만으로는 이 절차를 열지 않는다.

외부 예측이라면 OOF와 시험 예측의 행 정렬, 상류 분할 준수, 출처, 라이선스와 재배포 경계를 먼저 확인해야 한다.
Public, 사후 Private, 전역 배율 판본과 선택하지 않은 제출 결과는 어떤 경우에도 개방 근거로 쓰지 않는다.

## 사실과 추론의 경계

순위, 작성자, 댓글 표시값, 본문과 댓글의 수치, 특성, 모형, 분할과 계산 시간은 Kaggle 공식 화면에 적힌 사실이다.
S3E21의 고정 모형, 제출 자료 제약과 평가 절차도 Kaggle 공식 평가 화면의 사실이다.
본문이 보고하지 않은 팀 구성, CV, Public, Private, 하드웨어와 코드 세부는 미보고로 남겼다.

네 범주 분류와 S6E8 적용 판단은 조사자의 추론이다.
특히 S3E21 이상치 제거를 특수 대회 해법과 일반 행 선별 방법으로 나눠 판정한 것, S3E20 PCA의 성공 원리가 일반 차원 축소보다 공간 출력 압축이라는 해석, 전역 양수 배율이 ROC AUC에 무효라는 판단은 원문 진술이 아니다.
