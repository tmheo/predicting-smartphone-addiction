# 결측 증강 시드 42 선별 짝비교

이 문서는 [시드 42로 결측 증강과 단순 행 복제의 1차 짝비교를 실행한다](https://github.com/tmheo/predicting-smartphone-addiction/issues/501)의 실행 결과와 판정을 기록한다.

## 결론

결측 증강군은 직접 대조군인 3배 행 대조군보다 전체 OOF AUC가 `+0.0001410348` 높아 사전 고정한 1차 관문을 통과했다.
5개 분할의 차이가 모두 양수였고, 검증 행의 기존 결측 수가 많을수록 개선 폭이 커지는 방향도 일관됐다.
따라서 단순히 같은 행을 세 번 보여 준 효과가 아니라 관측값을 독립적으로 비운 증강에 별도 효과가 있다는 가설을 다음 단계에서 확인할 가치가 있다.
이 결과는 시드 42 한 번의 선별 결과이므로 최종 채택 판정은 아니며, 다음 단계는 [세 시드 평균으로 결측 증강 효과를 확인한다](https://github.com/tmheo/predicting-smartphone-addiction/issues/502)이다.

## 전체 결과

| 학습군 | OOF AUC | 원본 기준 차이 | 학습 행 구성 |
| --- | ---: | ---: | --- |
| 일반 기준군 | `0.9686391854` | 기준 | 원본 학습 행 1배 |
| 3배 행 대조군 | `0.9685956547` | `-0.0000435308` | 원본과 같은 행을 3배로 복제하고 추가 결측은 만들지 않음 |
| 결측 증강군 | `0.9687366895` | `+0.0000975041` | 원본 1배와 독립 결측 마스크를 적용한 복제본 2배 |

직접 판정값인 결측 증강군과 3배 행 대조군의 차이는 `+0.0001410348`이다.
행 수와 반복 노출 횟수가 같은 두 군을 직접 비교했으므로 이 차이는 단순 행 복제 효과와 분리된 결측 증강 효과를 나타낸다.
가중 OOF AUC도 결측 증강군 `0.9696248075`, 3배 행 대조군 `0.9694904892`로 같은 방향이었다.

## 실행 무결성

세 학습군은 커밋 `1aa1cafc4abab6dd61f89e983b7ed11c7248764e`, 동일한 입력 자료, 동일한 고정 5분할, 시드 42, 동일한 기계에서 순차 실행했다.
원본 학습 자료 SHA-256은 `f4669147311c76eb03496061a852af283efcf0f12cf5c19274e775def81edd9c`이고, 분할 파일 SHA-256은 `5f5d09e9356f227ecb4a063270b175bb5cae20afb25636c563db185e18a155c4`이다.
결측 증강군은 원래 관측된 학습 셀 59,408,544개 중 14,851,230개를 추가로 비워 실측 비율 `24.99847497%`를 만들었다.
분할과 복제본별로 만든 10개 마스크는 모두 서로 다른 결정적 해시를 가졌다.
3배 행 대조군과 결측 증강군은 부모 행 순서, 목표값 순서, 행 수가 일치했고 검증 및 시험 자료에는 증강을 적용하지 않았다.
목표 통계 인코딩은 복제본을 통계 산출에서 제외하고 부모 행의 바깥쪽 분할, 목표값, 위약 잡음을 물려받으며 증강된 원자료에서 결측 마스크만 다시 계산한다는 점검을 통과했다.
세 실행 묶음은 중앙 MLflow로 가져온 뒤 OOF, 입력 자료, 출처, 관측 기록, 산출물 해시를 다시 검증했다.

## 학습 길이 관찰과 후속 결정

현재 설정의 최대 반복 횟수는 20,000회다.
3배 행 대조군은 5개 분할 중 4개가 19,956회 이상에서 멈췄고, 결측 증강군은 한 분할이 정확히 20,000회에 닿았으며 두 분할도 19,947회 이상이었다.
따라서 20,000회 제한이 일부 분할의 충분한 조기 종료를 막았을 가능성이 있다.
다만 현재 지도의 비교 계약은 학습 길이를 포함해 고정되어 있으므로 바로 이어지는 3시드 확인은 20,000회를 유지한다.
사용자가 선택한 50,000회와 같은 조기 종료 조건의 재실행은 현재 지도 밖의 별도 후속 실험으로 기록하며, 결측 증강의 효과와 학습 길이 여유의 효과를 섞지 않는다.
