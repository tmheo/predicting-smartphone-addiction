# Contextualized Spline Transformer 제약 복원 구간 폭 3열 짝비교

## 결론

제약 복원 구간 폭 3열을 더한 `exp137_contextual_spline_recon_widths`의 seed 42 OOF AUC는 `0.9659886216`이었다.
같은 조건의 `exp085_contextual_spline_m0`은 `0.9671782981`이므로 짝차이는 `-0.0011896765`다.
비음수 선별 관문을 통과하지 못해 3시드 확인, 후보 풀 직접 교체와 포함·제외 중첩 OOF는 실행하지 않았다.
기존 `exp085_contextual_spline_m0`을 후보 풀에 유지하고 장부는 바꾸지 않는다.

## 구현과 비교 규율

후보 설정은 `exp085_contextual_spline_m0`의 `constrained_impute_aux.widths`만 `false`에서 `true`로 바꿨다.
그 결과 `gaming_hours_recon_width`, `social_media_hours_recon_width`, `work_study_hours_recon_width`만 추가되어 모델 입력은 33열에서 36열로 늘었다.
모델 종류, 수치 변환, 정확값 열, 원래 피처와 나머지 제공자 설정은 같게 고정했다.
회귀 테스트는 두 설정의 허용된 차이와 실제 추가 열 집합을 함께 검사한다.

## 실행 무결성과 원격 정리

기준과 후보는 고정 커밋 `43738535e92c2d99eb0509b4af536cc3311a0e4e`, 같은 입력 해시와 같은 5분할에서 각각 seed 42로 실행했다.
두 원격 실행은 변경 사항이 남지 않은 상태였고, 원격 실행 식별자는 기준 `8dc1a2ed76c64713b70f0e5837424065`, 후보 `30eabe7f2e2249659b7fbb8127b11590`이다.
결과 묶음의 원격과 로컬 SHA-256은 `6be8423042375e513d97e20172d4455a26e5b612b672d975c21ffd8d17ff7b53`로 일치했고 내부 산출물 manifest도 통과했다.
주 실행 저장소에 반입한 실행 식별자는 기준 `dc1ce01277f5472987e83b2135ad32dd`, 후보 `d96c06ab2a4f49178465b8e67a00ce73`이며 OOF 재채점과 필수 산출물 조회를 확인했다.

첫 원격 시도는 외부 입력 파일 하나가 전송 묶음에 빠져 학습 시작 전에 종료됐다.
원격 입력을 고치지 않고 선언된 외부 입력을 포함한 새 작업 묶음을 만들었으며 실패 결과도 별도 보존했다.
두 번째 실행 중 원격 접속 주소가 바뀌어 관측 연결이 잠시 끊겼지만 제공자 계측에서 학습 진행을 확인했고 재연결 뒤 작업이 정상 완료됐음을 검증했다.
첫 시도와 본 실행을 합친 추정 비용은 약 `0.368달러`다.
결과 보존과 MLflow 반입 뒤 이 작업의 계산 인스턴스를 삭제했고 별도 저장 공간과 종료 예약이 남지 않았음을 확인했다.
