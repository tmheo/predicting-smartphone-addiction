# Trompt 진입 진단

이 문서는 GitHub 이슈 [Trompt 재검토와 champion 교체·후보 풀 다양성 기여 결정](https://github.com/tmheo/predicting-smartphone-addiction/issues/145)의 구현과 Vast.ai fold 0 진입 진단 결과를 기록한다.

## 결론

Trompt는 fold 0 seed 42의 첫 epoch에서 AUC `0.9401445165`를 기록했다.
같은 fold의 champion AUC `0.9685285491`보다 `0.0283840326` 낮아 허용 폭 `0.01`을 넘었다.
첫 epoch는 `572.1108`초였고 50 epoch seed 42 5-fold 학습 예상 시간은 `143,027.7011`초, 약 `39.73`시간이었다.
예상 시간도 `24`시간 한도를 넘었으므로 성능과 시간 중단 조건이 모두 발생했다.
이슈 규칙에 따라 seed 42 5-fold, 중복·표준 순위 평균 기여 측정과 3시드 확정 재검증은 실행하지 않는다.
champion과 후보 풀은 바꾸지 않는다.

## 구현

`src/pipeline/trompt.py`에 TALENT 판본을 기준으로 수치·범주 임베딩, 행별 열 중요도, 여섯 Cell과 공유 decoder를 구현했다.
기준 구현은 [LAMDA-Tabular/TALENT](https://github.com/LAMDA-Tabular/TALENT)의 MIT 판본 커밋 `08301d670a7c854bcf3a73298763484ba58eecdb`이고 원 논문은 [Trompt: Towards a Better Deep Neural Network for Tabular Data](https://proceedings.mlr.press/v202/chen23c.html)다.
각 Cell의 이진 교차 엔트로피를 함께 학습하고 추론에서는 여섯 Cell의 logit 평균을 확률로 바꾼다.
`TromptAdapter`와 모델 등록부의 `trompt` 항목을 통해 기존 실행 계약에 연결했다.
`MissingIndicators` 특성 공급자는 지정한 아홉 열의 결측 여부를 0과 1로 내보낸다.
설정 `configs/exp086_trompt.yaml`은 champion의 33개 특성에 이 결측 표시 9개를 더한 42개 특성을 사용한다.
Trompt 전용으로 고정한 결측 표시는 일반 결측 특성 탐색이 아니라 모델 입력 계약의 일부다.

TALENT 기준값인 prompt `128`, 폭 `128`, Cell `6`, 학습률 `0.0003`, 가중치 감쇠 `0.00001`, 최대 `50` epoch와 조기 종료 대기 `5` epoch를 사용한다.
수치 열의 중앙값 대치와 표준화, 범주 열 사전은 outer 학습 fold에서만 맞춘다.
순열 중요도는 seed 고정 검증 표본 8,192개와 반복 1회를 사용하도록 구현했지만 진입 중단 뒤에는 계산하지 않았다.

## 진입 경계 보강

로컬 CPU 시험만으로 드러나지 않은 두 CUDA 경계를 실제 GPU 실행에서 재현하고 고쳤다.
첫째, PyTorch 결정론 모드의 첫 CuBLAS 연산이 `CUBLAS_WORKSPACE_CONFIG` 부재로 중단됐다.
Trompt 모듈이 PyTorch를 불러오기 전에 유효한 값 `:4096:8`을 고정하고 진단 관측값으로 남기도록 수정했다.
둘째, 학습 배치 256 용량 검사는 통과했지만 검증 배치 4,096이 GroupNorm에서 10.5GiB 추가 할당을 요구해 메모리 부족이 났다.
검증 배치를 용량 검사에서 선택한 학습 배치 이하로 제한해 실제 유효값을 256으로 낮췄다.

첫 epoch의 평균 시간에 설정된 50 epoch와 5개 fold를 곱한 예상 시간이 24시간을 넘으면 학습을 중단한다.
이때 이미 얻은 검증 예측과 진단값은 저장하되 테스트 예측과 순열 중요도는 계산하지 않는다.
공통 진입 진단은 이 모델 중단 사유와 예상 시간을 구조화된 중단 결과에 포함한다.

## 공개 자료 정상 작동 확인

`sklearn.datasets.load_breast_cancer` 공개 이진 분류 자료에서 TALENT 기준 구조를 먼저 실행했다.
prompt 128, 폭 128, Cell 6을 그대로 사용했고 학습 손실은 `0.5089973171`에서 `0.0701000633`으로 줄었다.
검증 AUC는 `0.9972746331`이었고 같은 seed 반복의 예측과 Cell 손실은 정확히 일치했다.
이 확인을 통과한 뒤에만 대회 자료 fold 0 진단을 시작했다.

## 원격 실행 복구와 비용

첫 Vast.ai 호스트는 실행 상태 뒤 5분 동안 계정에 등록된 대회 전용 SSH 키를 받아들이지 않아 입력 전송 없이 삭제했다.
서로 다른 두 호스트 실패 뒤에만 Runpod으로 전환한다는 규칙에 따라 다른 Vast.ai 호스트를 선택했고 SSH와 환경 사전 검사를 통과했다.
두 번째 실행은 CuBLAS 결정론 설정 부재, 세 번째 실행은 과도한 검증 배치에서 각각 중단됐다.
각 실패 결과를 SHA-256으로 회수하고 자원을 정리한 뒤 새 커밋, 작업 식별자와 원격 경로로 다시 실행했다.
네 번째 실행에서 공개 자료 확인과 구조화된 fold 0 중단 진단을 완료했다.

네 인스턴스의 확정 청구액은 차례대로 `$0.035`, `$0.018`, `$0.045`, `$0.049`이고 합계는 `$0.147`이다.
모든 Trompt 인스턴스와 별도 저장 공간이 계정 목록에서 사라졌고 GitHub 보조 종료 일정도 제거했다.
대회 전용 Vast.ai SSH 키는 대회 단위 고정 키이므로 삭제하지 않았다.

## 판정

Trompt는 공개 자료 학습, batch 256 용량, 결정론, 검증 행 무결성과 CUDA 메모리 관문을 통과했다.
그러나 fold 0 AUC와 5-fold 예상 시간 관문을 모두 통과하지 못했다.
따라서 이번 판본은 champion 교체 후보도 후보 풀 다양성 측정 대상도 아니다.
