# 조회 변환기 원본 프록시 CDF 차이 5열 짝비교

## 결론

원본 프록시 CDF 차이 5열을 더한 `exp141_lookup_orig_cdf_diff`의 seed 42 OOF AUC는 `0.9691454430`이었다.
같은 seed 42의 챔피언 `exp131_lookup_bivariate_plr5`는 `0.9691984425`이므로 짝차이는 `-0.0000529995`다.
분할 승수는 2/5였고 비음수 선별 관문을 통과하지 못했다.
이슈 #262의 사전 등록 계약에 따라 3시드 확인 실행은 시작하지 않았다.
챔피언과 후보 풀 장부는 바꾸지 않는다.

## 구현과 비교 규율

후보 설정은 챔피언 설정에 `original_cdf_diff` 제공자 하나만 추가했다.
추가 열은 `daily_screen_time_hours_orig_cdf_diff`, `weekend_screen_time_orig_cdf_diff`, `social_media_hours_orig_cdf_diff`, `notifications_per_day_orig_cdf_diff`, `app_opens_per_day_orig_cdf_diff`다.
다섯 열은 조회용 열 목록 밖에 있어 PLR 수치 입력으로만 들어간다.
KDE 로그 밀도비 열은 열지 않았다.
모델 설정, 기존 제공자, 범주형 열, 제외 열과 조회용 열 목록은 챔피언과 같게 고정했다.
구성 회귀 시험은 후보와 기준의 차이가 이름과 `features.providers.original_cdf_diff`뿐임을 검사한다.

분할별 값은 후보와 챔피언의 `oof_seed_42.parquet`를 같은 행 순서와 같은 목표값으로 다시 채점한 결과다.
챔피언 실행의 `auc_fold_*`는 3시드 평균 예측 지표이므로 seed 42 짝비교의 분할 기준으로 사용하지 않았다.
공식 선별 관문은 전체 seed 42 OOF 차이 `0` 이상이며 후보는 이 조건에 미달했다.
따라서 피처 묶음 신호는 `실신호 미확인`으로 기록했다.

## 실행 무결성과 원격 정리

후보는 고정 커밋 `408b833c8a2b3daa532f1ecec7b5c6a2062098cd`, 같은 학습 자료, 시험 자료와 5분할에서 실행했다.
독립 환경 검사에서 비공개 입력, 원격 Python 계약 시험 4개와 전체 시험 526개가 통과했다.
정확한 고정 컨테이너 이미지의 Python 가상환경 검사도 통과했다.
원격 실행은 사용자 결정에 따라 Vast.ai만 사용했고 Runpod 자원은 만들지 않았다.

첫 RTX A4000 4장 인스턴스에서 4개 분할을 완료한 뒤 2시간 수동 상한 전에 실행을 종료했다.
4개 분할 복구 묶음 SHA-256은 `97dbc13a4428b97f5dccae0b0729b427c5f4f0d9f54a2948fe88ac901f2d7ac4`다.
첫 인스턴스의 중간 결과를 검증하고 자원을 삭제한 다음 같은 RTX A4000 등급의 새 Vast.ai 인스턴스에서 마지막 분할을 이어서 계산했다.
재개 입력 묶음 SHA-256은 `b4b23985ac47d185c24233c5918d0bd0acf35fd365516aa084cd0699f582028c`다.
완성 결과 묶음의 원격과 로컬 SHA-256은 `6df8cde7aa94f681294880df3bc3bd584fabe0dfc9918693b14354047d5d6131`로 일치했다.
내부 파일별 해시, 종료 코드 0과 복구 선언 파일 5개를 확인했다.

원격 실행 식별자 `442abc71ad904f38982aa33a0474f8d9`의 후보 묶음을 기본 MLflow에 `62fda29e3d784c248d0edf0d5447d2ea`로 반입했다.
반입 과정에서 OOF를 로컬 목표값으로 다시 채점하고 필수 산출물을 조회했다.
두 Vast.ai 인스턴스를 모두 삭제했고 대상 목록 부재, 별도 저장 공간 0건과 이 작업의 종료 일정 부재를 확인했다.
같은 계정의 다른 작업과 잔액 변동이 겹쳐 이 작업의 단독 비용은 계정 잔액 차이로 산정하지 않았다.

공식 판정은 `artifacts/judgments/issue293-exp141-lookup-orig-cdf-diff-screen.yaml`에 보존한다.
