# 교사-학생 잔차 보정 가중치 중첩 선택

이 문서는 GitHub 이슈 316에서 의사 목표 총 영향력 `rho`와 잔차 보정 가중치 `beta`를 목표값 누출 없이 선택한 실행과 판정을 기록한다.

## 결론

중첩 선택기는 다섯 바깥 분할과 전체 자료 선택에서 모두 `rho=0`, `beta=0`을 골랐다.
중첩 선택 OOF AUC는 현재 풀 기준과 같은 `0.9697435407980921`이고 차이는 `0`이다.
바깥 분할 승리는 0/5이므로 공식 풀 채택 조건과 최종 순위 보정 조건을 모두 통과하지 못했다.
후보 풀, 전체 자료 재학습 계획과 제출 후보는 바꾸지 않는다.

## 고정 기준

실행 결과를 보기 전에 현재 32개 풀과 탐색 계약을 설정과 이슈 코멘트에 고정했다.

의사 목표 총 영향력 후보는 `{0, 0.025, 0.05, 0.10, 0.125, 0.20, 0.40, 0.80}`이다.
잔차 보정 가중치 후보는 `{0, 0.0125, 0.025, 0.05, 0.075, 0.10, 0.15, 0.20, 0.30}`이다.
`beta=0`은 `rho=0` 한 후보로 정규화해 총 65개 후보를 비교했다.
동률이면 AUC, 안쪽 분할 승리 수, 더 작은 `beta`, 더 작은 `rho` 순서로 선택했다.

## 목표값 경계

각 바깥 검증 목표값은 교사 학습, 학생 학습, 조기 종료, 후보 선택과 잔차 신호 조정에서 제외했다.
안쪽 선택에 쓰는 기준 풀 예측도 현재 바깥 분할과 현재 예측 분할을 조합기 학습에서 제외한 이중 중첩 산출물로 다시 만들었다.
교사 예측은 같은 바깥 및 안쪽 분할 안에서 `rho`와 무관하므로 후보 사이에서 재사용했다.
의사 목표 행별 가중치는 `rho * labeled_row_count / pseudo_row_count`로 계산했다.
공식 전체 OOF 점수는 다섯 바깥 예측을 합친 뒤 기준 예측 전체를 한 번만 순위화해 계산했다.
분할별 순위화 점수는 별도 진단값으로만 저장하고 판정에서 제외했다.

## 구현과 검증

중첩 선택기는 `src/pipeline/teacher_student_residual_selection.py`에 별도 실행 경로로 구현했다.
기존 `rho=0`, `beta=0.10` 경로는 `src/pipeline/teacher_student_residual.py`에 고정 대조군으로 유지했다.
실행 설정은 `configs/exp138_teacher_student_nested_selection.yaml`이다.
목표값 경계, 학습 행 겹침, 후보 동률 규칙, 복구 파일 재사용과 실행 기록 묶음 내보내기를 자동 시험으로 검증했다.
커밋 격리 상태의 `scripts/verify_environment_gates.sh --isolated`에서 원격 Python 계약 시험 4개와 전체 시험 426개가 통과했다.

고정 대조군은 방향 반복성을 다시 보였지만 공식 채택 문턱 `+0.00002`의 약 17%에 그쳤다.
고정 대조군은 중첩 선택 결과가 아니므로 작은 개선 구간의 최종 보정 후보로 채택하지 않는다.
중첩 선택은 모든 바깥 학습 부분에서 보정 없음을 골랐고 전체 OOF에서도 개선을 만들지 못했다.
이 결과는 고정 `beta=0.10`의 작은 이득을 시험 자료에 자동 적용할 근거가 없음을 뜻한다.

## 실행 식별자와 무결성

구현 커밋은 `b8a1837bdc55e18eb4c05b7b08ace5668a57310e`다.
원격 고정 대조군 실행은 `be2ea1b736c54bda936a143cd0a401e2`이고 main 실행 저장소 반입 실행은 `7a6201b3ca6e43a0ba61bf22d04affa0`이다.
원격 중첩 선택 실행은 `a10ed94449cf4707af629dda1e612b31`이고 main 실행 저장소 반입 실행은 `584ade6f76394c6db16e2ab82a726be8`이다.
두 반입 실행은 로컬 목표값 재채점, 입력 해시, 출처 커밋과 깨끗한 작업 폴더 검증을 통과했다.
고정 대조군 실행 묶음 SHA-256은 `13402c7c1518bbe7ea42b99d31da2cc7a2e8ec927d22f3961eac5b65de8e6253`이다.
중첩 선택 실행 묶음 SHA-256은 `5acaec747813ac3c5e23c7730cb793960780fd2438ff519ae85b745af96bc082`다.
회수한 전체 결과 묶음 SHA-256은 `7714e119a9ea8ac094748687f9c6212d15f7e62ae4db338fb60720962b460682`다.
결과 묶음의 원격과 로컬 SHA-256이 일치했고 내부 산출물 58개의 해시가 모두 통과했다.

중첩 선택 프로세스는 결과와 완료 실행 식별자를 기록한 뒤 Python 종료 과정에서 상태 코드 139를 반환했다.
그 전에 OOF, 시험 예측, 후보표, 결과 JSON과 완료된 실행 기록이 모두 저장됐다.
저장된 실행 식별자를 별도 프로세스에서 내보낸 실행 묶음이 검증을 통과했고 main 반입에서 다시 재채점됐으므로 모형 결과 자체는 유효하다.
