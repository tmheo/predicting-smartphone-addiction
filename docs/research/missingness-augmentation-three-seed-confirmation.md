# 결측 증강 세 시드 확인

이 문서는 [세 시드 평균으로 결측 증강 효과를 확인한다](https://github.com/tmheo/predicting-smartphone-addiction/issues/502)의 실행 결과와 판정을 기록한다.

## 결론

결측 증강군은 세 시드 평균 OOF AUC에서 직접 대조군인 3배 행 대조군보다 `+0.0001624974` 높아 사전 고정 관문을 통과했다.
평균 차이 관문의 최소값은 `+0.0000200000`이었다.
시드별 승수는 `3/3`, 평균 분할별 승수는 `5/5`로 두 보조 관문도 통과했다.
따라서 다음 단계는 [사전 등록 후보군을 구성한다](https://github.com/tmheo/predicting-smartphone-addiction/issues/503)이다.
이 판정은 결측 증강 후보군 구성을 허용하며, 아직 최종 채택이나 제출을 뜻하지 않는다.

## 실행 무결성

세 실행은 커밋 `7f714622653185b0eda0519716ce633f79edf1c3`의 깨끗한 작업 트리에서 같은 로컬 기계로 순차 실행했다.
원본 학습 자료 SHA-256은 `f4669147311c76eb03496061a852af283efcf0f12cf5c19274e775def81edd9c`이고 분할 파일 SHA-256은 `5f5d09e9356f227ecb4a063270b175bb5cae20afb25636c563db185e18a155c4`이다.
시드 42는 같은 설정·입력·의존성·OOF·분할·시험 행을 재검증한 뒤 기존 선별 실행에서 재사용했고, 시드 43과 44는 새로 학습했다.
결측 증강군은 원래 관측된 학습 셀 178,225,632개 중 44,553,016개를 추가로 비워 실측 비율 `24.99809679%`를 만들었다.
시드·분할·복제본별 마스크 30개는 모두 서로 다른 결정적 해시를 가졌다.
3배 행 대조군과 결측 증강군은 부모 행 순서, 원본 행 번호 순서, 목표값 순서, 전체 행 수가 일치했다.
검증 및 시험 자료에는 증강을 적용하지 않았다.
목표 통계 인코딩은 복제본을 통계 산출에서 제외하고 부모 분할·목표값·위약 잡음을 물려받으며 증강 원자료에서 결측 마스크만 다시 계산한다는 검사를 통과했다.
피처 중요도에서도 목표 통계 인코딩 위약 카나리아가 원본 위약 피처보다 낮아 누수 관문을 통과했다.

첫 원본 실행 `ee17ca6cf05647129b56d5761816e084`은 재사용 시드의 피처 이름 순서를 잘못 보존해 최종 평가에서 실패했다.
실패 원인을 실제 실행으로 재현한 뒤 현재 피처 계획의 선언 순서를 보존하도록 고쳤으며, 실패 실행의 결과는 판정에 사용하지 않았다.
수치, 시드·분할별 결과, 결측 수 구간, 입력·산출물 해시, 마스크 기록, 재사용 검증 내용은 `artifacts/issue502-three-seed-missingness-confirmation.json`에 기계 판독 가능한 형태로 보존한다.

## 학습 길이 관찰

세 배 행 대조군과 결측 증강군의 다수 분할이 20,000회 상한에 닿거나 매우 가까이 갔다.
현재 지도 판정은 학습 길이를 포함해 사전 고정한 조건을 유지했으므로 이 관찰 때문에 설정을 바꾸지 않았다.
학습 길이 확대 효과는 현재 지도 밖의 별도 실험으로 다뤄야 한다.
