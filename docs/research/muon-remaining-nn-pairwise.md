# 나머지 신경망 계열 Muon 혼성 최적화 짝비교

이 문서는 GitHub 이슈 [Muon 혼성 optimizer를 풀의 나머지 NN 구성원에 적용해 짝비교한다](https://github.com/tmheo/predicting-smartphone-addiction/issues/280)의 구현, 원격 실행과 판정 근거를 기록한다.
대상은 후보 풀의 `exp124_realmlp_dtype_fix`와 `exp085_contextual_spline_m0`이며, 각 설정에서 최적화 방식만 Muon 혼성 구성으로 바꿨다.

## 결론

RealMLP Muon판 `exp134_realmlp_muon`은 시드 42 스크리닝에서 `+0.0000879950`으로 문턱을 통과했다.
시드 42, 43, 44 확정 재검증의 평균 OOF는 `0.9684260631`로 원본보다 `+0.0001037173` 높았고 시드 3개와 폴드 5개에서 모두 개선됐다.
원본과의 스피어만 순위 상관은 `0.9869465711`로 중복 기준 `0.998`보다 낮아 두 RealMLP 구성원을 후보 풀에 함께 유지한다.

Contextual spline Muon판 `exp135_contextual_spline_muon`은 시드 42 OOF가 `0.9651901914`로 원본보다 `-0.0009332079` 낮았다.
중단 조건에 따라 이 계열은 확정 재검증 없이 닫고 원본 `exp085_contextual_spline_m0`만 유지한다.

## 혼성 매개변수 분할

공통 `hybrid_parameter_groups`는 기존 매개변수 그룹의 학습률과 가중치 감쇠를 보존하면서 선택한 2차원 행렬만 Muon으로 분리한다.
`MuonWithAdamW`는 RealMLP의 AdamW 운동량 계수도 그대로 전달해 최적화 방식 이외의 학습 계약을 유지한다.

RealMLP의 은닉 가중치는 내부 앙상블 축을 가진 3차원 텐서라 그대로는 Muon 대상이 될 수 없다.
Muon 구성에서만 같은 초기 3차원 난수 텐서를 내부 앙상블별 2차원 매개변수로 나누고, 순전파 때 다시 쌓아 원본 초기화와 계산을 보존한다.
은닉 행렬만 Muon으로 보내고 출력층, 수치·범주 임베딩, 편향, PBLD와 크기 조절 매개변수는 AdamW에 남긴다.

Contextual spline은 은닉 `Linear.weight`와 다중 머리 주의층의 `in_proj_weight`를 Muon으로 보낸다.
가산 예측 머리와 최종 출력층, 임베딩, 비선형 표, 편향은 AdamW에 남긴다.

시드별 예측 사이 스피어만 상관의 평균은 원본 `0.9980784239`에서 Muon판 `0.9917360899`로 낮아졌다.

## 후보 풀 판정

후보 진입 하한은 통과했고 최근접 구성원은 원본 exp124였다.
두 평균 OOF의 스피어만 순위 상관은 `0.9869465711`로 중복 기준보다 낮아 원본을 교체하지 않는다.
표준 평가 앙상블의 OOF는 후보 없이 `0.9690156292`, 후보 포함 `0.9690456786`으로 참고 변화는 `+0.0000300494`다.
확정 실행을 29번째 후보 풀 구성원으로 등록했고 전체 자료 재학습에는 원본과 같은 시드별 5 epoch를 기록했다.

## 실행 무결성과 자원 정리

모든 스크리닝과 확정 재검증은 커밋 `c792484169b56190323c01731f2e9d510c60e0be`, 같은 학습·시험·분할 자료 해시와 Vast.ai RTX A4000에서 실행했다.
각 반입 실행에서 깨끗한 Git 상태, 입력 해시, 특성 집합과 `optimizer: muon` 이외의 모형 설정 동일성을 확인했다.
최신 `main`을 반영한 워크트리 환경 관문은 비커밋 입력 검증, 시험 수집 397건, 원격 Python 계약 4건과 전체 시험 397건을 통과했다.

확정 재검증 준비 중 두 자원을 SSH 장애로 잘못 판정해 입력 전송 전에 삭제했다.
원인은 `ssh-keyscan`에 `사용자명@호스트` 전체를 넘긴 로컬 검사 명령 오류였고, 호스트 이름만 분리한 뒤 동일 장비에서 인증과 실행을 정상 완료했다.
두 잘못된 판정 자원에는 입력과 실험 실행이 없었으며 불필요한 비용은 합계 약 `$0.03777`이다.

스크리닝 두 건, 잘못 판정한 준비 자원 두 건과 확정 재검증 한 건의 추정 비용 합계는 약 `$0.46766`이다.
모든 결과를 회수하고 SHA-256 및 주 실행 기록 저장소 반입을 확인한 뒤 이 작업이 만든 인스턴스와 별도 저장 공간을 삭제했다.
각 자원의 목록 부재와 이 작업의 외부 종료 예약 제거를 확인했다.
