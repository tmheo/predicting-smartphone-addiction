# 표 합성곱망 fold 0 진입 진단

이 문서는 GitHub 이슈 177의 표 합성곱망 `M0`와 매개변수 규모를 맞춘 완전연결 제거 대조 `A0`를 fold 0, seed 42에서 비교한 결과다.
주목표는 champion 교체가 아니라 3시드 5-fold 다양성 확정 재검증으로 진입할 근거가 있는지 판단하는 것이다.

## 결론

세 진입 조건을 모두 통과했다.

| 조건 | 결과 | 판정 |
| --- | ---: | --- |
| M0 AUC가 A4000 기준 exp081 AUC에서 0.01 이내 | `0.9599919083 >= 0.9585566249` | 통과 |
| M0 AUC가 A0 AUC보다 큼 | `+0.0047284574` | 통과 |
| 위약 열과 adapter 무결성 검사 | M0와 A0 모두 전체 통과 | 통과 |

따라서 M0를 3시드 5-fold로 확정 재검증하는 후속 작업을 연다.
A0는 새 모델 계열의 독립 진입 하한에는 못 미쳤지만, 이 티켓에서 A0의 역할은 M0의 합성곱 상호작용을 제거한 구조 대조다.
M0가 A0보다 명확히 높으므로 구조 기여 조건은 충족한다.

## 실행 결과

| 실행 | fold 0 AUC | 기준 대비 | M0 대비 | 총 진단 시간 |
| --- | ---: | ---: | ---: | ---: |
| exp081 A4000 기준 | `0.9685566249` | 기준 | `+0.0085647166` | `2,088.25초` |
| M0 표 합성곱망 | `0.9599919083` | `-0.0085647166` | 기준 | `1,011.14초` |
| A0 완전연결 대조 | `0.9552634509` | `-0.0132931740` | `-0.0047284574` | `894.14초` |

M0와 A0의 진단 시간 합계는 `1,905.28초`, 약 `0.5293 GPU시간`이다.
이는 중요도 계산을 포함한 예약 상한 `1.5 GPU시간` 안이다.
M0의 seed 42 5-fold 예상 시간은 `5,029.88초`, 약 `1.40 GPU시간`이다.

## 동등 단계 기준과 GPU 차이

저장된 exp081 fold 0, seed 42 AUC는 `0.9684993008`이고 Runpod A40에서 생성됐다.
Vast.ai RTX A4000 재실행 AUC는 `0.9685566249`로 `+0.0000573241` 달랐다.
입력, fold, 설정, 커밋과 잠금 파일의 내용 해시는 모두 일치했고, 서로 다른 A4000 장비에서 중간 학습 손실과 AUC가 같은 값으로 반복됐다.
따라서 이 차이는 입력이나 구현 손상보다 GPU 종류에 따른 부동소수점 학습 경로 차이로 해석한다.

공통 진단의 기본 허용 범위 `1e-9`는 유지했다.
이번처럼 다른 GPU 종류에서 동등 단계 기준을 다시 만드는 경우에만 명시할 수 있는 상한 `0.0002`를 추가했고, 실제 허용 범위와 차이를 기준 진단 JSON에 기록했다.
이 상한은 이 티켓의 새 모델 계열 진입 여유 `0.01`의 2%다.

## 구조와 무결성

M0는 학습 fold에서만 범주 어휘와 분위수 변환을 맞춘다.
숫자 표현은 12개 구간의 구간별 선형 표현과 12차원 주기 표현을 결합한다.
상호작용 경로는 `Conv1d 32 -> 64 -> 128`, 채널 재가중, 평균 및 최댓값 전역 요약과 원시 입력 우회를 사용한다.
학습은 최대 30회, AdamW, 코사인 온재시작, 다중 표본 드롭아웃을 사용했다.

A0는 입력 표현, 원시 입력 우회와 학습 설정을 유지하고 합성곱 상호작용만 완전연결 상호작용으로 바꿨다.
M0의 전체 학습 매개변수는 `87,301`개이고 A0는 `86,716`개다.
상호작용 경로 매개변수는 M0 `39,488`개, A0 `38,903`개로 상대 차이 `1.4815%`다.

두 후보 모두 다음 검사를 통과했다.

- 전처리 적합 행은 학습 fold 행과 일치한다.
- 검증 목표값은 전처리에서 제외된다.
- 정확값 목표 인코딩과 빈도 인코딩은 없다.
- `placebo_noise`가 실제 학습 행렬에 있다.
- 상호작용 경로의 매개변수 규모가 5% 이내로 맞는다.
- 중요도 값이 모두 유한하다.

M0의 위약 열 순열 중요도는 `-0.0000596243`이고 A0는 `0.0001028104`다.
위약 열은 후보 선택에 쓰이지 않았고 두 값 모두 전체 중요도 산출물에 유한값으로 남았다.
