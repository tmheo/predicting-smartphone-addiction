# 표 합성곱망 3시드 5-fold 확정 재검증

이 문서는 GitHub 이슈 [P3 확정: 표 합성곱망 3시드 5-fold 다양성 재검증](https://github.com/tmheo/predicting-smartphone-addiction/issues/216)의 실행과 후보 풀 진입 판정을 기록한다.
대상은 진입 진단을 통과한 `configs/exp113_tab_cnn_m0.yaml`이며 seed 42, 43, 44와 커밋된 5개 fold를 그대로 사용했다.

## 결론

3시드 평균본의 OOF AUC는 `0.9620748339`로 진입 하한 `0.9591957618`을 `0.0028790721`만큼 넘었다.
후보 풀의 최근접 구성원과 스피어만 상관은 `0.9638799271`로 중복 기준 `0.998`보다 낮았다.
표준 평가 앙상블의 참고 AUC는 후보 제외 시 `0.9688447112`, 포함 시 `0.9688734036`으로 `+0.0000286924` 변했다.
15개 seed-fold 조합의 위약 열, 예측과 중요도 유한성, 전처리 누출 방지 검사를 모두 통과했다.

따라서 원본 실행 `a3c4f73cce764f8f85c3620631f16a71`을 `main`의 MLflow에 반입한 실행 `b47a4184249746cdb1d062aa98364437`을 `artifacts/pool.yaml`에 등록했다.
이 결과는 champion 교체가 아니라 P4 중첩 OOF 평가에 넘길 다양성 구성원이다.
전체 자료 재학습 계획에는 시드별 최적 epoch 중앙값 29에 규약 배수 1.25와 사사오입을 적용한 36 epoch를 기록했으며, 이 이슈에서는 해당 재학습을 실행하지 않았다.

## 실행 무결성

최종 결과에는 seed-fold 조합 15개의 진단 자료와 복구 manifest 15개가 있다.
최종 합산 실행은 15개 체크포인트를 모두 내용 해시와 실행 정체성으로 검증해 재사용했다.
OOF 691,369행과 시험 예측 296,302행은 모두 유한값이며 중요도 값도 모두 유한하다.
각 조합의 전처리 적합 행 수는 학습 행 수와 같고, 학습 행과 검증 행의 합은 전체 학습 자료 691,369행과 같다.

모든 조합에서 다음 검사가 참이었다.

- 전처리는 학습 fold 행에만 맞췄다.
- 검증 목표값은 전처리에서 제외했다.
- 정확값 목표 인코딩과 빈도 인코딩은 없다.
- `placebo_noise`가 실제 학습 행렬에 있다.
- 합성곱 상호작용 경로의 매개변수 규모가 기준과 일치한다.

위약 열 중요도 범위는 `-0.0001718570`부터 `0.0002801589`까지이고 절댓값 최대는 `0.0002801589`다.
최고 할당 CUDA 메모리는 393,394,176바이트이고 최고 예약 CUDA 메모리는 513,802,240바이트다.
조합별 모델 실행 시간은 `397.67초`부터 `1,800.68초`까지였고 합계는 `24,169.13초`, 약 `6.71 GPU시간`이다.

## 중단 복구와 원격 운영

주 실행은 Vast.ai RTX A4000 한 장과 `nvcr.io/nvidia/pytorch:26.01-py3` 이미지를 사용했다.
실행 환경은 Python `3.12.3`, PyTorch `2.13.0+cu130`, CUDA 13.0이었고 원격 커밋은 `b684ce9b0d618cab8ce392b8cc5d57b3ef22bb0b`다.

첫 인스턴스는 7시간 30분 실행 제한에서 종료 코드 124로 멈췄지만 완료된 14개 체크포인트를 결과 묶음으로 보존했다.
노트북 네트워크와 Vast 제어 API가 일시적으로 불안정한 동안에도 원격 학습과 GitHub 보조 종료 예약은 독립적으로 유지됐다.
결과 묶음을 직접 회수해 SHA-256을 확인한 뒤 제한 시각을 넘긴 첫 인스턴스를 삭제했다.

두 번째 인스턴스에서는 빠진 seed 44, fold 4만 실행했고 AUC `0.9604068232`를 얻었다.
같은 인스턴스에서 기존 14개 체크포인트와 마지막 체크포인트를 합쳐 최종 MLflow 실행과 이식 가능한 결과 묶음을 만들었다.
재학습 범위를 한 조합으로 제한해 이미 끝난 약 6.6 GPU시간을 다시 쓰지 않았다.

Vast 청구 내역에서 첫 인스턴스 비용은 `$1.023`, 복구 인스턴스 비용은 `$0.047`로 확인됐고 합계는 `$1.070`이다.
두 인스턴스는 모두 결과 회수 뒤 삭제했고 해당 식별자가 계정의 계산 자원 목록에서 사라진 것을 확인했다.
이 작업은 별도 저장 공간을 만들지 않았다.
이번 작업의 종료 예약만 제거했고 동시에 진행 중인 다른 작업의 종료 예약 한 건은 보존했다.
