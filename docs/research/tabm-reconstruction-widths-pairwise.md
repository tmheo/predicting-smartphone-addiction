# TabM 제약 복원 구간 폭 3열 짝비교

## 결론

제약 복원 구간 폭 3열을 TabM에 더한 `exp137_tabm_recon_widths`는 `exp065_tabm`보다 3시드 평균 OOF AUC가 `+0.00005855` 높았다.
세 시드와 다섯 분할이 모두 개선돼 판정 계약의 `실신호` 조건을 통과했다.
후보는 `exp065_tabm`과 스피어만 상관 `0.99955865`로 중복 문턱을 넘었고 단독 OOF가 더 높아 같은 모델 계열 구성원을 교체했다.
고정 결합 전략의 후보 포함·제외 한계 기여도 `+0.00000285`, 외부 분할 3/5로 양수여서 `후보 풀 기여`로 판정했다.

## 직접 기준 설정

[재개: TabM 격자 TE 조밀화·쌍 키·빈도 열 짝비교](https://github.com/tmheo/predicting-smartphone-addiction/issues/266)는 seed 42에서 `exp065_tabm`보다 낮아 확정 재검증 없이 기각됐다.
따라서 [TabM에 제약 복원 구간 폭 3열 이식 짝비교](https://github.com/tmheo/predicting-smartphone-addiction/issues/294)의 직접 기준은 기존 후보 풀 TabM 구성원인 `exp065_tabm`으로 고정했다.

## 구현과 비교 규율

`exp137_tabm_recon_widths`는 `exp065_tabm`의 `constrained_impute_aux.widths`만 `false`에서 `true`로 바꿨다.
추가 모델 입력은 `gaming_hours_recon_width`, `social_media_hours_recon_width`, `work_study_hours_recon_width` 3열뿐이다.
TabM 구조, 최적화 설정, 기존 피처 계획과 데이터 분할은 기준과 같게 유지했다.
설정 판독 회귀 검사는 두 설정의 차이가 실험 이름과 폭 열 스위치뿐이고 실제 추가 열이 정확히 3개인지 확인한다.

## 실험 결과

| 단계 | 시드 | 후보 OOF | 기준 OOF | 변화 | 분할 승수 |
| --- | --- | ---: | ---: | ---: | ---: |
| 선별 | 42 | 0.9682870233 | 0.9681893286 | +0.0000976947 | 4/5 |
| 확정 | 42, 43, 44 평균 | 0.9683846688 | 0.9683261182 | +0.0000585506 | 5/5 |

확정 실행의 시드별 변화는 시드 42 `+0.00009769`, 시드 43 `+0.00006908`, 시드 44 `+0.00001138`로 3/3이 양수였다.
확정 실행의 seed 42 예측은 별도 선별 실행과 691,369개 모든 행에서 정확히 일치했다.
평균 개선폭이 `+0.0002`보다 작은 경계 구간이므로 평균본 분할 승수 3/5 이상이 필요했고 실제로 5/5를 충족했다.

순열 기반 AUC 감소량은 `gaming_hours_recon_width`가 평균 `0.00003096`으로 플라시보보다 7/15칸 높았다.
`social_media_hours_recon_width`는 평균 `0.00006666`으로 11/15칸, `work_study_hours_recon_width`는 평균 `0.00000550`으로 1/15칸 높았다.
중요도 비교와 짝지은 OOF가 일부 충돌하지만 중요도는 결과 설명에만 쓰고 채택 관문으로 사용하지 않았다.
목표값을 쓰는 플라시보 파생 열의 중요도는 15개 모든 시드·분할에서 원본 플라시보보다 낮아 카나리아 유효성 판정을 통과했다.

## 후보 풀 판정

후보 OOF AUC `0.96838467`은 champion 기준 진입 하한 `0.95928405`를 통과했다.
최근접 구성원은 `exp065_tabm`이고 스피어만 상관 `0.99955865`로 중복 문턱 `0.998` 이상이지만 후보 단독 OOF가 `+0.00005855` 높아 직접 교체 조건을 충족했다.
기존 30개 풀에서 `exp065_tabm`을 후보로 바꾼 `missing_interaction_rank_logit` nested OOF는 `0.96970722`로 기존 `0.96970858`보다 `-0.00000136` 낮았고 외부 분할 4/5가 양수였다.
후보와 `exp065_tabm`을 모두 뺀 풀 대비 후보 포함 한계 기여는 `+0.00000285`였고 외부 분할 3/5가 양수였다.
직접 교체 nested 진단은 후보 풀 진입이나 중복 교체의 제거 관문이 아니며, 포함·제외 한계 기여는 별도 계약을 통과했다.
따라서 풀 구성원 수 30개를 유지하면서 `exp065_tabm`을 `exp137_tabm_recon_widths`로 교체했다.

## 결합 전략 재평가

후보 교체 뒤 30개 풀에서 22개 전략을 다시 평가했고 제외된 전략은 없었다.
최고값은 `shrunk_rank_logit_logistic`의 nested OOF `0.96971569`였다.
이 티켓의 고정 포함·제외 전략인 `missing_interaction_rank_logit`은 nested OOF `0.96970722`였다.
이 티켓은 TabM 구성원 교체 판정 범위이므로 전체 재학습의 결합 규약은 바꾸지 않았다.

## 전체 자료 재학습 계획

후보의 분할별 선택 epoch 중앙값은 seed 42, 43, 44에서 각각 `14`, `13`, `13`이다.
고정 배수 `1.25`와 반올림 규약을 적용한 전체 자료 재학습 예산은 `18`, `16`, `16`이다.
`artifacts/full-refit-plan.yaml`에서 `exp065_tabm`을 후보 실행과 이 예산으로 교체했다.

## 재현성과 원격 정리

선별과 확정 실행은 고정 커밋 `1bdbce6f21f2c38aa1cd99553ac22998c6ad1387`, 같은 입력 해시와 같은 5분할에서 실행했다.
확정 결과 묶음은 원격과 로컬 SHA-256 `080e7111bd9acf04294ff6c6d46dad73158d6ebdf5000fa47075748083947928`가 일치했고 내부 산출물 5개의 manifest 검증도 통과했다.
고정 포장 스크립트가 임시 manifest 자신을 검증 목록에 포함해 포장 단계만 실패했으며, 완성된 산출물 5개를 명시한 manifest로 재포장하고 학습과 실행 저장소 내보내기는 다시 실행하지 않았다.
확정 실행의 실제 비용은 0.353달러이고 선별을 합친 총 실제 비용은 0.494달러다.
결과를 주 실행 저장소에 반입하고 필수 산출물을 다시 조회한 뒤 계산 자원을 삭제했다.
삭제 뒤 대상 인스턴스와 별도 저장 공간이 없고 이 작업의 선별·확정 종료 예약도 남지 않았음을 확인했다.
