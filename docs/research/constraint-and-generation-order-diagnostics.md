# S6E8 숨은 제약과 생성 순서 판별 규약

## 결론

관측된 `p(X,Y,M)`만으로 설명변수 공동 생성, 별도 목표값 생성, 제약 보정, 결측 주입의 실제 시간 순서를 일반적으로 증명할 수는 없다.
같은 관측 공동분포는 `p(X)p(Y|X)p(M|X,Y)`로도, `p(Y)p(X|Y)p(M|X,Y)`로도 분해할 수 있기 때문이다.
따라서 목표는 생성 이력을 단정하는 것이 아니라, 명시한 제한적 후보 과정을 반증하고 남은 과정마다 다음 실험을 결정하는 것이다.
숨은 제약은 발견 자료와 확인 자료를 분리해 함수 종속성, 조건부 함수 종속성, 부정 제약, 작은 산술 문법, 조건부 범위 순서로 찾고, 원본 프록시와 대회 train 및 test에서 보존 여부를 따로 판정해야 한다.
목표값 표면, 제약 경계의 질량, 결측 마스크의 조건부 독립성을 함께 보면 `X,Y` 공동 생성, 별도 `Y|X`, 생성 후 제약 보정, 마지막 결측 주입 같은 제한적 후보를 구분할 수 있다.

## 표기와 식별 한계

`X`는 대회와 원본 프록시가 공유하는 12개 설명변수다.
`Y`는 `addicted_label`이다.
`M_j=1`은 설명변수 `j`가 결측임을 뜻하고, `M`은 12개 결측 지표의 벡터다.
`X*`는 결측을 주입하기 전의 완전한 설명변수를 뜻한다.
원본 프록시는 실제 생성 원본이 아니라 강한 관찰 근거를 가진 프록시로만 취급한다.

공동분포 분해의 동치 때문에 관측 자료만으로 `X`가 먼저인지 `Y`가 먼저인지 일반적으로 정할 수 없다.
Rubin의 [결측 자료 원 논문](https://doi.org/10.1093/biomet/63.3.581)도 결측 과정을 무시할 수 있는 조건을 자료만이 아니라 결측 메커니즘과 모수의 구분에 대한 가정으로 정의한다.
Mohan과 Pearl의 [결측 모형 검정 가능성 연구](https://proceedings.mlr.press/v33/mohan14.html)는 결측 그래프에 따라 MCAR, MAR와 일부 MNAR 가정은 검정 가능성이 다르다는 점을 보인다.
그러므로 아래 결과는 `가장 단순한 제한적 후보를 지지한다` 또는 `후보를 반증한다`고만 쓰고, 관측 자료가 생성 순서를 증명했다고 쓰지 않는다.

## 분석 자료 분할

원본 프록시와 대회 train은 각각 행을 발견 50%, 확인 50%로 무작위 분할하되, 목표값 비율과 주요 범주를 층화한다.
대회 test는 목표값 없는 독립 복제 자료로 사용하고 발견 단계의 규칙 선택에는 쓰지 않는다.
산술 후보, 조건 절편, 허용오차, 최소 지지 행 수는 발견 자료에서만 정한다.
확인 자료에서는 후보를 추가하거나 수식을 고치지 않고 위반률과 신뢰구간만 계산한다.
최종 후보는 원본 프록시 확인 자료, 대회 train 확인 자료, 대회 test에서 방향과 크기가 재현되어야 한다.
저장값 그대로의 정확 일치와 표시 반올림으로 설명 가능한 일치를 서로 다른 판정으로 둔다.
전자는 자료형의 기계 정밀도를 허용오차로 쓰고, 후자는 식에 들어간 각 열의 표시 단위 절반을 오차 전파한 범위를 허용오차로 고정한다.
여러 후보를 동시에 검사할 때는 후보군별 거짓 발견률을 Benjamini-Hochberg 절차로 제한하고, 정확 제약의 핵심 판정에는 더 보수적인 가족별 오류율도 함께 보고한다.

## 숨은 제약 발견 절차

### 1. 스키마와 단변량 범위

각 열의 자료형, 고유값, 최소값, 최대값, 소수 자릿수, 정수 여부, 경계 정확값 질량을 자료 집합별로 표로 만든다.
원본 프록시에만 있는 경계, 대회에서도 보존된 경계, 대회에서 새로 생긴 범위를 구분한다.
최소값과 최대값만 보고 자연 법칙으로 부르지 않고, 경계에 값이 쌓였는지와 표본 크기가 늘어도 경계 추정이 안정적인지를 함께 본다.

### 2. 함수 종속성과 조건부 함수 종속성

정확값 열과 범주 열에 대해 `A -> B` 형태의 함수 종속성을 찾고, 범주 조건 `C=c` 안에서만 성립하는 조건부 함수 종속성도 찾는다.
예를 들어 같은 `daily_screen_time_hours`가 같은 목표값을 결정하는지, 특정 성별 또는 스트레스 수준 안에서만 다른 열이 결정되는지를 검사할 수 있다.
조건부 함수 종속성은 값 조건을 포함한 자료 일관성 규칙으로 제안되었으며, 원 논문은 위반 튜플을 찾는 용도를 명시한다.
근거는 Bohannon 등의 [Conditional Functional Dependencies 원 논문](https://doi.org/10.1109/ICDE.2007.367920)이다.
발견 자료에서 위반이 0이어도 확인 자료에서 한 번이라도 정밀도 허용오차를 넘으면 정확 제약에서 제외하고 근사 제약으로 낮춘다.
낮은 지지 행 수에서 우연히 성립한 조건은 최소 지지 기준을 통과하지 못하면 보고하지 않는다.

### 3. 부정 제약

부정 제약은 한 행 또는 두 행의 값 조합이 동시에 참일 수 없다는 형식으로 범위, 순서, 동등성, 교차 열 관계를 표현한다.
후보 술어는 `=`, `!=`, `<`, `<=`, `>`, `>=`와 열 간 차이 또는 비율의 사전 정의된 비교로 제한한다.
예를 들어 `daily < social + gaming + work` 금지와 `weekend / daily`의 조건부 범위를 같은 틀에서 검사할 수 있다.
FastADC는 허용 위반 비율을 둔 근사 부정 제약을 빠르게 발견하므로, 정확한 규칙과 대체로 지켜지는 규칙을 구분하는 구현 후보가 된다.
근거는 [FastADC 원 논문](https://mashuai-ms.github.io/pubs/vldb2023a.pdf)과 [공식 구현](https://github.com/RangerShaw/FastADC)이다.
발견된 부정 제약은 확인 자료에서 위반률, 위반 크기, 경계 질량을 모두 검증한다.

### 4. 작은 산술 문법

도메인 추측보다 먼저 작은 문법을 완전 열거한다.
단항식은 열 자체, 절대값, 작은 정수배와 역수로 제한하고, 이항식은 합, 차, 비율, 최소값, 최대값으로 제한한다.
계수는 `{-3, -2, -1, -1/2, 1/2, 1, 2, 3}`처럼 작은 유리수로 고정하며, 식의 깊이는 2를 넘기지 않는다.
각 식에 대해 0 잔차 질량, 중앙 절대오차, 최대오차, 부호 위반률, 범주별 위반률을 기록한다.
`daily - social - gaming - work`처럼 세 개 이상이 필요한 합은 도메인상 미리 등록한 시간 예산식으로 별도 허용한다.
작은 문법으로 설명되지 않은 잔차에만 기호 회귀를 제안 생성기로 사용한다.
[PySR 원 논문](https://arxiv.org/abs/2305.01582)과 [공식 구현](https://github.com/MilesCranmer/PySR)은 오차와 식 복잡도의 Pareto 전선을 제공하지만, 후보를 많이 탐색할수록 우연한 식을 찾기 쉬우므로 확인 자료의 독립 검증이 필수다.
기호 회귀가 제안한 식은 작은 문법과 같은 허용오차, 지지율, 확인 분할 안정성 기준을 통과해야 제약 후보가 된다.

### 5. 조건부 범위

전역 범위가 아니라 특정 범주나 기준 열 구간에서만 성립하는 범위를 찾는다.
기준 구간은 원본 프록시 발견 자료의 고유값 또는 분위수로 정하고, 대회 자료를 본 뒤 경계를 움직이지 않는다.
각 구간에서 다른 열의 0.5%, 1%, 99%, 99.5% 조건부 분위수를 추정하고, 확인 자료의 범위 밖 비율을 이항 신뢰구간으로 평가한다.
표본 수가 작은 구간은 인접 구간과 사후에 합치지 않고 미판정으로 남긴다.
완전히 정확한 조건부 범위와 작은 꼬리를 가진 확률적 범위를 구분하고, 후자는 생성 후 강제 제약 후보로 사용하지 않는다.

### 6. 제약의 계보 분류

원본 프록시와 대회에서 모두 정확한 제약은 생성기가 보존했거나 동일 후처리가 적용된 후보가 된다.
원본 프록시에서 정확하지만 대회에서 완화된 제약은 생성기가 공동관계를 충분히 학습하지 못했거나 이후 잡음을 넣은 흔적이 된다.
원본 프록시에는 없지만 대회에서 정확한 제약은 생성 후 보정 또는 대회용 스키마 강제를 우선 의심한다.
두 자료에서 모두 근사적이지만 위반 크기와 경계 모양이 같은 제약은 원자료 분포를 학습한 결과와 양립한다.
한 자료에서만 작은 표본으로 성립한 제약은 계보 단서로 쓰지 않는다.

## 생성 순서 후보의 진단

### 설명변수 공동 생성과 별도 목표값 생성

첫 후보는 `X,Y`를 한 표의 열로 공동 생성한 과정이다.
두 번째 후보는 `X`를 생성한 뒤 별도 규칙 또는 확률 모형에서 `Y|X`를 뽑은 과정이다.
세 번째 후보는 TabDDPM 분류 설정처럼 목표값 비율을 먼저 정하고 `X|Y`를 생성한 과정이다.
세 과정은 충분히 유연하면 같은 공동분포를 만들 수 있으므로, 특정 공개 구현과 설정으로 제한한 재현 후보 사이에서만 판별한다.

진단의 중심은 원본과 대회의 `p(Y=1|X)` 표면 차이, 원본 정확값 또는 최근접 행 안의 목표값 불일치, 목표값 범주별 `p(X|Y)` 왜곡이다.
원본에서 단단한 규칙이 대회에서 폭이 거의 일정한 로지스틱형 전이로 바뀌고 `p(X)`는 그대로라면, `X` 생성 뒤 별도 확률 `Y|X` 후보가 간결하다.
전이 폭과 `p(X)` 왜곡이 생성기 잠재공간의 희소 영역에서 함께 커지면 `X,Y` 공동 생성 후보와 더 잘 맞는다.
목표값 범주의 사전확률을 바꿨을 때 `p(X|Y)`는 고정되고 전체 `p(X)`만 혼합 비율대로 변하면 외부 `Y` 뒤 `X|Y` 후보와 맞는다.
같은 정확값 또는 같은 최근접 원본 행에서 `Y`가 섞이는 비율이 별도 베르누이 표본 추출 후보의 예측과 맞는지도 확인한다.
어느 결과도 무제한 모형의 실제 시간 순서를 증명하지는 않는다.

### 생성 후 제약 보정

제약 위반률뿐 아니라 경계 주변의 밀도 모양을 본다.
값 자르기 또는 최근접 실현 가능점으로의 투영은 활성 경계에 정확값 질량을 만들고, 경계 바깥에서 안쪽으로 이동한 양만큼 경계 질량을 늘린다.
결정론적 재계산은 함수 종속성과 잔차 0의 질량을 기계 정밀도 수준으로 만든다.
거부 표본 추출은 경계 위 질량을 만들지 않지만, 무보정 후보와 비교하면 금지 영역과 그 주변의 밀도를 선택적으로 줄인다.
부드러운 벌점이나 조건부 재표본 추출은 위반을 0으로 만들지 못하거나 경계로 갈수록 위반률을 연속적으로 낮춘다.
SDV의 [제약 문서](https://docs.sdv.dev/sdv/single-table-data/modeling/customizations/constraints)는 확률 합성기가 규칙을 항상 학습하지 못하므로 제약을 별도로 강제한다는 구현 근거를 제공한다.
같은 핵심 생성기의 무보정, 자르기, 투영, 재계산, 거부 표본 추출 결과를 비교해야 보정 방식을 판별할 수 있다.

### 결측 주입

각 열에 `M_j`를 만들고, 먼저 train과 test의 열별 결측률을 별도로 추정한다.
열별 독립 MCAR 후보에서는 `M_j`가 `X*`, `Y`, 다른 `M_k`와 독립이고, 행별 결측 개수는 열별 Bernoulli 확률의 합인 Poisson-binomial 분포를 따른다.
쌍별 마스크 상관, 행별 결측 개수의 꼬리, 자주 함께 빠지는 열 묶음이 독립 후보를 반증한다.
각 `M_j`를 `Y`, 항상 관측된 값, 다른 열의 관측값과 마스크로 예측하는 교차적합 분류기를 만들고, 순열 검정으로 우연 수준을 평가한다.
분류 AUC가 0.5에 가깝다는 한 결과만으로 독립을 채택하지 않고, 조건부 평균 차이, 범주별 비율, 마스크 상관과 함께 본다.
Little의 [MCAR 검정 원 논문](https://doi.org/10.1080/01621459.1988.10478722)은 다른 변수의 결측 패턴으로 나눈 집단 사이의 관측 평균을 비교하는 전역 검정을 제공한다.
Little 검정은 평균 차이를 중심으로 하므로, 비선형 의존과 마스크 간 의존을 찾는 위 진단을 대체하지 않는다.

`M`이 `X*`와 `Y`에 독립이고 열 사이도 독립이며 train/test의 열별 비율만 다르면, 모든 값과 목표값을 만든 뒤 train/test별로 열 독립 결측을 주입한 후보가 가장 간결하다.
`M`이 `Y` 또는 관측 가능한 `X`와 연결되면 단순 MCAR 마지막 주입 후보는 반증되지만, MAR와 MNAR의 실제 방향은 관측 자료만으로 모두 구분되지 않을 수 있다.
마스크가 몇 개의 안정된 묶음으로 움직이면 행 단위 잠재 결측률이나 공동 마스크 생성기를 다음 후보로 연다.
제약식에 필요한 열이 위반 가능성이 큰 행에서 선택적으로 빠지면 결측이 제약 위반을 가리는 과정도 후보가 되지만, 결측값 자체를 관측하지 못하므로 민감도 분석 없이는 단정하지 않는다.

### 목표값과 결측의 상대 순서

목표값 모형이 완전한 `X*`를 본 후보와, 결측이 적용된 관측 `X,M`을 본 후보를 제한적 재현 과정으로 비교한다.
`p(Y|X_observed,M)`가 같은 관측값에서도 마스크에 따라 달라지고 그 차이가 단순 정보 손실 이상의 안정된 규칙이면, 목표값 생성에 마스크가 들어간 후보를 연다.
마스크별 목표값 차이가 완전 자료로 학습한 `Y|X*`를 적분했을 때의 차이로 설명되면, 목표값 뒤 결측 주입과 양립한다.
두 후보가 같은 관측 공동분포를 만들면 상대 순서는 미식별로 남긴다.

## 반증과 후속 실험 결정표

| 진단 결과 | 반증 또는 지지되는 제한적 후보 | 다음 실험 결정 |
| --- | --- | --- |
| 작은 산술식이 발견과 확인 자료에서 기계 정밀도로 성립한다. | 우연한 근사 관계는 반증된다. | 함수 종속성 또는 결정론적 재계산 후보를 비교한다. |
| 원본 프록시의 정확 제약이 대회에서 큰 꼬리 위반으로 바뀐다. | 완전한 제약 보존 또는 마지막 강제 보정은 반증된다. | 무보정 공동 생성과 제약 잡음 주입 후보를 비교한다. |
| 대회에만 정확 제약이 있고 경계에 질량이 쌓인다. | 생성기 학습만으로 생긴 제약보다 생성 후 투영이 유력하다. | 같은 핵심 생성기의 투영 전후 지문을 비교한다. |
| 위반은 0이지만 경계 질량 증가는 없고 경계 안쪽 밀도가 비어 있다. | 단순 자르기는 반증되고 거부 표본 추출이 유력하다. | 무보정 표본에 규칙을 적용한 거부 후보를 만든다. |
| 원본 목표값 경계만 완만해지고 `p(X)` 및 제약 지문은 보존된다. | 별도 확률 `Y|X` 후보를 지지한다. | 고정된 로지스틱 잡음, 규칙 오차, 이웃 기반 표본 추출을 비교한다. |
| 목표값 경계와 범주별 `X` 왜곡이 함께 움직인다. | `X` 뒤 독립적인 목표값 잡음만으로는 부족하다. | `X,Y` 공동 생성과 외부 `Y` 뒤 `X|Y` 후보를 비교한다. |
| 외부 목표값 범주 비율 변화가 `p(X|Y)`를 유지하고 `p(X)`만 바꾼다. | 목표값 조건부 생성 후보와 맞는다. | TabDDPM의 목표값 범주 비율과 표본 추출만 바꾸는 민감도 검사를 한다. |
| 마스크가 `X,Y`와 독립이고 행별 개수도 Poisson-binomial과 맞는다. | 열별 독립 마지막 주입을 반증하지 못한다. | 살아남은 완전 자료 후보에 train/test별 열 비율을 마지막에 적용한다. |
| 마스크 간 양의 상관과 행별 결측 과산포가 재현된다. | 열별 독립 주입은 반증된다. | 행별 잠재 결측률 또는 공동 마스크 생성기를 비교한다. |
| `M_j`가 관측 `X` 또는 `Y`로 안정적으로 예측된다. | 단순 MCAR는 반증된다. | 사전 등록한 MAR 모형과 민감도 범위를 비교하고 MNAR는 미식별로 남긴다. |
| 완전 `X*` 목표값 후보와 관측 `X,M` 목표값 후보가 같은 관측 지문을 만든다. | 상대 순서는 식별되지 않는다. | 추가 가정이나 생성 중간 산출물이 없으면 더 강한 결론을 내리지 않는다. |

## 비식별 진단으로 거부할 항목

전체 상관계수, 평균, 단변량 KS 거리, 전체 품질 점수는 숨은 제약과 생성 순서를 식별하지 못한다.
제약 위반률 0 하나는 학습, 거부, 자르기, 투영, 재계산을 구분하지 못한다.
결측 개수의 목표값 단독 AUC 하나는 열별 마스크 의존과 비선형 의존을 놓친다.
실제와 합성을 구분하는 전체 분류 AUC는 차이의 존재를 검출할 수 있지만 단계의 순서를 정하지 못한다.
다운스트림 예측 성능은 후보의 활용도를 평가할 수는 있어도 생성 이력을 식별하지 못하므로 이번 범위에서 실험하지 않는다.
기호 회귀의 발견 자료 오차만으로 산술 규칙을 채택하지 않는다.

## 권장 실행 순서

첫째, 원본 프록시와 대회 자료의 정밀도 및 단변량 범위를 고정한다.
둘째, 함수 종속성, 조건부 함수 종속성, 부정 제약과 작은 산술 문법을 발견 분할에서 찾고 확인 분할에서 걸러낸다.
셋째, 살아남은 제약을 원본 보존, 대회 완화, 대회 신규의 세 계보로 분류한다.
넷째, 목표값 표면과 범주별 설명변수 분포를 이용해 제한된 공동 생성, `Y|X`, `X|Y` 후보를 반증한다.
다섯째, 경계 질량과 밀도 그림으로 제약 보정 방식을 반증한다.
여섯째, 결측 마스크 독립성과 행별 개수 분포로 마지막 결측 주입 후보를 평가한다.
일곱째, 각 단계에서 살아남은 조합만 소규모로 재현하며, 전체 생성기 학습 탐색과 예측 성능 실험은 다음 티켓으로 남긴다.

## 주요 근거

- [Conditional Functional Dependencies](https://doi.org/10.1109/ICDE.2007.367920)는 값 조건을 포함한 일관성 규칙과 위반 검사의 근거다.
- [FastADC 원 논문](https://mashuai-ms.github.io/pubs/vldb2023a.pdf)과 [공식 구현](https://github.com/RangerShaw/FastADC)은 근사 부정 제약 발견의 근거다.
- [PySR 원 논문](https://arxiv.org/abs/2305.01582)과 [공식 구현](https://github.com/MilesCranmer/PySR)은 복잡도와 적합도의 Pareto 전선을 이용한 산술 후보 제안의 근거다.
- [Rubin 1976](https://doi.org/10.1093/biomet/63.3.581), [Little 1988](https://doi.org/10.1080/01621459.1988.10478722), [Mohan과 Pearl 2014](https://proceedings.mlr.press/v33/mohan14.html)은 결측 메커니즘의 가정, 검정과 식별 한계의 근거다.
- [SDV 제약 문서](https://docs.sdv.dev/sdv/single-table-data/modeling/customizations/constraints)는 확률 생성과 제약 강제를 별도 과정으로 비교하는 구현 근거다.
- [원본 프록시 조사](original-proxy-data.md), [원본 겹침 진단](original-overlap-diagnosis.md), [S6E8 디스커션 검증](discussion-insights.md)은 대회에 맞춘 산술식, 목표값 표면과 결측 후보의 근거다.
