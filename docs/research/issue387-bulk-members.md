# 이슈 387 트리·선형 구성원 일괄 생산 결과

## 결론

사전 고정한 12개 후보의 3시드 × 5분할, 총 180개 적합을 모두 끝냈다.
12개 중앙 실행은 모두 `FINISHED`, 시드 `[42, 43, 44]`, 깨끗한 커밋, 고정 folds 내용 해시 일치와 묶음 재채점 검증을 통과했다.

이 티켓에서는 `pool.yaml`을 바꾸지 않았고 실제 등록 수는 0개다.
같은 fold 0 탐색 결과로 생산 설정을 고르고 완성 OOF로 다시 부분집합을 골랐으므로, 7개는 별도 선택 절차 대조에서 양수 차이를 보인 경우에만 지속 등록한다.

## 실행 자격과 기록 보완

실행 입력은 train `f4669147…`, test `8b462dd4…`, folds `5f5d09e9…`로 고정했다.
모든 후보 설정은 누출 선언을 포함한 피처 계획 구성 검사를 통과했고, 중앙 반입은 입력 해시, 커밋 속 설정, 깨끗한 작업 트리, 시드별 OOF 평균과 지표 재채점을 검증했다.
빈 MLflow SQLite 저장소를 세 프로세스가 동시에 처음 열 때 두 실행이 모델 적합 전에 `table experiments already exists`로 실패한 문제를 재현했다.
SQLite 스키마와 실험 초기화를 파일 잠금으로 직렬화하고 회귀 검사를 추가했다.
또한 묶음 반입기가 가중 OOF 지표를 재채점하지 않던 문제를 고쳐, 12개 중앙 실행에 로컬 주장값과 일치하는 가중 OOF 지표를 보완했다.
비커밋 입력 검사, 원격 파이썬 계약 4개, 전체 검사 745개가 통과했고 새 SQLite 저장소를 세 프로세스가 동시에 여는 실제 재검증도 실험 하나만 생성하며 통과했다.

전체 정밀 수치, 실행 ID, 묶음 SHA-256, 학습 시간과 관측 반복 길이는 `artifacts/issue387-bulk-candidate-results.yaml`에 있다.
