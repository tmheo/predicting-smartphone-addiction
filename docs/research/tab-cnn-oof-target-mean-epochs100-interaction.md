# 표 합성곱망 OOF 목표 평균과 100회 상한 결합 검증

이 문서는 GitHub 이슈 [표 합성곱망 OOF 목표 평균과 100회 학습 상한 결합 비교](https://github.com/tmheo/predicting-smartphone-addiction/issues/334)의 실행 결과를 기록한다.
실행 기준일은 2026-08-23이다.

## 결론

`exp140_tab_cnn_oof_target_mean_epochs100` seed 42의 OOF AUC는 `0.9673913282820161`이다.
직접 기준인 `exp131_tab_cnn_oof_target_mean` seed 42의 `0.9674152910858209`보다 `0.0000239628038048` 낮다.
1차 짝차이 `-0.0000239628038048`이 음수이므로 결합 상호작용 개선은 없다고 판정했다.
계약에 따라 seed 43과 44는 실행하지 않았고 3시드 확인과 후보 풀 판정도 수행하지 않았다.

다섯 폴드의 최적 학습 횟수는 11회부터 15회 사이였고 실제 학습 횟수도 26회부터 30회 사이였다.
따라서 seed 42에서는 30회보다 큰 학습 상한이 실제 학습을 연장하지 않았다.
이 결과는 exp131과 exp132의 기존 채택 판정을 바꾸지 않으며 후보 풀과 전체 자료 재학습 계획도 바꾸지 않는다.

## 비교 계약

후보 설정은 [`exp140_tab_cnn_oof_target_mean_epochs100.yaml`](../../configs/exp140_tab_cnn_oof_target_mean_epochs100.yaml)이다.
기준 `exp131_tab_cnn_oof_target_mean.yaml`에서 `model.params.epochs`만 `30`에서 `100`으로 바꿨다.
인내 15회, 학습률, 모형 구조, 일괄 처리 크기, 46개 입력, 목표 평균 내부 10분할, 평활값 `10.0`과 모든 전처리는 동일하다.
설정 회귀 시험은 두 설정의 유일한 구조화된 차이가 최대 학습 횟수임을 확인한다.

기준 설정 SHA-256은 `36c92397da6b36f3232a153a2693426c9a150560f718f850c0107b0a8d532b6a`이고 후보 설정 SHA-256은 `861da5b7eb4f07caf12c59a88b243e8e9aaaa7cbc0745c8ed112b9b1d4ecdd8a`다.
구조화된 설정 차이와 실행 증거는 [`tab-cnn-oof-target-mean-epochs100-interaction-evidence.json`](tab-cnn-oof-target-mean-epochs100-interaction-evidence.json)에 고정했다.

기준 실행의 설정, 학습 자료, 시험 자료와 고정 분할 해시는 현재 계약과 일치했다.

기준 설정과 산출물이 모두 일치했으므로 기준을 다시 실행하지 않았다.

## 실행과 무결성

후보 실행 커밋은 `12f2978053c2aac090ec01bde35668a6a53c94ab`이고 Git 상태는 깨끗했다.
후보 원격 MLflow 실행은 `f3635d3dd00442fba337cd405571b7b1`이고 로컬 반입 실행은 `2ac084aa8f204ba7b1bccf9e05768192`다.
로컬 반입 실행은 `FINISHED` 상태이며 원격 실행 묶음의 지표, 매개변수, 꼬리표와 16개 최상위 산출물을 보존한다.

후보 OOF는 691,369행, 고유 식별자 691,369개와 유한한 예측만 포함했다.

## Vast.ai 자원 정리

Vast.ai 계산 자원은 결과 회수, 내부 해시 검증과 로컬 MLflow 반입을 마친 뒤 삭제했다.
삭제 뒤 대상 계산 자원이 계정 목록에서 사라졌고 별도 저장 공간은 0개임을 확인했다.
종료 안전장치에서 이 작업 일정만 제거하고 다른 네 작업 일정을 저장소 범위와 `vast-termination` 환경 범위에 같은 값으로 보존했다.

Vast.ai 청구 기록의 실제 비용은 0.737달러였다.
구성은 GPU 0.616달러, 임시 디스크 0.017달러, 내려받기 0.103달러와 올리기 0.001달러다.

## 후보 풀과 후속 영향

후보 풀 판정은 3시드 실행 완료가 전제지만 이번 후보는 seed 42에서 중단됐다.
따라서 진입 하한, 최근접 구성원, 스피어만 상관계수와 포함 전후 앙상블 AUC는 계산 대상이 아니다.
후보 풀, 전체 중첩 OOF 결합 전략과 ADR 0002의 전체 자료 재학습 계획은 바뀌지 않는다.
