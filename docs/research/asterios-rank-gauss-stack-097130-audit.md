# Asterios Rank-Gauss Stack 0.97130 판본의 외부 OOF 편입 감사

이 문서는 GitHub 이슈 [Asterios Rank-Gauss Stack 0.97130 판본의 외부 OOF 편입 가치를 판정한다](https://github.com/tmheo/predicting-smartphone-addiction/issues/518)의 조사 결과다.
조사 기준일은 2026-08-31이며, Kaggle의 고정 공개 판본, 저장 실행 결과, 연결 자료와 저장소의 외부 구성원 자격 계약만을 근거로 삼았다.

## 결론

현재 외부 OOF 장부 판본 3과 다음 외부 후보 동결 명세에 더할 자격 있는 OOF와 시험 예측 쌍은 **0개**다.

연결 자료의 기초 모형 9개는 행 수, 유한값, 원래 행 순서, 고정 5분할, 재채점 AUC와 정확 중복 검사까지 통과했다.
그러나 자료에 함께 공개된 유일한 학습 구현은 각 바깥 검증 분할의 AUC를 조기 종료에 직접 사용한다.
[외부 구성원 감사 기록 계약](https://github.com/tmheo/predicting-smartphone-addiction/issues/482#issuecomment-5447449188)은 확인된 검증 조기 종료나 최적 가중치 선택을 `자격 없음`으로 계산하므로 9개 모두 외부 후보 자격이 없다.

공개 점수 `0.97130`은 이 9개 중 하나의 점수가 아니다.
대상 노트북은 기초 예측 240개를 Rank-Gauss 로지스틱 회귀로 결합한 뒤, 그 시험 예측을 기존 공개 제출 두 장의 혼합과 다시 섞었다.
최종 파일에는 대응 OOF가 없고 마지막 가중치도 공개 점수 곡선을 보고 정했으므로, 외부 구성원이나 결합기 채택 근거로 쓸 수 없다.

새 결합 신호도 없다.
Rank-Gauss 로지스틱 회귀, 결측 개수별 로지스틱 회귀, 비선형 2단 결합과 결측 증강은 저장소에서 이미 더 엄격한 중첩 평가로 다뤘다.
기초 자료 작성자도 250개 공개 구성원 결합에 9개 전체를 더한 이득을 `+0.000008`로 기록했으며, 이는 현재 엄격 외부 교체 문턱 `+0.00002`보다 작다.
대상 결합의 OOF에는 알려진 10분할 입력도 들어갈 수 있어 `0.970167` 자체가 현행 5분할 결합기 비교값으로 적합하지 않다.

## 기초 예측 9쌍의 무결성

`train_keys.parquet`은 `id=0..691368`의 691,369행과 목표값을, `test_keys.parquet`은 `id=691369..987670`의 296,302행을 중복 없이 담는다.
두 식별자 순서는 대회 원래 행 순서이며, 훈련 식별자는 저장소 `artifacts/folds.parquet`의 식별자 순서와 정확히 같다.

## 기초 예측 9쌍의 학습 자격

자료의 `src/common.py`는 분할을 `StratifiedKFold(5, shuffle=True, random_state=42)`로 만들고 원래 배열 위치에 OOF를 채운 뒤 5개 시험 예측을 평균한다.
`src/latmask.py` 112행부터 120행은 바깥 학습과 검증을 분리하고, 116행부터 119행은 바깥 학습 부분 안에서 목표값 부호화용 내부 4분할을 다시 만든다.
181행부터 196행은 학습 행의 목표값 부호화를 내부 교차 적합으로 만들고 바깥 검증과 시험에는 바깥 학습 전체 대응표만 적용한다.
따라서 분할, 목표값 전처리 격리와 시험 예측의 5분할 평균 자체는 계약과 맞는다.

자격을 깨는 부분은 학습 시점 선택이다.
XGBoost 경로는 217행부터 230행에서 `early_stopping_rounds=200`을 설정하고 바깥 검증 행렬과 목표값 `(Xb, yb)`를 `eval_set`으로 넘긴다.
LightGBM 경로도 234행부터 248행에서 같은 `(Xb, yb)`와 `lgb.early_stopping(200)`을 사용한다.
OOF는 이렇게 선택된 반복 횟수의 모형으로 같은 바깥 검증 분할을 예측한 값이다.
이는 검증 행이 채점에만 쓰인 것이 아니며, 바깥 검증 결과 전에 학습 횟수가 고정됐다는 주장도 성립하지 않는다.

자료에는 9개 모형 각각의 명령행, 확정 반복 횟수나 별도 안쪽 조기 종료 분할을 적은 실행 manifest가 없다.
공개된 유일한 학습 구현과 작성 노트북은 모두 바깥 검증 조기 종료를 명시한다.
따라서 공개 계보를 그대로 따르면 `검증 조기 종료`가 확인된 자격 없음이다.
학습 소스와 각 배열의 직접 연결을 인정하지 않는 더 보수적인 읽기를 택하더라도, 직접 학습 계보와 학습 시점 근거가 부족해 `근거 부족`이 될 뿐 `자격 있음`으로 바뀌지는 않는다.

전처리의 설명변수 전용 상태는 훈련과 시험을 합친 자료에서 맞춘다.
대치 모형, 값 빈도와 범주 어휘가 여기에 해당하며 목표값은 읽지 않는다.
현재 계약은 목표값 기반 전처리의 바깥 학습 격리를 필수로 하므로 이 전이식 전처리 자체를 별도 제외 사유로 계산하지 않았다.

## 대상의 Rank-Gauss 결합과 최종 제출

대상 저장 실행은 자료별로 `74, 11, 9, 9, 22, 7, 5, 17, 5, 1`개, 모두 160개 기초 배열을 읽고, parquet 자료와 약한 모형 행렬을 더해 총 257개를 만든다.
순위 상관 `0.9995` 초과 12개와 이름으로 찾은 2단 구성원을 제거한 뒤 240개를 남긴다.
각 열의 전체 OOF와 전체 시험 예측을 별도로 백분위 순위와 정규 분위수로 바꾸고, 5개 바깥 분할에서 로지스틱 회귀를 교차 적합한다.
저장 실행의 결합 OOF AUC는 `0.970167`이다.

이 240개 후보 풀은 고정 5분할 계약을 지키지 않는다.
대상은 `szymonkapiski/s6e8-oof-library-47-models`의 알려진 10분할 `pub_evg`와 `tamerlanomralinov/s6e8-full-best-blend-npy`의 10분할 9개를 일반 `oof_*.npy` 쌍으로 읽는다.
판본 2 외부 장부는 전자를 10분할로 제외했고 후자 자료 9개 전체도 10분할로 기록했다.
대상 코드의 제거 규칙은 순위 상관과 `naji`, `v13_anchor`, `hb_candidate` 이름뿐이라 `sz_pub_evg`나 `tam_*`를 분할 사유로 제외하지 않는다.
저장 실행은 최종 240개 이름을 보존하지 않아 우연한 상관 제거로 이 10개가 모두 사라졌다고 확인할 수도 없다.
따라서 `0.970167`은 외부 5분할 결합기의 정직한 OOF 근거가 아니다.

이 결합은 OOF와 시험 예측 쌍을 파일로 저장하지 않는다.
외부 구성원 감사 계약은 결합 노트북 자체를 제외하지는 않지만 결합 출력에 개별 외부 구성원 자격을 주지 않고, 확인된 기초 모형만 따로 감사하도록 정한다.
따라서 실행 중 만들어진 `oof_meta`를 나중에 재구성하더라도 장부의 새 개별 구성원이 되지 않는다.

최종 제출은 `anthonytherrien/predicting-smartphone-addiction-vault`의 `submission.csv`와 `submission (1).csv`를 `2.9:0.1`로 먼저 섞고, 그 공개 제출 혼합 65%와 대상 결합 35%를 다시 섞는다.
대상 원문은 공개 점수 `0.97130`이 나온 가중치 구간 `0.20..0.50`을 공개 점수로 훑었고 그 중간인 `0.35`를 골랐다고 명시한다.
따라서 최종 제출은 시험 전용 외부 제출의 2단 재혼합이며 OOF 연결도 없고 공개 점수 선택도 포함한다.
공개 점수는 출처 확인용 기록일 뿐 편입이나 결합기 판정값이 아니다.

## 작성 노트북의 2단 결합

작성 노트북은 대상 노트북과 다른 결합 실험도 수행한다.
순위 로지스틱 회귀, 결측 개수별 로지스틱 회귀와 LightGBM 2단 모형을 만들고, 전체 OOF AUC를 직접 최대화하는 0.05 간격 격자로 세 가중치를 고른다.
저장 실행은 `rank_lr=0.50`, `regime_lr=0.25`, `lgbm=0.25`와 결합 OOF `0.970517`을 기록한다.

LightGBM 2단 모형은 다시 같은 바깥 검증 분할을 조기 종료에 사용한다.
세 가중치도 5개 바깥 OOF 전체에서 고른 뒤 같은 OOF를 최종 성능으로 보고하므로 이 값에는 2단 선택 편향이 있다.
저장 산출물은 최종 제출과 기초 `latmask_xgb` 예측 쌍뿐이며 세 2단 모형이나 혼합 결과의 OOF와 시험 예측 쌍은 보존하지 않는다.
대상 노트북은 이 2단 제출을 입력으로 쓰지 않으므로 이 경로는 대상 점수의 계보도 아니다.

## 새 모형 또는 결합 신호 판정

### Rank-Gauss와 선형 결합

저장소는 `rank_gauss_logistic`을 바깥 학습 부분 안에서 분위 변환을 맞추는 더 엄격한 형태로 이미 구현했다.
[동결 후보 풀의 결합 전략 최종 재확정 결과](issue337-final-combiner.md)는 같은 35개 입력에서 `rank_gauss_logistic`의 nested OOF를 `0.9697845846`, 현행 `shrunk_rank_logit_logistic`을 `0.9698105828`로 기록한다.
[확장 결합 사다리](extended-stack-ladder.md)에서도 209개 외부 구성원을 더한 조건의 Rank-Gauss 전략은 `0.9702459`로 Rank-Logit보다 낮았다.
대상 노트북은 Rank-Gauss 변환을 바깥 분할 전에 전체 OOF에서 맞추므로 저장소 구현보다 격리도 약하다.
새 실험이나 결합기 교체 근거가 없다.

### 결측 개수별 결합과 비선형 2단 모형

저장소는 `missing_segmented_rank_logit`, `missing_interaction_rank_logit`과 얕은 비선형 2단 모형을 같은 동결 입력에서 이미 비교했다.
최종 재확정에서 결측 구간별 두 전략은 현행 방식과 성능 동등 대역 안이었고, `xgb_rank_logit`은 현행 방식보다 nested OOF가 `0.0001773` 낮았다.
작성 노트북의 LightGBM 2단 모형은 바깥 검증 조기 종료와 전체 OOF 가중치 선택까지 더해져 이 기존 판정을 뒤집을 근거가 되지 않는다.

### 결측 증강과 실측 행 마스크

강한 나무 모형에 관측 셀을 추가로 가리는 핵심 발상은 이미 [독립 결측 증강 최종 근거와 분류](missingness-augmentation-final-classification.md)에서 세 시드와 5개 분할로 확인됐다.
그 결과는 일반 기준군보다 `+0.0001197352`, 같은 행 수의 3배 행 대조군보다 `+0.0001624974`였고, 후보 풀 원자 교체 뒤 경계 기여 구성원으로 등록됐다.

연결 자료가 덧붙이는 변형은 독립 셀 가리기 대신 훈련과 시험에서 실제로 관측한 결측 행 패턴을 복제 행에 적용하는 것이다.
그러나 [챔피언 값 가리기 증강의 분포 형태 짝비교](champion-value-dropout-mask-shape.md)는 학습 분할과 시험의 실측 행 마스크를 각각 사용한 두 판이 독립 가리기 기준보다 `-0.0000346`, `-0.0000252` 낮고 분할 승수도 `0/5`, `1/5`였음을 이미 기록한다.
그 비교 대상은 신경 모형이어서 나무 모형의 동일 변형을 논리적으로 완전히 반증하지는 않지만, 새 계열을 열 양의 근거도 남기지 않는다.

연결 자료의 작성자 측 측정도 250개 공개 구성원 결합에서 최고 단일 추가가 `+0.000007`, 9개 전체 추가가 `+0.000008`이라고 명시한다.
이 수치는 현재 엄격 외부 교체 문턱 `+0.00002`보다 작고, 그 측정 자체도 이번 자격 감사에서 제외된 조기 종료 예측을 사용한다.
따라서 실측 행 마스크를 나무 모형에 다시 적용하는 별도 실험을 열지 않는다.

### 격자 목표값 부호화, 제약 대치와 생성 자료 지문

자료 README와 작성 노트북은 격자 목표값 부호화와 제약 대치를 Szymon Kapiński의 공개 라이브러리에서, 전체 해상도 목표값 부호화를 omidbaghchehsaraei에게서 가져왔다고 명시한다.
대상 노트북도 이 자료를 새 방법론이 아니라 공개 풀에 더한 9개 구성원으로 취급한다.
빈도, 소수점 자릿수와 화면 시간 항등식도 저장소의 기존 특성과 후보군에 이미 포함돼 있으므로 새 모델링 신호가 아니다.

## 최종 판정

- 외부 OOF 장부 판본 3의 자격 있는 현행 기록이나 다음 후보 동결 명세에 추가할 예측 쌍은 없다.
- 무결성을 통과한 연결 자료 9쌍은 `outer_validation_early_stopping` 사유로 자격 없음이다.
- 작성 노트북이 별도로 저장한 기초 예측 1쌍도 같은 사유로 자격 없음이며 대상 점수의 입력도 아니다.
- 대상의 Rank-Gauss 결합은 보존된 개별 쌍이 아니고 여러 외부 예측의 2단 결과이므로 구성원으로 편입하지 않는다.
- 대상의 Rank-Gauss 결합은 알려진 10분할 입력도 걸러 내지 않으므로 그 OOF를 결합기 개선 근거로 쓰지 않는다.
- `0.97130` 최종 제출은 외부 공개 제출을 섞고 공개 점수로 가중치를 고른 시험 전용 파일이므로 편입하지 않는다.
- Rank-Gauss, 결측 구간별 결합, 비선형 2단 모형, 결측 증강과 실측 행 마스크에서 새 후속 실험을 열 근거가 없다.

이 판정은 공개 점수를 모델 또는 결합기 선택에 사용하지 않았으며, 공개 점수 `0.97130`은 고정 판본 식별과 계보 설명에만 기록했다.
