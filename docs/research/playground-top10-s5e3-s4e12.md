# Playground Series S5E3부터 S4E12까지 상위 10위 해법과 댓글 조사

이 문서는 GitHub 이슈 [리서치: S5E3-S4E12 상위권 해법 글과 댓글 조사](https://github.com/tmheo/predicting-smartphone-addiction/issues/471)의 조사 결과다.
조사 기준일은 2026-08-28이다.

## 결론

네 대회의 공식 해법 범주에 보이는 글 19개를 모두 열었고, 제목이나 본문에 Private 최종 1위부터 10위가 명시된 글 15개를 포함했다.
목록 화면의 댓글 표시값 합계는 444개였고, 상세 화면 머리말의 일반 댓글 표시값 합계는 393개, 감사 댓글 표시값 합계는 45개였다.
모든 포함 글에서 내부 댓글 영역을 끝까지 내려 지연 표시되는 댓글을 불러왔고, `more replies`로 접힌 답글도 모두 펼쳐 확인했다.

현재 S6E8에 새 실험을 열 만큼 강한 새 정보 관점은 발견하지 못했다.
가장 강하게 반복된 원본 자료의 목표값 통계, 정확값 및 결합값 통계, 서로 다른 모형의 OOF 결합은 현재 자체 35개 후보 풀 또는 외부 278개 확장 결합이 이미 덮는다.
결측 양상을 한 범주로 묶는 방법은 S5E2에서 성공했지만 S6E8 자체 제거 대조가 반박했고, 시계열 추세와 휴일 조정은 과제가 달라 옮길 수 없다.
S5E1 2위의 잔차 학습과 의사 라벨은 S6E8에서 완전 중첩 선택까지 수행했으나 보정 없음이 선택돼 기각됐다.
S5E2 3위의 지도형 자동부호화 잠재 표현과 S5E3 2위의 선형 SVC는 자체 35개 풀에서 빈 학습기 계열이지만, 해당 구성 요소만의 한계 기여 대조나 서로 독립된 성공 사례가 없어 근거 부족이다.

현재 비교 기준은 자체 후보 풀 35개와 외부 구성원 278개를 더한 313개 확장 결합이다.
자체 35개 풀의 최고 결합은 `shrunk_rank_logit_logistic`, nested OOF `0.9698105828`이다.
최신 확장 결합 실행 `443b3a71a2b045ba9052fbb3d821255d`는 자체 35개와 외부 278개를 같은 전략으로 결합해 nested OOF `0.9703509469`, 가중 OOF `0.9712170271`을 기록했다.
Public `0.97135`는 사후 참고값이며 후보 판정에는 사용하지 않는다.

## 조사 범위와 방법

Kaggle API, 웹 검색 결과 요약, 직접 HTTP 요청과 리더보드 조회는 사용하지 않았다.
`agent-browser`의 격리된 이름 세션과 콘텐츠 경계를 켜고 각 대회의 실제 Kaggle 공식 화면을 직접 확인했다.
각 조사는 사용자가 지정한 [`competitionWriteUps` 화면](https://www.kaggle.com/competitions/playground-series-s5e3/discussion?category=competitionWriteUps&sort=recent-comments)에서 대회 slug만 바꾸어 시작했다.
추천 수와 정렬 순서는 발견 순서로만 사용했고 표본 선정에는 쓰지 않았다.
순위는 글 제목 또는 상세 화면의 `Solution Writeup · Nth place` 표기만 사용했다.
상위 10위 글이 없는 순위는 다른 글로 채우지 않았다.

과제와 평가지표는 Kaggle의 [S5E3 평가](https://www.kaggle.com/competitions/playground-series-s5e3/overview/evaluation), [S5E2 평가](https://www.kaggle.com/competitions/playground-series-s5e2/overview/evaluation), [S5E1 평가](https://www.kaggle.com/competitions/playground-series-s5e1/overview/evaluation), [S4E12 평가](https://www.kaggle.com/competitions/playground-series-s4e12/overview/evaluation) 화면에서 확인했다.
포함 글마다 본문, 작성자 표시, 순위 표시, 검증 설명, 특성, 모형, 결합, 보고 점수, 계산 자원, 외부 자료, 일반 댓글, 접힌 답글과 감사 댓글을 확인했다.
화면에 없는 팀 구성, 점수 또는 설정은 추정하지 않고 미보고로 남겼다.

Kaggle 목록의 댓글 수와 상세 화면 머리말의 일반 댓글 및 감사 댓글 수는 여러 글에서 서로 일치하지 않았다.
목록 수에는 접힌 답글과 삭제 댓글이 다르게 반영되는 것으로 보이지만 Kaggle 화면은 집계 규칙을 설명하지 않는다.
따라서 아래 장부는 두 화면의 원시 표시값을 따로 기록한다.

## 제외와 결측 장부

S5E3에서는 제목에 18위와 37위가 적힌 두 글을 제외했다.
나머지 포함 글은 2위와 6위뿐이며 다른 순위는 결측으로 남겼다.

S5E2에서는 공식 해법 글 네 개가 모두 상위 10위 조건을 충족했다.
4위와 6위부터 10위까지는 공식 해법 글이 없었다.

S5E1에서는 제목과 본문에 Private 11위가 명시된 글과 Private 232위가 명시된 글을 제외했다.
1위부터 6위까지의 글은 모두 포함했고 7위부터 10위까지는 결측으로 남겼다.

S4E12에서는 공식 해법 글 세 개가 모두 상위 10위 조건을 충족했다.
1위, 2위와 9위 외의 순위는 결측으로 남겼다.

삭제되어 접근할 수 없는 글, 제목과 본문의 순위가 충돌한 글, 같은 팀원의 중복 해법 글은 없었다.
상세 화면은 각 글의 계정 작성자와 순위만 표시하며 별도 팀명이나 공동 작성자를 표시하지 않았다.
삭제 댓글은 내용에 접근할 수 없으므로 삭제 사실만 확인했다.

## S5E3: Binary Prediction with a Rainfall Dataset

### 2위: Chris Deotte

[2nd Place - GBDT + NN + SVR + Original Data](https://www.kaggle.com/competitions/playground-series-s5e3/writeups/chris-deotte-2nd-place-gbdt-nn-svr-original-data)는 Chris Deotte의 2위 글이다.
목록에는 댓글 97개가 표시됐고 상세 화면에는 일반 댓글 73개와 감사 댓글 9개가 표시됐다.

작성자는 원본 366행을 합성해 만든 훈련 자료 2,190행을 실제 신호량이 작은 자료로 보고 특성 공학을 하지 않았다.
검증은 `id // 365`로 연도를 나눈 6-fold GroupKFold였으며 시험 자료의 두 새 연도를 흉내 내도록 한 해 전체를 검증 부분으로 뺐다.
원본 자료를 새 행으로 더한 XGBoost는 CV `0.893`, Public `0.848`, Private `0.90317`을 보고했다.
같은 입력의 TabPFN은 CV `0.894`, Public `0.867`, Private `0.90193`을 보고했다.
두 모형의 같은 가중치 평균은 CV `0.897`, Public `0.859`, Private `0.90474`로 11위였다.
원본 자료의 각 값별 강수 목표 평균을 새 열로 붙인 RAPIDS SVC는 `C=0.1`, 1차 다항 커널을 사용해 CV `0.896`, Public `0.852`, Private `0.90610`으로 단독 2위 수준이었다.
XGBoost, TabPFN과 SVC의 같은 가중치 평균은 CV `0.898`, Public `0.855`, Private `0.90728`로 사후 1위 수준이었다.
최종 두 제출은 CatBoost, LogisticRegression, XGBoost와 SVR을 더한 6모형 같은 가중치 평균이었고 Private은 각각 `0.90604`와 `0.90599`였다.
추가 세 모형은 CV를 `0.900`과 `0.901`로 올렸지만 Private은 세 강한 모형의 결합보다 낮았다.

새 행 추가 설명 옆 예시 코드는 `pd.concat([train, orig], axis=1)`로 표시돼 서술과 축이 충돌한다.
따라서 새 행 경로는 본문만으로 그대로 재현할 수 없고, 새 열 경로는 코드가 명확하다.

댓글에서 작성자는 원본 366행을 증강한 2,190행을 2,190개의 독립 신호로 보아서는 안 된다고 설명했다.
행당 열 수가 지나치게 많아지면 가짜 규칙이 CV를 올릴 수 있으며, 실제로 SVM 상호작용 특성은 CV와 Public을 올리고 Private을 낮췄다고 사후 확인했다.
작은 자료에서 같은 가중치를 쓰는 이유는 새 모형에 1% 같은 작은 가중치를 주어 생기는 우연한 CV 개선을 막기 위해서라고 답했다.
추가 세 모형도 CV만 올리고 Private은 개선하지 못했다는 본문 결과가 이 설명과 같은 방향이다.
작성자는 합성된 여덟 해 사이에 시간적 인과 순서가 없다고 판단해 순방향 시계열 분할이 아닌 연도 GroupKFold를 사용했다고 설명했다.
Public 146행의 목표를 공개 제출 파일과 점수로 역산했다는 댓글은 리더보드 탐색이며 현 검증 계약에는 사용할 수 없다.

S6E8 판단은 기존 결정과 중복이다.
원본 목표 통계를 새 열로 주는 관점은 자체 35개 풀의 원본 프록시 목표 통계, 최근접 라벨, 원본 잔차, 분포 좌표가 이미 더 여러 방식으로 구현한다.
같은 가중치 결합과 여러 학습기 계열은 현재 자체 35개와 외부 278개 결합보다 좁다.
SVC는 자체 풀과 외부 장부의 명시적 이름에서 비어 있지만, 한 작은 자료 대회의 단독 성공만 있고 현재 풀의 빈 정보 관점이라는 증거가 없어 근거 부족이다.

### 6위: kgmuzu

[Two XGBoost models + rainfall fraction per group](https://www.kaggle.com/competitions/playground-series-s5e3/writeups/kgmuzu-two-xgboost-models-rainfall-fraction-per-gr)는 kgmuzu의 6위 글이다.
목록과 상세 화면 모두 댓글 1개를 표시했다.

작성자는 대회 훈련 자료용 XGBoost와 원본 자료용 XGBoost의 OOF를 따로 만들고 원본 모형에 `0.3` 가중치를 주어 합쳤다.
각 열로 묶은 평균, 표준편차, 왜도와 강수 비율을 추가했으며 강수 비율이 XGBoost에서 가장 두드러졌다고 했다.
모형은 `max_depth=6`, `colsample_bytree=0.9`, `subsample=0.9`, `n_estimators=10000`, `learning_rate=0.1`, `early_stopping_rounds=100`인 XGBRegressor였다.
검증은 전월 Chris Deotte 방식의 안쪽과 바깥쪽 분할 구조를 사용했다고만 적었고 수치 CV, Public과 Private 점수는 보고하지 않았다.
댓글은 노트북 공개 요청 하나뿐이고 작성자 답변은 없다.

S6E8 판단은 기존 결정과 중복이다.
원본 전용 모형과 합성 전용 모형을 따로 두는 관점은 자체 풀의 원본 최근접 라벨, 원본 프록시 잔차와 원본 분포 관점이 이미 덮는다.
강수 비율은 대회 고유 목표 통계라 S6E8에 직접 대응하지 않는다.

## S5E2: Backpack Prediction Challenge

### 1위: Chris Deotte

[1st Place - Single Model - Feature Engineering](https://www.kaggle.com/competitions/playground-series-s5e2/writeups/chris-deotte-1st-place-single-model-feature-engine)는 Chris Deotte의 1위 글이다.
목록에는 댓글 102개가 표시됐고 상세 화면에는 일반 댓글 97개와 감사 댓글 5개가 표시됐다.

최종 해법은 500개 특성을 넣은 단일 XGBoost였고 A100 80GB 한 장을 사용했다.
138개 특성의 T4 16GB 단순판도 1위 수준이라고 보고했지만 CV, Public과 Private 수치는 본문에 없다.
핵심은 `groupby(COL1)[COL2].agg(STAT)` 형태의 평균, 표준편차, 개수, 최솟값, 최댓값, 값 종류 수와 왜도였다.
회귀 목표인 가격의 그룹별 히스토그램 구간 빈도와 분위수, 수치 반올림, 소수 자릿수, 범주 쌍, 파생 통계 비율도 사용했다.
모든 결측 여부를 2진수 한 열로 합친 결측 양상 범주를 만들고 다시 그룹 집계의 키로 사용했다.
원본 자료의 무게별 평균 가격을 제조사 권장가에 비유해 새 열로 붙였다.
목표값을 쓰는 통계는 중첩 분할로 누출을 막았다고 명시했다.

댓글에서 작성자는 관련 특성 약 12개를 한 묶음으로 순차 추가하고 CV가 오르면 전부 유지했다고 설명했다.
수백 개가 쌓인 뒤 한 분할에서 재귀 제거와 XGBoost 중요도 제거를 시도했지만 전체 분할에서는 차이가 없어 최종 제거를 쓰지 않았다.
원본 자료 병합은 CV와 리더보드를 `0.005` 개선했다고 답했다.
범주 결합 뒤 목표 평균을 붙이면 나무가 여러 범주 조합을 한 번의 분기로 묶을 수 있다고 설명했다.
히스토그램과 분위수는 그룹 안 가격 분포가 여러 봉우리를 가진다는 중요도 관찰에서 나왔다고 했다.
지도형 심층 모형을 여러 구조로 시도했지만 GBDT 수준에 도달하지 못했다고 답했다.

S6E8 판단은 대부분 기존 결정과 중복이다.
정확값 목표 평균과 빈도, 반올림, 자릿수, 범주 쌍, 원본 목표값 통계는 자체 35개 풀의 채택 또는 기각된 관점에 이미 있다.
회귀 목표의 히스토그램과 분위수는 이진 목표에서는 양성 수, 음성 수와 평균으로 퇴화하므로 현재 과제에 새 정보가 아니다.
결측 양상 범주는 S5E2에서는 생성 과정 신호였지만 S6E8의 결측 표시와 결측 개수 제거 대조는 무익 또는 악화였으므로 기존 배제 결정을 유지한다.

목표값 통계 결측 대체에 현재 안쪽 학습 부분이 아닌 전체 train 평균을 사용한 것은 약한 누출이라고 직접 인정했다.
작성자는 이 누출판이 CV와 리더보드를 올려 사용했다고 설명했지만, S6E8 계약은 바깥 검증 목표값이 어떤 대체 통계에도 들어가는 것을 허용하지 않는다.
높은 값 종류 수의 결합은 값당 약 40개 관측을 확보할 만큼 큰 자료에서만 탐색한다고 설명했다.
합성 자료에서는 사람이 이해하기 어려운 생성 신호가 있어 실제 자료보다 자동 조합 탐색을 더 많이 한다고 답했다.

S6E8 판단은 기존 결정과 중복 또는 현재 계약에 부적합이다.
정확값 목표 평균과 빈도, 자릿수, 반올림, 쌍 통계와 자동 선택은 이미 자체 실험에서 채택 또는 기각됐다.
삼중 이상은 쌍 66개의 완전 중첩 선택이 음성이어서 개방 조건이 닫혀 있다.
전체 train 평균을 안쪽 통계에 쓰는 방법은 성능과 무관하게 목표값 누출이라 사용할 수 없다.

### 2위: SCRIPTCHEF

[Rank 2 approach - brute force ensembling (118 oofs)](https://www.kaggle.com/competitions/playground-series-s4e12/writeups/scriptchef-rank-2-approach-brute-force-ensembling-)는 SCRIPTCHEF의 2위 글이다.
목록에는 댓글 8개가 표시됐고 상세 화면에는 일반 댓글 7개와 감사 댓글 1개가 표시됐다.

AutoGluon, H2O, FLAML, LAMA, TabNet, DeepTables, XGBoost, LightGBM과 CatBoost에서 118개 OOF를 모았다.
AutoGluon은 값 종류가 많은 건강 점수 범주를 넣었을 때 상위 단계 모형에 정보 누출이 생겨 심하게 과적합했다고 보고했다.
목표를 크기 순 구간의 다중 범주로 바꾼 CatBoost OOF, OpenFE 특성, 원본 자료와 서로 다른 특성 집합도 사용했다.
최종 결합은 Ridge가 주 방식이었고 탐욕 결합은 73개로 같은 점수를 냈다.
TabNet 비선형 결합 출력 하나를 다시 OOF로 더하자 전체 결합이 조금 좋아졌다고 했다.
원본 자료는 튜닝된 모형의 CV를 약 `1.031`에서 `1.027`로 개선했다.
최종 CV, Public과 Private 수치는 보고하지 않았다.

댓글에서 Optimistix도 AutoGluon의 누출 결과를 독립적으로 경험했다고 확인했다.
S6E8 판단은 기존 결정과 중복이다.
대규모 OOF, Ridge, 탐욕 선택, 비선형 2단 결합, AutoML과 원본 관점은 자체 35개와 외부 278개 결합 또는 자체 음성 실험이 이미 덮는다.
연속 목표의 순서 구간 다중 분류는 이진 목표에서는 원래 목표와 같아 새 관점이 아니다.
AutoGluon 상위 단계 정보 누출은 외부 OOF의 상류 분할 준수를 별도 검증해야 한다는 주의 근거로만 남긴다.

### 9위: Optimistix

[9th place solution: With a little help from my (Kaggle) friends](https://www.kaggle.com/competitions/playground-series-s4e12/writeups/optimistix-9th-place-solution-with-a-little-help-f)는 Optimistix의 9위 글이다.
목록과 상세 화면 모두 댓글 9개를 표시했다.

공개 노트북의 OOF, 결측 파생, OpenFE 약 140개, 여러 CatBoost 목적 함수와 표본 추출, 신경망을 모았다.
최고 단일은 30-fold CatBoost로 CV `1.03152`, Public `1.02935`, Private `1.03081`이었다.
최종 81 OOF Lasso는 CV `1.02729`, Public `1.02601`, Private `1.02765`로 9위였다.
같은 81 OOF의 AutoGluon은 마감 뒤 CV `1.02536`, Public `1.02398`, Private `1.02582`였고 순위는 여전히 9위였다고 보고했다.
댓글은 기술적 보충 없이 위로와 축하 중심이었다.

S6E8 판단은 기존 결정과 중복이다.
공개 OOF 폭, Lasso, Ridge, AutoGluon과 여러 목적 함수의 CatBoost는 현재 확장 결합이 더 큰 규모와 엄격한 선택 경계로 덮는다.

## 반복 근거와 댓글 반례

원본 자료를 새 열이나 별도 모형으로 쓰는 방법은 S5E3 2위와 6위, S5E2 1위와 2위, S4E12 2위에서 반복됐다.
이 반복은 원본 프록시 관점의 유효성을 보강하지만 새 후보를 만들지는 않는다.

대규모 자료에서는 범주 결합과 목표값 통계 탐색이 성공했고 작은 원본 신호에서는 같은 탐색이 CV만 올리고 Private을 낮췄다.
S5E2 1위와 S4E12 1위는 수백만 행에서 공격적 특성 탐색이 통했고, S5E3 2위 댓글은 원본 366행에서 상호작용이 CV와 Public만 올리고 Private을 낮춘 직접 반례다.
따라서 행 수보다 독립 신호량과 선택 절차를 보아야 하며, 현재 S6E8은 결과를 본 뒤 고르는 특성 선택을 반드시 중첩 재현해야 한다.

강한 모형을 더 많이 넣는 것이 항상 이득은 아니었다.
S5E3 2위의 추가 세 모형, S5E2 5위의 25모형 AutoGluon, S5E1 6위의 약한 Transformer 결합은 CV 또는 Public을 올려도 Private을 개선하지 못했다.
이는 외부 278개 가운데 약한 고전 모형 120개를 뺐을 때 313개 확장 결합이 좋아진 현재 절제 결과와 같은 방향이다.

누출은 상위권 글에도 실제로 존재했다.
S4E12 1위는 전체 train 평균을 안쪽 목표값 통계에 쓰는 약한 누출을 인정했고, S4E12 2위와 9위는 AutoGluon 상위 단계 정보 누출을 독립적으로 관찰했다.
따라서 순위가 높거나 CV와 Private이 함께 좋았다는 사실만으로 상류 OOF를 안전하다고 간주할 수 없다.

## 적용 우선순위와 종료 조건

이번 구간만을 근거로 새 실험 티켓을 만들지 않는다.
자체 35개와 외부 278개의 현재 확장 결합을 기준으로 유지한다.
원본 프록시, 정확값 통계, 결합 전략과 교사-학생 보정의 기존 판정을 다시 열지 않는다.

지도형 자동부호화 또는 SVC를 다시 검토하려면 현재 자료에서 기존 35개와 다른 정보 관점 또는 오류 계열이라는 사전 증거가 먼저 필요하다.
최소한 공통 fold의 OOF 및 시험 예측 쌍, 자체 풀 최근접 순위 상관, 고정 후보 단일 포함과 제외 nested OOF, 바깥 분할 반복 승리와 계산 자원 기록이 있어야 한다.
단독 AUC나 과거 대회의 순위만으로는 실험을 열지 않는다.

새 자료가 생겨도 ADR 0001의 계열 2 규약에 따라 현재 풀을 내용 해시로 고정하고 핵심 결합 전략을 양쪽에서 다시 선택해야 한다.
외부 예측이라면 OOF와 시험 예측의 행 정렬, 상류 fold 준수, 출처, 라이선스와 재배포 경계를 먼저 확인해야 한다.
Public 점수, 공개 제출 혼합 성과와 누출된 목표값 통계는 어떤 경우에도 개방 근거로 쓰지 않는다.

## 사실과 추론의 경계

순위, 작성자, 댓글 표시값, 본문과 댓글의 수치, 특성, 모형, 분할과 자원은 Kaggle 공식 화면에 적힌 사실이다.
본문이 보고하지 않은 팀 구성, CV, Public, Private, 계산 시간과 코드 세부는 미보고로 남겼다.
S5E1 4위의 Private `0.4560`이 오타처럼 보인다는 판단은 문맥 추론이며 수치를 고치지 않았다.

네 범주 분류와 S6E8 적용 판단은 조사자의 추론이다.
특히 회귀 목표 통계가 이진 목표에서 퇴화한다는 판단, SVC와 지도형 자동부호화가 현재 빈 방법이지만 근거 부족이라는 판단, 약한 모형 제거 결과와 과거 댓글 반례가 같은 방향이라는 해석은 원문 진술이 아니다.
