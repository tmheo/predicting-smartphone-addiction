이 문서는 [마감 전 병렬 실행 용량과 비용 예약을 동결한다](https://github.com/tmheo/predicting-smartphone-addiction/issues/509)의 측정 결과와 변경 불가 자원 명세를 기록한다.
기계 판독 원본은 `artifacts/issue509-parallel-capacity-freeze.json`이다.
동결 원본의 SHA-256은 `7685163fc3b5fbaeaea3f2ae2b35f9a23a93777a7524ea9ab6f8f0714dda5e1c`이다.
이슈 505에서 새 후보가 등록되어 기존 SHA-256 `7b1bd55de6050cd397f8cad94f25e9a840e7962a6a3816be781c4b4b1fb5c3bb` 명세를 대체했다.

## 결론

현재 후보 풀 36개는 그대로 유지한다.
이 가운데 이미 결측 증강판인 구성원은 대조 대상이 아니며, 외부 대형 모형인 `exp067_tabpfn3`는 후보 풀에는 남기되 이번 결측 증강 짝비교에서만 제외한다.
이슈 505에서 등록한 `exp209_issue505_lgb_lr_onehot_init`은 CPU 짝으로 추가한다.
따라서 이번 실행 대상 34개는 CPU 19짝과 일반 GPU 15짝으로 나뉜다.
설정에 장치가 적혀 있지 않아도 CUDA가 있으면 GPU를 고르는 신경망 구현은 일반 GPU 등급으로 분류했다.
로컬 CPU 1짝, Kaggle CPU 5짝, Vast.ai CPU 13짝, Vast.ai GPU 15짝을 한 번에 시작하면 34짝의 68개 비교 팔을 동시에 실행할 수 있다.
각 실행 자리에서는 3배 행 대조군과 독립 결측 증강군을 같은 호스트나 같은 공급자와 같은 실행 환경 등급에 묶고 두 팔을 동시에 시작한다.

## 현재 용량 측정

로컬 장비는 Apple M4 Pro 14코어, 메모리 48GiB, 여유 저장 공간 282GiB다.
재측정 시점의 CPU 유휴율은 `33.33%`, 메모리 압력 기준 여유율은 `82%`였으며 실행 중인 `pipeline.run` 학습은 없었다.

Kaggle 명령줄 도구에서 최근 CPU 커널은 모두 완료 상태였고 실행 중이거나 대기 중인 커널은 없었다.
과거 여섯 번째 CPU 커널 제출이 거부된 실측 근거에 따라 동시 커널 상한은 5개, 현재 가용 수도 5개로 고정한다.
각 커널은 두 팔을 한 실행 환경에서 동시에 돌리며 사전 추정 짝 경과 시간이 10시간 이하이고 두 프로세스 메모리 관문을 통과한 CPU 짝만 배치한다.

Vast.ai 계정에는 크레딧 `$13.03158340596893`이 있었고 실행 중인 인스턴스와 남은 저장 공간은 모두 0개였다.
2026년 8월 차감액 `$96.962`는 보수적 환산 기준으로 최소 145,443원이어서 기존 월 기본 비용 잔여분은 0원이다.
사용자는 이 지도에서 비용보다 최대 병렬 실행을 우선하고 필요하면 Vast.ai 크레딧을 추가하기로 결정했으므로 기존 월 기본 상한은 이번 동결의 용량 제한으로 쓰지 않는다.

2026-08-29 01:14 UTC 재검색에서는 가격 상한 안의 CPU 짝 호스트 29대와 일반 GPU 짝 호스트 25대가 서로 다른 장비로 확인됐다.
정상 배치에는 각각 13대와 15대가 필요하고 로컬과 Kaggle의 CPU 6짝을 모두 옮기는 최악의 경우에도 CPU 호스트는 19대면 된다.
따라서 현재 매물은 34짝을 동시에 시작하는 데 필요한 수보다 많다.

## 동일 환경 결속

같은 짝의 두 팔은 공급자, 실행 환경 등급, 컨테이너 이미지 내용 해시, 의존성 잠금 파일 해시를 공유한다.
Vast.ai에서는 한 짝을 한 호스트에 두고 CPU는 두 프로세스, GPU는 장치별 한 프로세스로 동시에 실행한다.
두 팔은 서로 분리된 작업 경로와 MLflow 저장소를 사용해 동시 기록 충돌을 막는다.
짝 호스트가 사라지면 같은 GPU 등급의 단일 팔 호스트 두 대를 같은 합산 시간당 가격 상한 안에서 사용할 수 있다.
Kaggle에서 한 팔만 끝나거나 시간 초과하면 남은 팔만 잇지 않고 같은 짝 전체를 Vast.ai CPU 예비 자리에서 다시 실행한다.

CPU 공급자 배정은 결과와 무관한 사전 추정 짝 경과 시간의 오름차순으로 정한다.
동률은 `artifacts/pool.yaml` 순서로 풀고, 로컬 1짝과 Kaggle 5짝을 먼저 채운 뒤 나머지 13짝을 Vast.ai에 둔다.
로컬이나 Kaggle의 두 팔 동시 실행이 메모리 관문을 통과하지 못하면 그 짝 전체를 Vast.ai CPU로 옮긴다.

## 실행 전 재확인

실제 매물 식별자는 이 동결에 넣지 않는다.
자원 생성 직전에 같은 검색 조건으로 CPU 짝 호스트 19대와 일반 GPU 짝 호스트 15대가 남아 있는지 다시 확인한다.
크레딧, 대회 전용 SSH 공개 키, 독립 종료 예약, 이미지 호환성과 입력 해시는 기존 원격 자원 관문을 모두 통과해야 한다.
조건을 충족하지 못한 개별 매물은 다른 적격 매물로 바꿀 수 있지만 공급자별 동시 실행 수, 짝 결속, 자원 하한, 가격 상한과 마감 시각은 바꾸지 않는다.
