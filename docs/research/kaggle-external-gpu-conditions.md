# Kaggle S6E8 자료의 외부 GPU 사용 조건

## 조사 질문과 판정

2026-08-14 JST 기준으로 Playground Series S6E8의 자료와 참가자 자신의 코드를 Google Colab 또는 시간제 GPU 서비스의 비공개 실행 환경으로 옮겨 실험하는 것은 대회 규칙상 허용된다고 판단한다.
S6E8 규칙은 외부 도구 사용을 명시적으로 허용하며, 특정 계산 장비나 Kaggle 안의 실행 환경만 사용하라고 제한하지 않는다.
다만 외부 도구는 모든 참가자가 합리적으로 접근할 수 있고 비용이 지나치지 않아야 하며, 참가자는 대회 자료가 규칙에 동의하지 않은 사람에게 노출되지 않도록 합리적이고 적절한 보호 조치를 해야 한다.
따라서 개인용 Colab Pro나 일반적인 시간제 GPU 한 대는 허용 범위에 들어갈 가능성이 높지만, 최종 판단 권한은 대회 주최자에게 있으므로 비용이 큰 전용 서비스나 접근 지역이 제한된 도구는 사전에 Kaggle에 확인해야 한다.

이 문서는 법률 자문이 아니라 현재 공개된 공식 규칙의 보수적인 운영 해석이다.

## 근거

### 외부 계산 환경

S6E8 전용 규칙 2.6은 외부 자료와 모델뿐 아니라 외부 소프트웨어 및 도구의 사용을 전제로 허용 기준을 정하고 있다.
외부 도구는 모든 참가자가 합리적으로 접근할 수 있고 비용이 적어야 하며, 주최자가 비용 문턱과 지역 제한 등을 바탕으로 합리성을 판단한다.
규칙은 소액 구독을 허용 가능한 예로 들고, 상금보다 비싼 독점 자료 사용권은 허용되지 않을 예로 든다.
같은 조항은 적절한 사용권을 확보한 자동화된 기계 학습 도구도 사용할 수 있다고 명시한다.
따라서 Colab Pro나 공개 가격의 시간제 GPU를 개인 계정의 비공개 실행 공간에서 쓰는 행위는 그 자체로 금지되지 않는다.
[S6E8 공식 대회 규칙 - 2.6 External Data and Tools](https://www.kaggle.com/competitions/playground-series-s6e8/rules)

S6E8 자료에는 CC BY 4.0 사용권이 붙어 있고, 전용 규칙 2.4는 상업 또는 비상업 목적을 포함한 사용을 허용한다.
그러나 같은 2.4의 자료 보안 의무도 동시에 지켜야 하므로, 사용권만 보고 대회 중 원본 자료를 공개 저장소나 공개 장비 이미지에 올려서는 안 된다.
[S6E8 공식 대회 규칙 - 1.7 및 2.4 Competition Data](https://www.kaggle.com/competitions/playground-series-s6e8/rules)

### 자료와 코드의 공개 범위

S6E8 규칙은 규칙에 동의하지 않은 사람이 대회 자료에 접근하지 못하도록 합리적이고 적절한 조치를 취하라고 요구한다.
참가자는 대회 자료를 참가하지 않은 사람에게 전송, 복제, 게시, 재배포하거나 달리 제공해서는 안 되며, 무단 전송이나 접근을 알게 되면 Kaggle에 즉시 알리고 바로잡아야 한다.
[S6E8 공식 대회 규칙 - 2.4.b Data Security](https://www.kaggle.com/competitions/playground-series-s6e8/rules)

대회 기간에는 같은 팀 밖으로 대회 관련 소스 코드나 실행 코드를 비공개로 공유할 수 없다.
코드를 공개하려면 모든 참가자가 이용할 수 있도록 해당 대회의 Kaggle 토론 게시판이나 노트북에서 공개해야 한다.
그러므로 외부 GPU 서비스의 작업 공간, 저장 공간, 장비 이미지, 스냅샷, 실행 기록 및 결과 주소는 비공개로 설정하고 팀원이 아닌 사람에게 공유하지 않아야 한다.
공개 이미지 저장소나 공개 Colab 노트북에 대회 자료 또는 비공개 대회 코드를 포함하는 방식은 허용 범위를 벗어난다.
[S6E8 공식 대회 규칙 - 3.5.d 및 3.6 Submission Code Requirements](https://www.kaggle.com/competitions/playground-series-s6e8/rules)

### 계정과 자격 증명

Kaggle 이용 조건은 계정이나 비밀번호를 다른 사람과 공유하지 말고 보안을 지키며, 계정에서 일어난 활동을 계정 소유자가 책임지도록 정한다.
한 Kaggle 사용자 식별자를 여러 사람이 함께 쓰는 것도 금지한다.
따라서 외부 장비에는 개인 계정의 API 토큰만 넣고, 팀원이나 서비스 운영자와 Kaggle 계정을 공동 사용해서는 안 된다.
[Kaggle 이용 조건 - What are the basics of using Kaggle?](https://www.kaggle.com/terms)

Kaggle의 공식 명령줄 도구 문서는 웹 인증, 환경 변수 `KAGGLE_API_TOKEN`, `~/.kaggle/access_token`, 예전 형식인 `~/.kaggle/kaggle.json`을 인증 방법으로 제시한다.
Kaggle의 공식 `kagglehub` 문서는 Colab 비밀 값 `KAGGLE_API_TOKEN`도 지원한다고 명시한다.
외부 장비에서는 비밀 값 기능이나 실행 시점의 환경 변수로 토큰을 주입하고, 노트북 셀, 출력, Git 저장소, 공유 드라이브, 장비 이미지 또는 스냅샷에 토큰 파일을 남기지 않는 방식이 이 조건에 가장 잘 맞는다.
[Kaggle 공식 명령줄 도구 인증 문서](https://github.com/Kaggle/kaggle-cli/blob/main/docs/README.md#authentication)
[Kaggle 공식 kagglehub 인증 문서](https://github.com/Kaggle/kagglehub/blob/main/README.md#authenticate)

### 외부 서비스와 보존 책임

Kaggle 이용 조건은 제3자 서비스 이용에 따른 위험을 사용자가 부담하고, 해당 서비스의 이용 조건과 개인정보 처리 방침을 직접 확인하도록 안내한다.
따라서 GPU 공급자가 비공개 저장 공간의 자료를 운영자 접근, 학습, 분석 또는 장기 보존에 사용하는지 여부는 공급자별 약관에서 별도로 확인해야 한다.
[Kaggle 이용 조건 - Who is responsible for what I see and do on the Services?](https://www.kaggle.com/terms)

S6E8 규칙에는 외부 장비의 비공개 저장본을 언제까지 삭제해야 한다는 명시적인 기한이 없다.
그렇더라도 자료 보안 의무를 계속 충족하고 불필요한 노출면을 줄이려면 결과를 회수한 직후 원본 자료, API 토큰, 임시 디스크, 장비 이미지와 스냅샷을 지우는 것이 가장 안전하다.
실험 결과를 장기 보관해야 한다면 접근 권한이 본인과 정식 팀원으로 제한된 저장 공간을 쓰고, 원본 `train.csv`와 `test.csv`를 결과 묶음에 함께 넣지 않는 편이 좋다.

## 안전한 실행 조건

다음 조건을 모두 지키면 Colab Pro 또는 시간제 GPU 사용을 진행해도 된다.

- 본인만 접근하는 비공개 작업 공간과 비공개 저장 공간을 사용한다.
- 공급자의 기본 설정과 장비 생성 화면에서 공개 노트북, 공개 포트, 공개 파일 주소, 공개 장비 이미지 및 공개 스냅샷이 꺼져 있는지 확인한다.
- Kaggle 토큰은 서비스의 비밀 값 기능이나 실행 시점 환경 변수로만 넣고 코드, 출력 및 장비 이미지에 기록하지 않는다.
- 대회 자료와 코드는 정식 팀원이 아닌 사용자, 지원 담당자 또는 다른 고객에게 공유하지 않는다.
- 외부 GPU 비용은 일반 참가자도 감당할 수 있는 소액 구독 또는 통상적인 시간제 사용료 범위로 제한한다.
- 자료 다운로드, 학습, 결과 회수에 필요한 최소 시간만 장비를 켜 두고 자동 종료를 설정한다.
- 회수 결과에는 측정값, 예측, 모델 가중치와 실행 기록만 포함하고 원본 대회 자료 사본은 넣지 않는다.
- 결과 회수 후 원격 디스크, 휴지통, 자동 백업, 장비 이미지, 스냅샷 및 비밀 값을 삭제하고 장비를 폐기한다.
- 코드나 결과를 공개해야 한다면 S6E8 규칙이 요구하는 대로 해당 대회의 Kaggle 공개 공간을 사용하고, 공개 전에 자격 증명과 원본 자료가 섞이지 않았는지 확인한다.

## 서비스 선택에 주는 결론

규칙 준수 관점에서 Colab Pro와 일반적인 시간제 GPU 사이에 본질적인 우열은 없다.
핵심 선택 기준은 개인 전용 실행 공간, 비밀 값 주입, 비공개 영구 저장, 자동 종료, 장비 이미지와 스냅샷 공개 여부, 완전 삭제 절차를 얼마나 분명하게 제공하는지다.
이 조건을 검증할 수 없는 공급자는 가격이나 GPU 성능이 좋아도 S6E8 실행 후보에서 제외해야 한다.
