# S6E8 사내 대회 회고 발표 제작 장부

이 문서는 [2시간 사내 대회 회고 이야기 흐름 설계서](s6e8-retrospective-story-flow.md)의 35개 화면을 실제 발표 자료로 옮길 때 사용할 제작 입력을 고정한다.
청중용 문구와 시각 자료를 완성하는 문서가 아니라, 화면마다 주장과 근거, 시각 자료, 발표자 메모, Confluence 보충 설명과 단일 기술 근거 부록의 연결 대상을 빠짐없이 대조하는 장부다.

## 적용 원칙

- 이야기 흐름 설계서의 5막, 35개 화면 순서와 시간 흐름은 바꾸지 않는다.
- 본문 화면에는 주장 하나와 이해에 필요한 최소 수치만 둔다.
- 발표자 메모에는 실제로 말할 오해 방지 문장과 수치의 읽는 법만 둔다.
- 실행 식별자, 전체 설정, 해시, 파일 경로와 분할별 또는 반복별 진단값은 발표자 메모나 Confluence 본문에 복제하지 않고 단일 부록에서 원본으로 연결한다.
- 일반 OOF, nested OOF, Public과 Private은 서로 다른 측정 경계로 유지한다.
- 교육용 예시와 실제 대회 자료에서 측정한 결과를 같은 종류의 근거처럼 보이지 않게 표시한다.
- 같은 내용이 다시 나오는 화면은 새 주장을 추가하지 않고 앞선 시각 자료의 구조와 용어를 재사용해 회수한다.

## 화면별 제작 입력

### 화면 01: Private 0.97109, 최종 14위에서 시작합니다

- **청중용 주장:** 공식 비공개 점수 `0.97109`로 최종 14위였고, 이 결과를 만든 과정을 되짚는다.
- **원본 근거:** R01과 R02의 제출 `55907610`, 공식 순위표 재조회와 제출 계보를 사용한다.
- **시각 자료:** V01의 공식 결과 표를 사용하고 Public은 호박 마름모, Private은 보라 별로 분리한다.
- **발표자 메모:** `0.97109`는 순위를 정한 비공개 점수이고 `0.97135`는 같은 제출의 공개 점수라고만 말한다.
- **Confluence 보충 설명:** 두 점수의 채점 표본이 다르고 개별 실험의 개선량으로 역산할 수 없음을 적는다.
- **부록 연결:** A의 공식 제출, 점수와 순위 항목으로 연결한다.

### 화면 02: 검증 가능한 작은 실험을 조립한 결과였습니다

- **청중용 주장:** 결과는 작은 실험, 서로 다른 오차와 공통 검수 절차를 조립해 얻었다.
- **원본 근거:** R01, R03과 이야기 흐름의 중심 메시지를 종합한 회고 주장이다.
- **시각 자료:** V02의 세 조각이 14위 결과로 모이는 길 지도를 사용한다.
- **발표자 메모:** 실험 실행 체계는 같은 실험 명세를 여러 장소에서 실행하고 결과를 로컬의 같은 검수 절차로 모으는 구조라고 처음 설명한다.
- **Confluence 보충 설명:** 세 조각을 각각 뒤에서 다룰 화면 범위와 연결하고 하나의 비밀 모델이 있었다는 뜻이 아님을 적는다.
- **부록 연결:** E, G와 H의 색인 첫머리로 연결한다.

### 화면 03: 12개 생활 습관 변수로 중독 위험의 순서를 예측했습니다

- **청중용 주장:** 식별자와 목표값을 제외한 12개 생활 습관 변수를 사용해 사람들의 스마트폰 중독 위험 순서를 예측했다.
- **원본 근거:** R04의 설정과 실행 기록에서 입력 12개, 이진 목표값 `addicted_label`, 학습 691,369행과 예측 296,302행을 확인한다.
- **시각 자료:** V03에서 한 사람의 12개 입력이 위험도 하나로 바뀌고 여러 사람이 순서로 놓이는 흐름을 사용한다.
- **발표자 메모:** 행 수는 질문이 나올 때만 약 69만 건과 약 30만 건으로 말하고 본문에는 넣지 않는다.
- **Confluence 보충 설명:** 정확한 입력 열과 행 수를 짧은 표로 적고 분류 문턱이 아니라 순위 평가라는 연결을 붙인다.
- **부록 연결:** A의 자료 범위와 목표값 항목으로 연결한다.

### 화면 04: ROC AUC는 순서 전체를 봅니다

- **청중용 주장:** ROC AUC는 임의의 중독 한 명을 비중독 한 명보다 더 높은 위험도로 놓는 비율이다.
- **원본 근거:** R02의 평가 정의와 R13의 비전문가 설명 결정을 사용한다.
- **시각 자료:** V03의 0.5부터 1.0 기준 막대와 네 사람의 두 위험 순서를 함께 사용한다.
- **발표자 메모:** 0.5는 무작위 순서, 1.0은 완전한 순서이며 정답 문턱 하나의 정확도가 아니라고 말한다.
- **Confluence 보충 설명:** 동률 처리와 곡선 정의는 부록으로 보내고 본문에는 쌍 순서 해석만 둔다.
- **부록 연결:** B의 ROC AUC 정의와 평가 구현 항목으로 연결한다.

### 화면 05: 청중 참여 1에서 더 좋은 위험 순서를 고릅니다

- **청중용 주장:** 청중은 정답 계산 없이 A와 B 가운데 더 나은 위험 순서를 고른다.
- **원본 근거:** R13의 교육용 참여 장면이며 실제 대회 행에서 뽑은 표본이 아니다.
- **시각 자료:** V03의 네 사람과 A 및 B 순서를 사용하되 점수와 정답 쌍은 가린다.
- **발표자 메모:** 손들기나 짧은 구두 투표만 받고 선택 이유를 한두 명에게 묻는다.
- **Confluence 보충 설명:** 이 네 사람은 ROC AUC 작동 원리를 설명하는 교육용 예시라고 명시한다.
- **부록 연결:** B의 교육용 네 사람 예시와 쌍 비교표로 연결한다.

### 화면 06: B는 네 쌍 모두에서 중독 한 명을 더 위에 놓았습니다

- **청중용 주장:** 교육용 예시에서 A는 네 쌍 중 세 쌍, B는 네 쌍 모두를 올바른 순서로 놓았다.
- **원본 근거:** R13에서 확정한 참여 장면의 계산을 사용하며 실제 모형 성적이라고 표현하지 않는다.
- **시각 자료:** V03의 같은 사람과 행 위치를 유지하면서 네 쌍과 3대 4 결과를 차례로 공개한다.
