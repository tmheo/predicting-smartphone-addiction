# 디스커션 증분 업데이트 절차

S6E8 대회 디스커션에 새로 올라온 글과 코멘트를 `docs/research/discussion-insights.md`에 반영하는 반복 절차다.
운영 방식은 [이슈 #8](https://github.com/tmheo/predicting-smartphone-addiction/issues/8)에서 결정했다.

## 일정

- 주간 회차: 2026-08-17(월), 2026-08-24(월).
- 최종 스냅샷: 마감(2026-08-31) 2~3일 전인 2026-08-28(금)~29(토) 사이 1회.
- 트리거는 수동이다. 사용자가 세션에서 "디스커션 업데이트 돌려줘"라고 요청하면 이 절차를 실행한다.
- 최종 스냅샷 이후에는 이 절차를 종료한다. 대회 종료 후 상위권 솔루션 정리는 이 절차의 범위 밖이며, 원하면 별도 효력으로 새로 연다.

## 기준 장부

읽은 스레드의 전수 목록은 `docs/research/discussion-insights.md`의 "부록: 읽은 스레드 장부"다.
장부에는 스레드 id, 제목, 확인 시점의 코멘트 수, 재방문 여부가 기록되어 있다.
문서에 반영된 범위와 읽은 범위가 한 커밋으로 함께 갱신되도록, 장부는 항상 종합 문서와 같은 커밋에서 고친다.

## 회차 절차

1. 디스커션 목록 페이지를 Jina Reader로 읽는다: `https://r.jina.ai/https://www.kaggle.com/competitions/playground-series-s6e8/discussion`.
   렌더링이 비면 재시도하고, 그래도 실패하면 insane-search 스킬, 그다음 브라우저 자동화로 폴백한다.
2. 목록을 장부와 대조해 새 스레드를 식별한다.
3. 재방문 스레드(장부에 표시)는 목록의 코멘트 수를 장부의 기록과 비교해, 늘어난 스레드만 다시 읽는다.
4. 새 스레드 전부와 3번에서 걸러진 재방문 스레드를 읽는다.
5. 종합 문서를 직접 갱신한다. 회차별 리딩 노트는 만들지 않는다.
   - 새 인사이트는 해당 주제 절에 넣고, 기존 규칙대로 출처 스레드 링크를 단다.
   - 기존 주장과 상충하면 상충 주장 판정표에 행을 추가하거나 갱신한다.
   - 문서 머리의 스냅샷 기준일을 회차 날짜로 갱신한다.
   - 장부를 갱신한다: 새 스레드 행 추가, 재확인한 스레드의 코멘트 수 갱신.
   - 이번 회차에 새로 본문에 인용된 스레드는 재방문 목록에 추가한다(목록도 증분 관리).
6. main에 직접 커밋하고, 커밋 메시지에 회차 날짜와 반영한 스레드 범위를 남긴다.
