# Kaggle 공개 노트북 사용 조건

## 기본 규칙

Kaggle에 공개된 노트북 소스는 공개 시 Apache License 2.0이 적용된다.
내려받은 `.ipynb`나 Kaggle API 메타데이터 안에 사용 조건 문구가 없더라도 공개 노트북 코드의 사용 허가가 불명확하다고 판단하지 않는다.
Kaggle 공개 페이지 하단의 사용 조건 표시와 [Kaggle 공식 Meta Kaggle Code 설명](https://www.kaggle.com/datasets/kaggle/meta-kaggle-code)을 근거로 삼는다.

## 코드를 참고하거나 재사용할 때

1. 공개 노트북 주소와 사용한 판본을 조사 문서나 구현 기록에 남긴다.
2. 코드를 복사하거나 수정해 배포하면 Apache License 2.0 원문 사본을 제공하고 원래의 저작권, 사용 조건과 고지 문구를 유지한다.
3. 수정한 파일에는 변경했다는 사실을 눈에 띄게 표시한다.
4. 원본에 `NOTICE`가 있으면 관련 고지를 파생물에도 보존한다.
5. 그대로 가져온 부분과 저장소 규율에 맞게 바꾼 부분을 구분해 기록한다.

[Apache License 2.0 원문](https://www.apache.org/licenses/LICENSE-2.0)의 조건이 이 요약보다 우선한다.
