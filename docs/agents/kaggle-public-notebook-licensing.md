# Kaggle 공개 노트북 사용 조건

## 기본 규칙

Kaggle에 공개된 노트북 소스는 공개 시 Apache License 2.0이 적용된다.
내려받은 `.ipynb`나 Kaggle API 메타데이터 안에 사용 조건 문구가 없더라도 공개 노트북 코드의 사용 허가가 불명확하다고 판단하지 않는다.
Kaggle 공개 페이지 하단의 사용 조건 표시와 [Kaggle 공식 Meta Kaggle Code 설명](https://www.kaggle.com/datasets/kaggle/meta-kaggle-code)을 근거로 삼는다.

## 코드를 참고하거나 재사용할 때

1. 공개 노트북 주소와 사용한 판본을 조사 문서나 구현 기록에 남긴다.
2. 코드를 복사하거나 수정해 배포하면 Apache License 2.0 원문 사본을 제공하고 원래의 저작권, 사용 조건과 고지 문구를 유지한다.
3. 수정한 파일에는 변경했다는 사실을 눈에 띄게 표시한다.
4. 원본에 `NOTICE`가 있으면 관련 고지를 파생물에도 보존한다.
5. 그대로 가져온 부분과 저장소 규율에 맞게 바꾼 부분을 구분해 기록한다.

[Apache License 2.0 원문](https://www.apache.org/licenses/LICENSE-2.0)의 조건이 이 요약보다 우선한다.

## 적용 범위 분리

공개 노트북 소스의 Apache License 2.0은 노트북이 읽는 자료, 사전 학습 모형, 설치 패키지, 외부 저장소 코드와 출력 파일의 사용 조건을 대신하지 않는다.
각 외부 구성요소의 출처와 사용 조건을 따로 확인하고 기록한다.
확인할 수 없는 코드, 모형, 자료는 재배포하거나 자체 산출물에 포함하지 않는다.
확인할 수 없는 공개 예측 배열(OOF·시험 예측)만은 아래 "공개 예측 배열의 사용 한정" 규칙에 따라 결합 입력으로 쓸 수 있다.

코드 재사용 허가와 실험 결과의 채택 가능성도 구분한다.
Apache License 2.0으로 코드를 사용할 수 있어도 자료 누출, fold 불일치, 학습 부분 밖에서 맞춘 전처리, 재현성 부족이나 외부 예측 제외 규칙은 별도로 바로잡아야 한다.

## 공개 예측 배열의 사용 한정

Kaggle 공개 데이터셋과 공개 노트북 출력물에 있는 다른 참가자의 예측 배열(OOF·시험 예측)은 라이선스가 `unknown`·`other`이거나 출력 파일에 라이선스 표시가 없어도 확장 스택 제출의 결합기 입력으로 사용할 수 있다.
이 규칙은 지도 #451의 2026-08-27 사용자 결정이고 이슈 #454가 문서로 옮겼다.
근거는 두 가지다.

- 대회 규칙 Section 6은 외부 자료가 공개돼 있고 무료이며 모든 참가자가 동등하게 접근할 수 있으면 사용을 허용한다.
- 우승 솔루션에 요구되는 라이선스가 None이라 대회 참가 목적의 사용에는 별도의 라이선스 부여가 필요하지 않다.

사용 한정의 뜻은 다음과 같다.

1. 예측 배열은 확장 스택 제출의 결합기 입력으로만 쓴다.
   후보 풀, champion 판정, 안전판 제출에는 넣지 않는다(`CONTEXT.md`의 외부 구성원 정의).
2. 배열을 저장소에 커밋하지 않고(`data/`는 커밋 제외 경로), 데이터셋이나 노트북으로 재배포하지 않으며, 솔루션 공개나 자체 산출물에 첨부하지 않는다.
3. 외부 구성원 장부(`docs/research/external-member-ledger.{md,json}`)에 출처(데이터셋 또는 노트북 주소), 라이선스 표시, 분할 근거 종류를 남기고, 라이선스를 확인할 수 없는 구성원에는 `license_unknown` 주의 사항을 단다.
4. CC BY 4.0·Apache 2.0 구성원은 제출 manifest와 문서에서 저작자 표기를 유지한다.
5. 라이선스는 검증 항목이 아니라 기록 항목이다.
   행 순서, 분할 일치, 재채점 AUC는 그대로 검증 항목이고, 10분할 배열과 2단계 산출물 제외 규칙도 그대로다.
