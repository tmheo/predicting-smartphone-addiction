# Vast.ai 원격 자원 제어 합격 보고서

## 검증 범위

2026년 8월 15일에 [GitHub 이슈 132](https://github.com/tmheo/predicting-smartphone-addiction/issues/132)의 운영 합격 기준을 실제 Vast.ai 계정으로 검증했다.
공식 `vastai` 명령줄 도구 경로와 직접 REST 경로에 서로 다른 저비용 RTX A4000 자원을 사용했다.
모든 시각은 UTC다.

공식 명령줄 도구는 고정 판본 v1.5.4를 사용했다.
일상 실행 키에는 `misc`, `instance_read`, `instance_write`, `user_read`, `billing_read`만 부여했다.
키는 macOS 키체인에 저장하고 자식 프로세스의 `VAST_API_KEY` 환경 변수로만 전달했다.

API 키, `instance_api_key`, Jupyter 토큰, SSH 개인 키, 실제 SSH 접속 주소와 원문 API 응답은 이 보고서와 실행 로그에 남기지 않았다.

## 공통 매물 조건

- 검증된 공급자
- 공급자 신뢰도 99.5% 이상
- 일반 임대
- GPU 메모리 16GB 이상
- 남은 임대 가능 시간 2.4시간 이상
- 직접 SSH 포트 1개 이상
- 시간당 총액 0.12달러 이하
- 계산 자원 디스크 5GB
- 프로젝트용 별도 저장 공간 1GB

RTX A4000을 우선했고 두 경로에 서로 다른 공급자 장비를 사용했다.
