# 같은 학습 궤적의 여러 시점을 독립 후보 실행으로 보존한다

신경망 학습 상태를 대조하려면 같은 입력, 난수 초기화, 학습 순서와 학습률 일정 지평에서 나온 여러 시점의 예측을 비교해야 한다.
시점마다 별도로 학습하면 같은 종료 횟수라도 학습률 일정이 달라지거나 실행 순서가 달라져 하나의 학습 궤적을 비교한다는 보증이 사라진다.
반대로 한 실행 안에 여러 예측 열만 저장하면 후보 풀 판정, 실행 기록 묶음 반입과 전체 자료 재학습이 요구하는 독립 실행 정체성이 없다.

## 결정

### 설정과 실행 정체성

- 후보 시점 전체 목록, 선택 시점, 궤적 종료 시점, 학습률 일정 지평, 상태 종류와 사전 고정 선택 규칙을 각 후보 설정의 `training_state` 블록에 기록한다.
- 한 후보는 고유한 설정 이름과 커밋된 설정 파일 하나를 가진다.
- 같은 궤적의 후보 설정들은 이름과 선택 시점 외의 내용이 모두 같아야 한다.
- 후보 설정 전체를 한꺼번에 전달한 전용 실행 경로만 `training_state` 설정을 실행할 수 있다.
- 기존 단일 설정 실행 경로는 `training_state` 설정을 거부하며 일반 설정의 의미와 산출물은 바꾸지 않는다.

### 물리 학습과 후보 게시

- 판정 불가 부모 실행 하나가 실제 학습 궤적과 진행 관측을 소유한다.
- 각 시드와 바깥쪽 분할에서 모델은 궤적 종료까지 한 번만 학습한다.
- 결과 확인 전에 고정한 각 시점의 EMA 상태에서 검증 예측, 시험 예측, 계열 무관 중요도, 학습 관측과 학습 길이 근거를 만든다.
- 각 시점은 표준 OOF, 시드별 OOF, 시험 예측, 중요도, 제출 파일과 고유 설정을 가진 독립 자식 실행으로 기록한다.
- 모든 자식 실행과 부모 계보 기록이 완성된 뒤에만 자식 실행의 `training_state.ready` 태그를 `true`로 바꾼다.
- 판정과 실행 기록 묶음 내보내기는 완료 상태와 준비 태그를 모두 확인한다.

### 계보와 복구

- 궤적 정체성 해시는 커밋, 입력 해시, 단계, 시드, 모델, 공통 설정, 후보 집합, 궤적 종료와 일정 지평을 포함한다.
- 후보 정체성 해시는 궤적 정체성, 후보 설정 해시, 선택 시점과 일정 지평을 포함한다.
- 후보 manifest는 사전 고정 후보 전체 목록, 검증 목표값을 선택에 사용하지 않았다는 값, 예측과 중요도 내용 해시를 보존한다.
- 기존 `FoldRecovery`의 단일 시점 의미는 바꾸지 않는다.
- 여러 시점 전용 복구 경계는 한 시드와 한 분할의 전체 후보 출력 집합을 한 번에 원자적으로 확정한다.
- 후보 일부만 남은 복구 상태는 재사용하지 않는다.

### 전체 자료 재학습

- 기존 일반 반복형 구성원은 관측 학습 길이 중앙값에 1.25를 곱하는 현재 규칙을 계속 사용한다.
- 학습 상태 대조축으로 채택된 후보만 `trajectory_state` 방식의 판별형 재학습 계약을 사용한다.
- 이 방식은 모든 시드와 분할의 관측 학습 길이가 후보 시점과 정확히 같은지 확인하고 그 시점 자체를 재학습 예산으로 사용한다.
- 전체 자료 학습은 후보 실행과 같은 학습률 일정 지평을 유지하고 선택 시점에서 정확히 끝나야 한다.
- 모델이 보고한 실제 종료 시점과 일정 지평을 요청 계약과 대조한 뒤에만 예측을 확정한다.
- 기존 재학습 계획 구성원 블록과 항목 해시는 바꾸지 않으며 새 방식은 계획 문법 판본 3의 새 구성원에서만 허용한다.

## 결과

- Lookup-Transformer는 실제 종료 횟수와 학습률 일정 지평을 분리하고 지정 시점의 EMA를 포착한다.
- RealMLP는 기존 `fixed_epochs`와 `schedule_epochs` 분리를 유지하며 지정 시점의 EMA를 포착한다.
- 후보 풀 판정과 실행 기록 묶음 반입은 각 시점을 기존 독립 실행과 같은 표면으로 소비할 수 있다.
- 중단 뒤 재개는 모든 후보 시점이 완성된 분할만 재사용하므로 후보 사이의 계보가 갈라지지 않는다.
- 기존 단일 시점 실행, 단일 시점 복구와 일반 1.25배 전체 자료 재학습 결과는 그대로 유효하다.

## 기각한 대안

- 시점마다 별도 학습하는 안은 학습률 일정과 난수 소비가 같은 궤적이라는 보증을 하지 못해 기각한다.
- 한 실행에 여러 예측 열만 저장하는 안은 후보 풀의 고유 설정과 독립 실행 계약을 충족하지 못해 기각한다.
- 기존 `FoldRecovery`에 시점 축을 추가하는 안은 단일 시점 복구 경계의 의미를 바꾸므로 기각한다.
- 정확 시점 재학습을 배수 `1.0`으로 표현하는 안은 일반 중앙값 배수 규칙과 다른 의미를 숨기므로 기각한다.
- 부모 실행의 한 시점을 대표 후보로 삼는 안은 나머지 후보와 비대칭 계보를 만들므로 기각한다.
