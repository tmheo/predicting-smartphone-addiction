# 복제 행 신경망 짝비교는 출처의 최적화 갱신 수와 학습률 궤적을 보존한다

결측 증강 전파 짝은 원본 학습 행을 세 배로 만들기 때문에 같은 epoch 수를 그대로 쓰면 신경망의 최적화 갱신 수가 약 세 배가 된다.
이전 구현은 관측 epoch 수만 고정해 출처와 같은 학습 노출량이라는 계약을 지키지 못했고, Lookup-Transformer에서는 선택 시점까지 학습률 일정 지평으로 줄여 학습률 위치도 바꿨다.

복제 행을 쓰는 신경망은 출처의 물리 배치 크기와 부모 행 수를 유지한다.
한 epoch마다 원본 부모를 출처와 같은 방식으로 섞고 부모마다 복제 보기 하나만 골라 학습하며, 부모별 보기는 epoch와 부모 위치로 결정적으로 순환한다.
따라서 3배 행 대조군은 출처와 같은 부모 배치와 경사 잡음 규모를 재현하고, 독립 결측 증강군만 같은 부모 자리에 다른 결측 보기를 넣는다.
모형 내부 전처리와 목표 인코딩 상태는 원본 부모 행에서만 맞춘 뒤 모든 보기에 적용한다.
출처에서 선택한 epoch 수는 두 비교군에 동일하게 적용하고, 선택 시점과 별개인 학습률 일정 지평도 출처 설정 그대로 보존한다.
트리 계열의 반복 수와 조기 종료 계약은 바꾸지 않는다.

물리 배치 크기를 행 배수만큼 늘리는 안은 갱신 수만 같게 만들 뿐 한 갱신에 참여하는 서로 다른 부모 수와 경사 잡음 규모를 바꾸므로 기각한다.
epoch 수를 행 배수만큼 늘리는 안은 이미 늘어난 epoch별 갱신 수에 다시 배수를 곱해 출처 대비 약 아홉 배의 갱신을 만들기 때문에 기각한다.
두 비교군에서 조기 종료를 각각 다시 수행하는 안은 결측 증강 외에 검증 선택 결과까지 비교군마다 달라지므로 기각한다.
