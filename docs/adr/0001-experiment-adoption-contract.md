# 실험 채택 판정 계약: 특성·다양성·앙상블 세 계열

이슈 #45의 결정이다.
실험 프로그램(#44)의 모든 후속 티켓은 실험 채택 여부를 이 계약으로 판정한다.
기존 개선 판정(#15, #19, #33)은 특성 challenger 하나만 다뤘으나, champion 교체·다양성 구성원·앙상블은 요구할 증거가 서로 달라 계열별로 분리해 확정했다.

## 공통 규약

- 판정 지표는 커밋된 `artifacts/folds.parquet`의 5-fold OOF AUC다.
- 다중 시드 실행의 OOF AUC는 시드별 예측을 평균한 뒤 채점한 값이다(시드 평균본).
- 시드는 스크리닝 42 단일, 확정 재검증 [42, 43, 44]로 고정한다.
- 시드별 OOF AUC를 MLflow 지표로 함께 기록해 시드별 비교를 가능하게 한다.
- 플라시보 피처는 모든 실행에 상시 포함한다.
  타깃 인코딩을 쓰는 실행은 placebo 카나리아의 중요도가 플라시보보다 낮아야 유효하다.
- 판정과 결과 요약이 읽는 피처 중요도는 계열 무관 중요도다(#97 개정).
  모든 모델 계열은 모델에 맞는 중요도를 gain 축으로 환산해 반환하며, gain importance가 없는 계열은 검증 fold permutation importance(AUC 하락 폭)를 쓴다.
  환산은 실행 시드로 결정적이어야 하고, 환산 방식과 정밀도 파라미터의 선택은 모델 계열이 소유한다.
  플라시보 게이트(카나리아·새 피처)는 이 환산값 위에서 계열 구분 없이 같은 비교 규칙으로 판정한다.
  permutation 환산은 플라시보 기준값이 0 근처라 정상 카나리아의 비교가 우연히 실패할 수 있으나, 실패는 채택을 막는 방향(fail-safe)이므로 허용 오차를 두지 않고 재실행으로 다룬다.
- Public 점수는 어떤 계열에서도 판정 근거가 아니다(마일스톤 건전성 점검 전용).

## 계열 1: 특성·단일 모델 challenger (champion 교체)

- 2단계 판정이다.
  seed 42 스크리닝에서 champion의 같은 시드(seed 42) OOF AUC 대비 개선이 0 이상이면 3시드 확정 재검증으로 넘어간다.
  기준선은 champion.yaml의 `seed_aucs[42]`다(#74 개정).
  시드 평균본 OOF AUC를 기준선으로 쓰면 시드 평균 이득(약 +0.0003)이 문턱에 섞여, 같은 시드끼리는 실재하는 +0.0002 규모 개선을 스크리닝이 걸러내기 때문이다.
- 확정 조건: 시드 평균본 OOF AUC가 champion 대비 +0.00002 이상이고, 3시드 중 2시드 이상에서 같은 시드의 champion 대비 시드별 OOF AUC 개선이 0보다 커야 한다.
- 개선 폭이 +0.00002 이상 +0.0002 미만인 경계 구간이면 시드 평균 fold 점수 5개 중 3개 이상 승리를 추가로 요구한다.
  그 외 구간에서 fold별 승리 수는 보조 증거로 기록만 한다.
- 피처를 추가한 실험은 새 피처의 fold별 gain importance 평균이 플라시보 평균보다 높아야 한다.
  피처를 추가하지 않은 실험(모델 계열·하이퍼파라미터 변경, 피처 제거)에는 이 조건을 묻지 않는다.
- champion 교체는 개선 폭과 무관하게 항상 3시드 확정을 거친다.
  단일 시드 개선이 +0.0003을 넘으면 그대로 채택하던 기존 `SINGLE_SEED_MARGIN` 규칙은 폐기한다.
  champion은 항상 3시드 평균본이라는 불변식을 유지하기 위함이다.

## 계열 2: 다양성 구성원 (후보 풀 진입)

- 진입 하한: 시드 평균본 OOF AUC가 진입 시점 champion − 0.01 이상.
  하한은 진입 시점에만 적용하고 champion 갱신 때마다 재심사하지 않는다.
- 스크리닝은 단일 시드로 허용하되, 진입 확정은 3시드 평균본으로 한다.
  후보 풀에는 시드 평균본만 등록한다.
- 중복 게이트: 풀 내 최근접 구성원과 OOF 예측의 순위 상관(스피어만)이 0.998 이상이면 중복으로 보고 성능이 높은 쪽만 유지한다.
  상관은 중복 제거에만 쓰고 다양성 가치의 하드 게이트로 쓰지 않는다.
- 기여 참고값: 표준 평가 앙상블(풀 전체의 순위 평균)의 OOF AUC에서 해당 구성원을 제외했을 때의 변화를 기록한다.
  균등 순위 평균 하나에서의 변화는 다른 결합 전략에 대한 기여를 대표하지 않으므로 진입이나 제거 게이트로 쓰지 않는다.
- 무결성과 중복 검사를 통과한 후보는 모두 P4의 nested OOF 평가에 넘긴다.
- 일괄 재심사는 P3의 풀 점검 티켓(#63)과 P4 앙상블 구성 단계에서 수행한다.
- 풀 진입은 새 피처 게이트를 묻지 않는다(#97 명문화).
  타깃 인코딩을 쓰는 실행의 카나리아 유효성(공통 규약)은 그대로 적용된다.
- 풀 장부는 커밋되는 `artifacts/pool.yaml`이다.
  구성원별 run id, OOF AUC, 진입 판정 근거(하한·상관·기여 값)를 기록한다.
  탈락은 티켓 코멘트와 MLflow 태그로만 남기고 장부에 넣지 않는다.

## 계열 3: 앙상블 (nested OOF)

- nested OOF 정의: outer fold k마다 나머지 4개 fold의 OOF만으로 구성원 선택과 가중치를 학습하고, 그 결과로 fold k 예측을 만들어 5개 fold를 합쳐 채점한 값이다.
  OOF 전체로 구성원과 가중치를 고른 뒤 같은 OOF로 채점하는 선택 편향을 막는다.
- 앙상블 구성원은 후보 풀의 시드 평균본만 쓴다(S6E2 2위 규칙).
- 채택 조건: nested OOF AUC가 champion(3시드 평균본)의 OOF AUC 대비 +0.00002 이상.
- 앙상블 간 비교도 nested OOF AUC로 하되, 차이가 +0.00002 미만이면 동률로 보고 구성원 수와 선택 자유도가 적은 더 단순한 방식을 선택한다.

## 기각한 대안

- 모든 실험을 처음부터 3시드로 실행: 판정은 단순해지나 탐색 폭이 좁아져 기각.
  대신 스크리닝 문턱을 개선 ≥ 0으로 느슨하게 잡아 시드 운 탈락을 줄였다.
- 3시드 전부 개선 요구: 시드 노이즈에 과민해 좋은 후보를 버릴 수 있어 2/3으로 완화.
- OOF 상관을 다양성의 하드 게이트로 사용: 상관이 높아도 잔차 구조가 다른 구성원의 기여를 놓칠 수 있어 중복 제거 전용으로 한정.
- fold별 승리 수를 상시 하드 게이트로 사용: 개선 폭이 큰 후보를 fold 편차로 막을 수 있어 경계 구간 전용으로 한정.

- 2026-08-17 (#64 후속): 계열 1과 계열 3의 공통 채택 문턱과 앙상블 동률 범위를 +0.0001에서 +0.00002로 낮췄다.
