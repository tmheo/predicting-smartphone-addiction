# 실험 채택 판정 계약: 특성·다양성·앙상블 세 계열

이슈 #45의 결정이다.
실험 프로그램(#44)의 모든 후속 티켓은 실험 채택 여부를 이 계약으로 판정한다.
기존 개선 판정(#15, #19, #33)은 특성 challenger 하나만 다뤘으나, champion 교체·다양성 구성원·앙상블은 요구할 증거가 서로 달라 계열별로 분리해 확정했다.

## 공통 규약

- 판정 지표는 커밋된 `artifacts/folds.parquet`의 5-fold OOF AUC다.
- 다중 시드 실행의 OOF AUC는 시드별 예측을 평균한 뒤 채점한 값이다(시드 평균본).
- 시드는 스크리닝 42 단일, 확정 재검증 [42, 43, 44]로 고정한다.
- 시드별 OOF AUC를 MLflow 지표로 함께 기록해 시드별 비교를 가능하게 한다.
- 플라시보 피처는 모든 실행에 상시 포함한다.
  목표 평균 인코딩을 쓰는 실행의 카나리아 키는 검증 행마다 학습 부분에 없는 고유값이어야 한다.
  따라서 검증 카나리아 값은 학습 부분 전체 목표 평균 하나로 고정돼야 한다.
  카나리아 중요도가 `max(원본 플라시보 중요도, 0)` 이하이면 유효하며 상한과 같은 값도 통과시킨다.
  새 피처 중요도는 계속 원본 플라시보 중요도보다 엄격히 높아야 한다.
- 판정과 결과 요약이 읽는 피처 중요도는 계열 무관 중요도다(#97 개정).
  모든 모델 계열은 모델에 맞는 중요도를 gain 축으로 환산해 반환하며, gain importance가 없는 계열은 검증 fold permutation importance(AUC 하락 폭)를 쓴다.
  환산은 실행 시드로 결정적이어야 하고, 환산 방식과 정밀도 파라미터의 선택은 모델 계열이 소유한다.
  플라시보 게이트(카나리아·새 피처)는 이 환산값 위에서 계열 구분 없이 같은 비교 규칙으로 판정한다.
  순열 중요도에서 원본 플라시보가 음수일 때도 상수 카나리아의 중요도 0이 거짓 실패하지 않도록 위 영가설 상한을 적용한다(#286 개정).
- Public 점수는 어떤 계열에서도 판정 근거가 아니다(마일스톤 건전성 점검 전용).

## 계열 1: 특성·단일 모델 challenger (champion 교체)

- 2단계 판정이다.
  seed 42 스크리닝에서 champion의 같은 시드(seed 42) OOF AUC 대비 개선이 0 이상이면 3시드 확정 재검증으로 넘어간다.
  기준선은 champion.yaml의 `seed_aucs[42]`다(#74 개정).
  시드 평균본 OOF AUC를 기준선으로 쓰면 시드 평균 이득(약 +0.0003)이 문턱에 섞여, 같은 시드끼리는 실재하는 +0.0002 규모 개선을 스크리닝이 걸러내기 때문이다.
- 확정 조건: 시드 평균본 OOF AUC가 champion 대비 +0.00002 이상이고, 3시드 중 2시드 이상에서 같은 시드의 champion 대비 시드별 OOF AUC 개선이 0보다 커야 한다.
- 개선 폭이 +0.00002 이상 +0.0002 미만인 경계 구간이면 시드 평균 fold 점수 5개 중 3개 이상 승리를 추가로 요구한다.
  그 외 구간에서 fold별 승리 수는 보조 증거로 기록만 한다.
- 피처를 추가한 실험은 새 피처의 fold별 gain importance 평균이 플라시보 평균보다 높아야 한다.
  피처를 추가하지 않은 실험(모델 계열·하이퍼파라미터 변경, 피처 제거)에는 이 조건을 묻지 않는다.
- champion 교체는 개선 폭과 무관하게 항상 3시드 확정을 거친다.
  단일 시드 개선이 +0.0003을 넘으면 그대로 채택하던 기존 `SINGLE_SEED_MARGIN` 규칙은 폐기한다.
  champion은 항상 3시드 평균본이라는 불변식을 유지하기 위함이다.

## 계열 2: 다양성 구성원 (후보 풀 진입)

후보 풀 판정 계약 판본은 `candidate-pool-v2`다.

- 신규 후보는 정식 장부에 넣기 전 현재 풀에 일시적으로 더한 읽기 전용 평가 사본에서 판정한다.
- 일반 후보 판정은 `missing_segmented_rank_logit`, `missing_interaction_rank_logit`, `shrunk_rank_logit_logistic` 세 가지 핵심 결합 방식만 평가한다.
  나머지 16개 기본 등록 결합 방식은 선택적 전체 점검에서만 평가한다.
  `pipeline.pool_judgment --full-combiners`가 19개 전체 평가 경로다.
- 평가 시작 때 후보 풀과 선택한 결합 방식 평가 범위 및 목록을 내용 해시로 동결한다.
  판정이 끝나기 전에 어느 하나라도 바뀌면 결과를 오래된 판정으로 표시하고 새 기준에서 다시 평가한다.
- 채택 자격은 3시드 평균본, 깨끗한 커밋, 커밋된 folds 내용 해시 일치와 누출 검사 통과다.
  진입 하한은 시드 평균본 OOF AUC가 진입 시점 champion보다 `0.01` 이상 낮지 않은 값이다.
- 결과를 보기 전에 고정한 후보 하나는 후보 포함 풀과 제외 풀을 직접 비교한다.
  같은 OOF에서 여러 변형 가운데 고른 후보는 바깥쪽 검증 분할의 학습 부분 안에서 선택 과정 전체를 반복한 선택 절차 대조를 먼저 통과해야 한다.
- 포함 풀과 제외 풀은 기본 등록 결합 방식을 각각 다시 평가하고, 각자의 최선 방식으로 만든 전체 nested OOF AUC를 비교한다.
- 지속 등록의 주 조건은 `포함 AUC - 제외 AUC > 0`이다.
  바깥쪽 검증 분할 승수는 선택 불안정성 경고로 기록하되 등록을 막거나 뒤집지 않는다.
- 양수 차이가 성능 동등 대역 상한 `+0.000027669802` 이내면 경계 기여로 표시한다.
  경계 기여는 등록을 막지 않고 다음 후보 풀 일괄 재심사의 우선 확인 대상으로 남긴다.
- 같은 동결 기준에서 여러 후보가 통과해도 하나씩만 직렬 등록한다.
  한 후보를 등록한 뒤 나머지는 갱신된 풀에서 다시 평가한다.
- OOF 예측의 스피어만 순위 상관이 `0.998` 이상인 중복 후보와 이전판 교체를 목적으로 제시된 같은 모델 계보 묶음 후보는 원자 교체 대조로 판정한다.
  현재 풀 `P_old`와 이전판 하나를 새 후보로 바꾼 `P_new`에서 각각 최선 기본 등록 결합 방식을 다시 고르고 `AUC(P_new) - AUC(P_old) > 0`일 때만 교체한다.
  단독 OOF AUC가 더 높다는 사실만으로는 교체하지 않는다.
  같은 모델 계보 묶음이어도 중복 문턱 미만이고 교체가 목적이 아니면 일반 지속 등록 규약으로 기존 구성원과 공존할 수 있다.
- 마지막 일괄 재심사 뒤 지속 등록과 교체가 합계 5건 쌓인 때와 전체 자료 재학습 또는 최종 동결 직전 중 먼저 오는 시점에 후보 풀을 일괄 재심사한다.
  현재 풀의 모든 단일 제거 후보를 비교하고, 제거 뒤 전체 nested OOF AUC가 가장 많이 높아지는 구성원 하나를 제거한 다음 줄어든 풀에서 다시 전수 비교한다.
  `제거 후 AUC - 제거 전 AUC > 0`인 실제 개선만 제거 근거로 쓰며 양수 개선이 없을 때 종료한다.
- 누출, 잘못된 fold, 내용 해시 불일치나 손상된 OOF로 판정 입력이 무효인 구성원은 성능 대조 없이 즉시 제거한다.
  계산 실패와 시간 초과는 판정 불가이며, 신규 후보는 미등록 상태로 남기고 기존 구성원은 제거하지 않는다.
- 제거한 구성원은 자동 복구하지 않는다.
  후보 풀 구성이나 기본 등록 결합 방식 집합이 바뀐 뒤에만 현재 지속 등록 규약으로 다시 평가할 수 있다.
  결함 수정판은 자동 복구가 아니라 별도 신규 후보로 판정하고, 같은 계보 교체로 제거된 이전판은 역방향 원자 교체 대조를 통과해야 한다.
- 등록, 교체, 제거와 복구는 후보 신원과 모델 계보 묶음, 동결 후보 풀과 기본 등록 결합 방식 집합 해시, 후보 선택 경위, 양쪽 최선 방식과 nested OOF AUC, 전체 및 분할별 차이, 경계 기여 여부, 최종 상태와 근거 산출물 해시를 변경 불가 후보 풀 판정 기록으로 남긴다.
  교체 기록에는 이전판, 제거 기록에는 당시 기준 풀, 복구 기록에는 원래 제거 기록을 추가한다.
- `pipeline.pool --admit`은 현재 후보 풀과 folds, 계약 판본에 맞는 결합 방식 평가 범위, 후보와 교체 대상, 양수 nested OOF 차이와 근거 산출물 해시가 모두 유효한 `candidate-pool-v2` 판정 기록을 소비할 때만 `artifacts/pool.yaml`을 쓸 수 있다.
  기존 `candidate-pool-v1` 기록은 당시 19개 전체 목록과 해시를 그대로 검증해 읽을 수 있다.
- folds, 기본 등록 결합 방식 집합, nested OOF 절차 또는 성능 동등 대역 측정 절차가 바뀌면 계약 판본을 올린다.
  영점 대역 재측정과 후보 풀 일괄 재심사를 마칠 때까지 신규 지속 등록과 복구를 보류한다.
- 풀 진입은 새 피처 게이트를 묻지 않는다.
  타깃 인코딩을 쓰는 실행의 카나리아 유효성은 공통 규약대로 적용한다.
- 후보 풀 장부는 커밋되는 `artifacts/pool.yaml`이다.
  현재 32개 시작점은 이전 등록의 양수 포함 기여를 소급 요구하지 않고 이후 일괄 재심사 규칙을 적용한다.

## 계열 3: 앙상블 (nested OOF)

- nested OOF 정의: outer fold k마다 나머지 4개 fold의 OOF만으로 구성원 선택과 가중치를 학습하고, 그 결과로 fold k 예측을 만들어 5개 fold를 합쳐 채점한 값이다.
  OOF 전체로 구성원과 가중치를 고른 뒤 같은 OOF로 채점하는 선택 편향을 막는다.
- 앙상블 구성원은 후보 풀의 시드 평균본만 쓴다(S6E2 2위 규칙).
- 채택 조건: nested OOF AUC가 champion(3시드 평균본)의 OOF AUC 대비 +0.00002 이상.
- 개선 폭이 +0.00002 이상 +0.0002 미만인 경계 구간이면 outer fold 5개 중 3개 이상 승리를 추가로 요구한다.
  그 외 구간에서 outer fold별 승리 수는 보조 증거로 기록만 한다(계열 1과 대칭).
- 채택 조건을 통과한 앙상블 중 nested OOF AUC가 가장 높은 방식을 선택한다.
  전략 간 별도 동률 범위나 복잡도 우선 규칙은 두지 않는다.

## 기각한 대안

- 모든 실험을 처음부터 3시드로 실행: 판정은 단순해지나 탐색 폭이 좁아져 기각.
  대신 스크리닝 문턱을 개선 ≥ 0으로 느슨하게 잡아 시드 운 탈락을 줄였다.
- 3시드 전부 개선 요구: 시드 노이즈에 과민해 좋은 후보를 버릴 수 있어 2/3으로 완화.
- OOF 상관을 다양성의 하드 게이트로 사용: 상관이 높아도 잔차 구조가 다른 구성원의 기여를 놓칠 수 있어 중복 제거 전용으로 한정.
- fold별 승리 수를 상시 하드 게이트로 사용: 개선 폭이 큰 후보를 fold 편차로 막을 수 있어 경계 구간 전용으로 한정.
