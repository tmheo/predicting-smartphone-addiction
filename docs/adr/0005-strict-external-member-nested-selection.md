# 엄격 외부 후보는 단독 성능 하한 없이 중첩 결합 기여로 선별한다

현재 313개 확장 구성은 여러 공개 출처에서 모은 외부 예측을 포함하지만, 개별 구성원의 재현 가능성과 누출 방지 근거가 모두 같은 수준은 아니다.
별도 재감사와 신규 조사로 OOF와 시험 예측을 함께 검증할 수 있는 외부 후보 19개를 확보했으며, 2026-08-30 증분 확인에서 새로 자격을 갖춘 후보가 나오면 동결 전에 더할 수 있다.
이 후보를 전체 OOF에서 한 번 고른 뒤 같은 OOF로 개선을 주장하면 선별 편향을 숨기게 된다.
반대로 단독 AUC 하한이나 단독 AUC 순서로 후보를 미리 줄이면 단독 성능은 낮아도 기존 구성의 오차를 보완하는 후보를 놓칠 수 있다.

## 결정

### 비교 경계와 동결 입력

- 현재 313개 확장 구성은 변경하지 않는 비교 팔로 둔다.
- 후보 절차 팔은 자체 후보 풀 35개를 필수 시작 구성원으로 두고 엄격 외부 후보만 추가로 선별한다.
- 자체 35개는 검색에서 제거하거나 외부 후보와 교체하지 않는다.
- 선별 단위는 출처나 모델 계열 묶음이 아니라 검증된 개별 OOF와 시험 예측 쌍이다.
- 현재 엄격 외부 후보 집합은 19개이며 2026-08-30 증분 확인에서 새로 자격을 갖춘 후보가 나오면 사전 고정 전에 원장 끝에 더한다.
- 후보 신원과 순서, OOF와 시험 예측 내용 해시, folds 해시, 현재 313개 구성 해시, 자체 35개 구성 해시, 고정 결합 전략, 검색 규칙과 코드 상태를 결과 확인 전에 동결한다.
- 공개 점수는 후보 선별, 절차 통과 판정과 최종 제안 명단 어디에도 사용하지 않는다.

### 바깥 분할 안의 후보 선별

- 바깥쪽 채점 분할 하나를 봉인하고 나머지 4개 분할의 행만 후보 측정과 검색에 사용한다.
- 각 외부 후보의 단독 AUC와 후보 사이 스피어만 순위 상관은 열린 4개 분할에서 계산해 진단값으로 기록한다.
- 단독 AUC는 후보 자격, 선별 하한, 검색 순서와 중복 후보 대표 선택에 사용하지 않는다.
- 외부 후보가 필수 자체 구성원 가운데 하나와 스피어만 순위 상관 `0.998` 이상이면 그 바깥 분할의 검색에서 제외한다.
- 외부 후보끼리 스피어만 순위 상관 `0.998` 이상이면 상호 배타 후보군으로 기록하며 어느 한쪽도 단독 성능으로 미리 제거하지 않는다.
- 검색 결과는 필수 자체 구성원과 선택 외부 후보 전체에서 모든 구성원 쌍의 스피어만 순위 상관이 `0.998` 미만인 후보 풀 중복 불변식을 만족해야 한다.
- 빠른 다중 후보 검색은 고정 `shrunk_rank_logit_logistic` 결합 전략 하나만 사용한다.
- 검색 풀 점수는 열린 4개 분할 안에서 다시 한 분할씩 빼고 예측을 이어붙인 AUC다.
- 같은 행의 목표값으로 결합기를 맞추고 그 행을 다시 채점한 값을 검색 풀 점수로 사용하지 않는다.

### 허용 이동과 정지 규칙

- 검색은 자체 35개만 담은 필수 시작 구성에서 출발한다.
- 순방향 단계는 선택하지 않은 외부 후보의 단일 추가와 선택 외부 후보 하나를 충돌하는 미선택 외부 후보 하나로 바꾸는 단일 원자 교체를 모두 정확히 평가한다.
- 후보가 선택 외부 후보 여러 개와 충돌해 단일 원자 교체만으로 후보 풀 중복 불변식을 회복할 수 없으면 그 상태에서 교체할 수 없다.
- 순방향 단계는 허용 이동 가운데 AUC 차이가 가장 큰 엄격한 양수 이동 하나를 받고 다시 모든 이동을 평가하며, 양수 이동이 없을 때 멈춘다.
- 후방 단계는 선택한 외부 후보의 단일 제거를 모두 정확히 평가해 가장 큰 엄격한 양수 이동 하나씩을 받고 양수 제거가 없을 때 멈춘다.
- 후방 단계 뒤 순방향 단계를 다시 수렴시킨다.
- 그 뒤 선택하지 않은 외부 후보의 허용된 순서 없는 쌍 추가를 한 번 전수 평가한다.
- 가장 좋은 후보 쌍의 AUC 차이가 엄격히 양수면 그 쌍을 원자적으로 추가하고 순방향, 후방, 순방향 순서로 다시 수렴한 뒤 검색을 끝낸다.
- 후보 쌍의 최대 AUC 차이가 양수가 아니면 현재 명단에서 검색을 끝낸다.
- 여러 선택 외부 후보를 한꺼번에 바꾸는 이동과 두 개보다 큰 묶음 추가는 허용하지 않는다.
- 모든 단계에서 최대 이동이 정확히 같으면 동결 후보 원장 순서로 결정하고, 후보 쌍 동률은 그 순서에 따른 사전식 비교로 결정한다.
- 성능 동등 대역과 수치 오차 범위는 경계 기여 보고에만 쓰며 이동 승인 문턱을 바꾸지 않는다.

### 바깥 분할 예측과 절차 판정

- 바깥 분할의 외부 후보 명단을 잠근 뒤 열린 4개 분할 전체에 고정 결합 전략을 맞춰 봉인한 분할의 후보 절차 팔 예측을 한 번 만든다.
- 현재 313개 비교 팔도 같은 바깥 분할과 같은 고정 결합 전략으로 맞추고 예측한다.
- 이 과정을 바깥 분할 5곳에 각각 독립적으로 반복하고 두 팔의 예측을 원래 행 순서로 이어붙인다.
- 후보 절차 팔의 이어붙인 AUC가 현재 313개 비교 팔보다 `0.00002` 이상 높고 바깥 분할 5곳의 AUC 차이가 모두 엄격히 양수일 때만 절차를 통과시킨다.
- 전체 AUC 차이는 분할별 AUC 차이의 평균이 아니라 이어붙인 두 예측을 직접 채점한 차이다.
- 계산 하나라도 실패하거나 끝나지 않으면 완료한 일부 결과를 사용하지 않고 전체 판정을 판정 불가로 둔다.
- 중단 뒤 재개는 모든 입력 해시와 코드 상태가 정확히 같을 때만 허용한다.

### 실제 제안 명단

- 절차가 통과한 뒤에만 같은 동결 규칙을 전체 OOF에 한 번 적용해 실제 엄격 외부 제안 명단을 만든다.
- 전체 OOF 선별 점수는 절차 통과 문턱을 다시 판정하는 데 사용하지 않는다.
- 바깥 분할별 선택 횟수와 전체 OOF 제안 명단의 차이는 선택 안정성으로 기록한다.
- 분할별 명단을 투표, 교집합 또는 합집합으로 합쳐 실제 제안 명단을 만들지 않는다.
- 이 결정은 선별 계약만 확정하며 실제 외부 구성원 반입, 중첩 실행, 구성 조립과 제출은 수행하지 않는다.

### 변경 불가 산출물

- `precommit.json`은 동결 후보 신원과 순서, 모든 내용 해시, folds 해시, 두 시작 구성 해시, 고정 결합 전략, 검색 규칙과 코드 상태를 담는다.
- `fold-<k>/selection.json`은 열린 행 범위, 단독 AUC, 상관과 충돌 관계, 평가한 모든 이동, 승인한 이동, 최종 명단과 중단 상태를 담는다.
- `fold-<k>/predictions.parquet`은 후보 절차 팔의 봉인 분할 예측을 담는다.
- `fold-<k>/baseline-predictions.parquet`은 현재 313개 비교 팔의 같은 분할 예측을 담는다.
- `nested-comparison.json`은 이어붙인 전체 AUC 차이, 분할별 AUC 차이, 5분할 부호와 통과 문턱 판정을 담는다.
- `selection-stability.json`은 후보별 분할 선택 수, 분할별 명단과 전체 OOF 제안 명단의 차이를 담는다.
- `full-selection.json`은 절차 통과 뒤에만 만들며 전체 OOF 검색 이동, 실제 제안 명단과 시험 예측 열 순서를 담는다.
- `report.md`는 사람이 판정을 검토할 수 있는 요약이며 `manifest.sha256`은 모든 판정 산출물의 내용 해시를 묶는다.

## 결과

- 단독 성능이 낮아도 기존 구성의 오차를 보완하는 외부 후보가 실제 결합 기여를 증명할 기회를 얻는다.
- 매우 비슷한 외부 후보의 대표는 단독 성능이 아니라 현재 구성에서의 추가 또는 교체 기여로 정해진다.
- 외부 후보 수가 늘어도 각 단계의 이동 집합과 정지 조건이 결정적이라 같은 입력과 코드에서 같은 명단을 재현할 수 있다.
- 계산량은 단독 AUC 하한이나 탐욕적 중복 제거보다 커지지만 누출 방지와 보완 후보 보존을 우선한다.
- 바깥 분할별 명단이 달라질 수 있으나 이는 절차 평가의 자연스러운 결과이며 실제 제안 명단을 투표로 정할 근거가 아니다.

## 기각한 대안

- `champion AUC - 0.01` 단독 성능 하한은 보완적인 약한 후보를 검색 전에 버리므로 기각한다.
- 후보끼리 중복일 때 단독 AUC가 높은 후보를 대표로 남기는 안은 현재 구성에서의 실제 기여를 보지 않으므로 기각한다.
- 전체 OOF에서 명단을 먼저 고르고 같은 OOF로 교체 문턱을 판정하는 안은 선별 편향을 숨기므로 기각한다.
- 바깥 분할별 선택 빈도로 실제 제안 명단을 만드는 안은 평가한 절차와 실제 적용 절차를 다르게 만들므로 기각한다.
- 공개 점수로 동률이나 경계 결과를 해소하는 안은 비공개 결과를 향한 반복 편향을 만들므로 기각한다.
- 여러 선택 후보를 한꺼번에 바꾸는 일반 묶음 교체는 탐색 공간과 정지 규칙을 별도로 정해야 하므로 이번 계약에 포함하지 않는다.
