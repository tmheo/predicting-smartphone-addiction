# #340 원형: 선택 편향 없는 후보 풀 재심사 절차

버릴 수 있는 원형이다.
main에 병합하지 않고 `prototype/issue-340-pool-rereview` 가지에만 둔다.
결정은 이슈 340의 답변 코멘트에 있고, 이 코드는 그 결정의 근거를 만든 도구다.

## 무엇을 확인했나

- **누출 경계**: 바깥쪽 채점 분할의 목표값을 뒤섞어도 그 분할의 풀·전략·궤적이 글자 단위로 같다.
- **결정적 재현**: 같은 입력의 두 실행이 글자 단위로 같은 결정 산출물을 낸다.
- **중간 저장 재개**: 단위 6개 중 2개만 남기고 이어받아도 결정 산출물이 같고, 끝난 단위를 다시 계산하지 않는다.
- **산출물 모양**: 대조 99건 전부가 #347 11절의 항목 10개를 남긴다.

## 어떻게 돌리나

```sh
uv run python prototypes/issue-340/runner.py verify   # 네 가지 검사. 합성 2,000행 · 8구성원 · 5전략.
uv run python prototypes/issue-340/runner.py cost     # 등록 전략 19개 전부. 합성 4,000행 · 14구성원.
uv run python prototypes/issue-340/runner.py scale    # 실제 규모 691,369행 · 35구성원의 적합 1회 단가.
```

## 파일

- `fixture.py` - 합성 예측 행렬과 합성 장부. 실제 후보 풀 산출물을 읽지 않는다.
- `procedure.py` - 절차 본체. 학습 분할 안 leave-one-fold-out, 전략 재선택, 하향 4단계 궤적.
- `runner.py` - 네 가지 검사와 비용 측정.
